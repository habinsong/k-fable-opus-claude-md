# AI 냄새 측정기

한국어와 영어 글에서 **AI 티**(챗봇 잔재, 의미 부풀리기, 부정 대구, 번역투, 군더더기)를 비교 검토하고 **교정된 글을 출력**하는 윤문 도구 모음입니다. 윤문 엔진, 윤문 스킬, 윤문 에이전트를 한데 묶어 구성했습니다.

AI 에이전트에게 다음처럼 지시하시면 설치부터 시험까지 스스로 수행합니다.

```text
AI 냄새 측정기/ai-smell-meter 폴더의 AGENTS.md를 읽고, 설치하고, 스스로 시험해서 결과를 알려 줘.
```

| 폴더 | 내용 |
|---|---|
| [`ai-smell-meter/`](ai-smell-meter/README.md) | 엔진(`python3`, 표준 라이브러리만 사용), 스킬, 에이전트 정의, 설치 스크립트, 시험, 설계·근거·한계 문서 |

본 도구는 AI 탐지기가 아닙니다. 산출 점수는 문체 패턴의 출현 빈도일 뿐이며, 저자 판정에 쓰지 않습니다. 탐지기 우회 기능은 일절 제공하지 않습니다. 세부적인 한계는 [`ai-smell-meter/docs/limits.md`](ai-smell-meter/docs/limits.md)에 기술되어 있습니다.
