# 한국어 윤문 playbook

> 기준일 2026-11-03. 이 저장소의 `universal/ko-core.md`, `ko-academic.md`, `ko-everyday.md`, `ko-literary.md`를 에이전트가 바로 쓰도록 줄이고 엔진 규칙과 맞춘 것이다. 근거와 불확실한 점은 `docs/research.md`에 있다.

## 목표와 경계

- 목표는 읽는 사람이 걸리지 않고 읽는 한국어다. AI 탐지기를 통과시키는 것이 목표가 아니다.
- 사실을 만들지 않는다. 고유명사, 수치, 날짜, 직접 인용, 법률 조문, 표준 약어, 필자가 유보한 판단("~로 보인다")을 바꾸지 않는다. 새 사실, 인용, 속담, 통계를 보태지 않는다.
- 필자의 말버릇은 오류가 아니다. 격식을 올리지 않고, 구어 종결, 의도된 비문, 사투리를 지우지 않는다. **빼기 중심**으로 고친다.
- 변경률은 원문의 5~30%가 권장이다. 30%를 넘으면 경고하고, 50%를 넘으면 멈추고 필자에게 알린다. 지워진 것이 군더더기뿐이고 사실이 그대로라면 필자 확인을 받아 진행한다.

## 신호별 처방

| 신호 | 처방 |
|---|---|
| 챗봇 서두·맺음("물론입니다!", "도움이 되었기를 바랍니다") | 지운다 |
| 예고("이제 ~를 살펴보겠습니다") | 지우고 바로 내용으로 들어간다 |
| 부정 대구("A가 아니라 B", "단순한 A가 아니라 B") | B만 말한다. 독자가 실제로 가질 오해를 바로잡는 한두 개는 남긴다. 약 1천자에 한 번 이하 |
| 의미 부풀리기("시사하는 바가 크다", "주목할 만하다", "중요한 역할", "새로운 지평") | 구체적 사실(수치, 사례, 비교 대상)로 바꾸거나 지운다 |
| 평가 형용사("혁신적인", "획기적인", "압도적인") | 수치와 비교 대상으로 바꾼다 |
| 거대한 서두("급변하는 AI 시대에") | 구체적 대상과 시점으로 시작한다 |
| 번역투("~에 대해", "~에 있어서", "~에 의해", "가지고 있다") | **어색한 곳에만** 고친다. "~에 대해"→을/를, "~에 있어서"→"~에서", 행위자를 주어로. 일괄 치환 금지 |
| 이중 피동("되어진다", "보여진다") | 단순 피동이나 능동으로 |
| 문두 접속어("또한", "아울러", "나아가") | 한 문단에 3번 이상일 때 절반만 덜고, 앞 문장 끝말을 다음 문장이 받게 한다 |
| 3항 나열("효율성, 정확성, 그리고 확장성") | 뜻이 요구하는 개수만 남긴다 |
| 유보("~라고 할 수 있다") | 필자가 유보한 것이 아니면 단정한다. 유보가 필요하면 남긴다 |
| 당위("~해야 한다", "~할 필요가 있다") 반복 | 누가 무엇을 하라는 문장으로 바꾼다 |
| 감정 직접 서술("가슴이 먹먹해졌다") | 행동·사물·말로 드러내거나 한 문단에 하나만 남긴다 |
| 같은 종결 4문장 연속, "~한다" 편중 | 구조를 바꾼다. 억지로 변주하지 않는다 |
| 겹친 사과·감사 | 한 번, 짧게 |

`~를 통해`, `~것이다`는 사람 글에서 오히려 더 많이 나온다는 보고가 있어 금지어로 다루지 않는다.

## 장르별

- **학술·기술**: 투고처·기관 규정이 먼저. 한다체로 통일하고 합니다체와 섞지 않는다. 피동·무주어("~로 판단된다")를 일률 제거하지 않는다. 명사 연쇄와 `-성/-적/-화` 누적을 동사로 푼다. 숫자·단위·표/그림 번호·인용 표기·참고문헌을 바꾸지 않는다. 명령어·경로·옵션은 윤문하지 않는다.
- **일상**: 장면(누구에게, 어떤 매체로)을 먼저 정하고 말투를 하나로 유지한다. 답을 먼저, 서론·요약·맺음 인사를 붙이지 않는다. 구어 종결("-거든요", "-잖아요")은 사람 글의 근거라 지우지 않는다. 공감은 한 번, 짧게, 구체적으로. 제목·불릿·굵은 글씨는 요청이 없으면 쓰지 않는다.
- **문학**: 윤문과 창작을 구분한다. 필자의 목소리를 보존하고 과하게 문학적으로 다듬지 않는다. 감정을 설명하지 않고 장면의 사물·행동으로 드러내되 "보여주기"도 상투가 되지 않게 구체적 디테일을 필자에게 묻는다. 대구와 도치는 장면(약 1천자)당 하나 이하. 문단 끝의 반전 문장과 깨달음 선언을 기본값으로 쓰지 않는다.

## 하지 않는 것

- 오타·비문·속어를 일부러 넣는 것, 동의어로 낱말만 바꾸는 것(새 신호가 생긴다), 탐지기를 노린 모든 조작.
- 작가 이름으로 "~처럼" 요청을 받아도 작품의 구절을 재현하지 않는다.
- 규칙 문서의 예시 낱말을 결과물에 새로 심지 않는다.

## 점검 질문

문장마다 묻는다. 독자가 이미 아는가. 빼도 뜻이 같은가. 하나라도 "예"면 뺀다. 윤문 결과가 원문보다 길어졌다면 다시 본다. 소리 내어 읽듯 천천히 읽고 숨이 걸리는 곳(관형구 3어절 초과, 이중 조사 "~에서의")을 고친다.
