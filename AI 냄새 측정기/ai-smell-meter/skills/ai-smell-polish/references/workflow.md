# 작업 흐름과 명령

## 명령 모음

`S`는 `scripts/ai-smell`의 경로다. Windows는 `python3` 대신 `py -3`을 쓴다.

| 목적 | 명령 | 출력 |
|---|---|---|
| 설치 확인 | `python3 "$S" selftest` | 통과/실패 목록. 종료 코드 0이면 정상 |
| 환경 점검 | `python3 "$S" doctor` | Python 버전, 설치 위치 |
| 측정 | `python3 "$S" analyze 글.md [--genre academic] [--format json]` | 지수와 신호 목록 |
| 교정문 출력 | `python3 "$S" polish 글.md [--tier standard]` | **표준 출력: 교정문**, 표준 오류: 요약 |
| 파일로 저장 | `python3 "$S" polish 글.md --out 글.교정.md` | 교정문 파일, 요약은 표준 출력 |
| 제자리 교정 | `python3 "$S" polish 글.md --in-place` | `.bak` 백업 후 덮어쓰기 |
| diff 보기 | `python3 "$S" polish 글.md --diff` | 통합 diff |
| JSON | `python3 "$S" polish 글.md --format json` | `corrected`, `edits`, `remaining`, `verify` |
| LLM 프롬프트 | `python3 "$S" prompt 글.md --target claude` | 남은 신호를 고칠 지시문 |
| 대조 검증 | `python3 "$S" verify 원문.md 윤문본.md` | PASS/WARN/CONFIRM/FAIL |
| 규칙 보기 | `python3 "$S" rules [--lang ko] [--category structure]` | 규칙 id, 등급, 교정 단계 |
| 작성자 금지어 | `--ban "구절"` 또는 `--ban-file 목록.txt` | 모든 명령에서 쓸 수 있다 |

입력은 파일 경로, `-`(표준 입력), `--text "..."` 중 하나다. 한글이 깨지면 `PYTHONUTF8=1`을 준다. 파일 크기 상한은 2MB다.

## 교정 단계

| 단계 | 하는 일 | 뜻이 바뀔 수 있나 |
|---|---|---|
| `safe` | 누출된 인용 토큰, 보이지 않는 문자, 줄바꿈 없는 공백 정리 | 아니오 |
| `standard` (기본) | 챗봇 잔재·예고·공치사 삭제, 장황한 구절 단순화, 이중 피동, 불필요한 유보 삭제 | 거의 아니오 |
| `strong` | 부정 대구의 앞 절 삭제, 분사 꼬리 삭제, 낱말 교체, 줄표·강조어 정리 | **예. 읽고 확인한다** |

구조 습관(대구, 부풀린 서술, 3항 나열, 번역투 일부)은 어느 단계에서도 자동으로 고치지 않는다. 필자가 무엇을 말하려는지 알아야 고칠 수 있기 때문이다.

## 반복 루프

```
측정(analyze) -> 기계적 교정(polish) -> 남은 신호 수정(에이전트) -> 대조(verify) -> 재측정
```

중단 조건(하나라도 해당하면 멈추고 사용자에게 알린다):

- `verify`가 **FAIL**: 숫자, 주소, 코드, 직접 인용이 바뀌었다. 되돌린다.
- `verify`가 **CONFIRM**: 변경률이 50%를 넘었다. 지워진 것이 군더더기뿐인지 필자 확인을 받는다.
- 같은 신호가 두 번 고쳐도 남는다: 접근을 바꾸거나 필자에게 묻는다.
- 3회 반복해도 지수가 줄지 않는다.
- 글에 구체적 내용(수치, 사례, 고유명사)이 없다: 지어내지 말고 필자에게 알맹이를 묻는다.

## 보고 형식 (사용자 언어로)

1. 교정문 (그대로, 요약하지 않는다)
2. 지수 변화: `72 → 31 (강함 → 약함)`
3. 바꾼 것 3~5개 (무엇을, 왜)
4. 남긴 것과 이유 (필자의 문체, 학술 관행 등)
5. 필자가 채울 것 (구체적 수치·사례), 확인이 필요한 strong 단계 교정
6. 한 줄 한계: "문체 신호를 줄였을 뿐, 사람이 썼다는 뜻도 탐지되지 않는다는 뜻도 아니다."

## 종료 코드

`analyze`: 0 (단, `--fail-above N`이면 지수가 N보다 클 때 1). `polish`, `verify`: FAIL이면 1. 오류: 2.
