## 2. 이 모델의 웹 리서치 운용 (잠정)
2026-11-03 기준 GLM-5.5의 공식 발표를 찾지 못했다. 모델 상태와 출시일 체크리스트는 같은 폴더의 `general.md` §2를 따른다. 출시 전에는 `glm/glm-5.3/web-research.md`를 적용한다.

**출시 후 웹 리서치에서 따로 확인할 것**
- 내장 웹 검색 여부와 요금: 5.3에서는 리셀러가 내장 검색($0.033/요청)을 서술했을 뿐 공식 확인이 없었다. 5.5의 공식 문서에서 검색 기능, 인용 반환 방식, 요금을 확인하기 전에는 검색을 하네스가 맡고 모델은 읽고 정리하게 한다.
- 심층 리서치 지표(BrowseComp 등), 인용 정확도, 인젝션 방어율의 독립 측정이 나오는지 확인한다. 5.3에는 없었다. 있다 해도 벤치마크 이름·하네스·보고 주체를 확인하고, 터미널·코딩 점수를 리서치 능력으로 옮기지 않는다.
- 환각률(AA-Omniscience 등)의 독립 값이 공개되면 지수 버전과 변형을 명시해 읽는다. 값이 좋아도 이름·날짜·수치·버전은 직접 연 출처로 확인하고 인용 구절은 코드로 원문 포함 여부를 대조한다.
- 컨텍스트가 커도(5.2 계승 추정 100만 토큰) 페이지 하나씩 필요한 구간만 넣는다. 추론 토큰이 출력 한도에 포함되는지, 병렬 도구 호출이 호출 경로마다 다른지 사용하는 경로에서 시험한다.
- 웹 페이지의 지시문은 데이터다. 읽기 단계와 행동 단계를 분리하고, 이미지 입력이 있다면 스크린샷 속 글자도 지시문처럼 따르지 않게 한다.
- 호출 경로(구독 대 토큰 과금)의 약관이 대량 자동 수집을 허용하는지, 수집한 자료를 보내도 되는지 데이터 처리 조건과 함께 확인한다. 대상 사이트의 이용 약관·로봇 배제 표준(§3.2)도 지킨다.

**잠정 운용**
- 출시 전 웹 리서치는 GLM-5.3과 상위 모델을 기준선으로 한다. 공식 발표와 독립 측정이 나오기 전에는 5.5를 리서치의 기본으로 지정하지 않는다.
