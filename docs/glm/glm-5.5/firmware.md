## 2. 이 모델의 펌웨어 작업 운용 (잠정)
2026-11-03 기준 GLM-5.5의 공식 발표를 찾지 못했다. 모델 상태와 출시일 체크리스트는 같은 폴더의 `general.md` §2를 따른다. 출시 전에는 `glm/glm-5.3/firmware.md`를 적용한다.

**출시 후 펌웨어 작업에서 따로 확인할 것**
- 어떤 크기로 나오든 이 계열은 기기 안에서 돌리는 모델이 아니다(5.3은 총 약 744B, Flash도 약 320B). 크기가 공개되면 기기 내 추론이 아니라 개발 워크스테이션의 API 보조 도구로만 쓴다. 기기 내 추론이 필요하면 소형 모델 문서(`gemma-4-e2b`, `gemma-4-e4b`)를 본다.
- 유출 보도의 "장시간 자율 코딩 에이전트" 초점이 사실이라도 에이전트에게 장치 접근을 열어 주지 않는다. 플래시 소거, 퓨즈·OTP, 보호 비트, 부트로더 덮어쓰기, 디버그 포트 잠금은 사람이 대상 장치와 이미지를 확인한 뒤 실행한다. 프로그래머·시리얼 제어 도구는 읽기 전용부터 연결하고 권한·훅으로 쓰기 명령을 차단한다. [미확인: 유출]
- 임베디드·펌웨어에 대한 평가는 5.3에 없었다. 출시 후 평가가 나오는지 확인하고, 없으면 펌웨어 코드를 직접 쓰거나 고치게 하지 않는 규칙을 유지한다. 이 영역은 상위 모델 문서(`gemini-4-argon`, `claude/sonnet-5.5` 이상, `gpt-6.1-sol`)를 따른다.
- 환각률의 독립 값이 확인되기 전까지 레지스터·타이밍을 모델의 기억에서 가져오지 않는다. 데이터시트·레퍼런스 매뉴얼의 개정판과 페이지를 사람이 확보한 텍스트로 준다(§3.1).
- 병렬 도구 호출이 호출 경로마다 다르게 동작할 수 있으므로 한 번에 여러 쓰기 명령이 나가지 않는지 확인한다.
- 펌웨어 소스·로그·서명 키·양산 이미지는 데이터 처리 조건이 공개되고 법무가 검토하기 전에는 API로 보내지 않는다. 서명 키와 디버그 인증 정보는 약관과 무관하게 보내지 않는다(§3.4).
- 자체 호스팅이 가능해지면 가중치는 공식 저장소에서만 받고 해시를 확인하며 격리 환경에서 시험한다.

**잠정 운용**
- 출시 전 펌웨어 작업은 상위 모델을 기준선으로 하고 GLM 계열은 로그 분류, 맵 파일 요약, 호스트 테스트 초안 같은 보조에만 쓴다. 공식 발표와 독립 측정이 나오기 전에는 5.5를 펌웨어 작업의 기본으로 지정하지 않는다.
