## 2. 이 모델의 연구 작업 운용 (잠정)
2026-11-03 기준 GLM-5.5의 공식 발표를 찾지 못했다. 모델 상태와 출시일 체크리스트는 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 출시 전에는 `glm/glm-5.3/research.md`를 적용한다.

**출시 후 연구 작업에서 따로 확인할 것**
- 유출 보도는 깊은 추론을 강조한다고 한다. 사실이어도 시험 문제 풀이 점수가 가설 설계, 통계 해석, 문헌 종합의 정확도를 대신하지는 않는다. 연구 보조 정확도의 독립 평가가 나오는지 확인하고, 없으면 새 가설·증명·통계 해석은 상위 모델 문서(`gemini-4-argon`, `claude/opus-5.5`, `gpt-6-astra`)를 따르고 전문가 검토를 거친다. [미확인: 유출]
- 독립 평가 점수를 인용할 때는 벤치마크 버전과 변형을 함께 쓴다. GLM-5.3은 같은 평가 사이트에서 60과 45로 갈렸고 일부 페이지에 "독립 평가 예정(추정치)" 표기가 있었다.
- 벤더 벤치마크는 연구 근거로 인용하지 않는다. 인용해야 하면 "벤더 보고"임을 쓰고 원문을 연다.
- 참고문헌 생성 정확도는 모델 전반의 약점으로 보고돼 있다(26개 LLM 연구에서 모든 필드가 맞은 비율 48.3%, 저자 목록이 가장 약함). 5.5의 별도 측정이 나오기 전에는 인용을 모두 Crossref·DataCite·원문으로 확인한다(§3.2).
- 환각률의 독립 값이 공개되면 벤치마크 버전과 변형을 명시해 읽는다. 값이 좋아도 모르는 것을 모른다고 답한다는 근거가 되는지는 지표 정의를 확인한다.
- 연구 데이터를 API로 보내기 전에 데이터 처리 위치·보관·학습 사용 조건을 확인한다. 사람 대상 자료, 개인정보, 미공개 데이터는 연구 윤리 심의와 동의 범위(§3.3)를 먼저 확인한다.
- 재현성을 위해 모델 이름, 변형, 호출 경로, 호출 날짜, 추론 설정, 샘플링 설정을 기록한다. 이 계열은 빠르게 갱신되고 경로마다 동작이 달라 기록 없이는 재현할 수 없다.

**잠정 운용**
- 출시 전 연구 작업은 상위 모델을 기준선으로 하고 GLM 계열은 서식 변환, 로그 정리, 정해진 필드 추출 같은 보조에만 쓴다. 공식 발표와 독립 측정이 나오기 전에는 5.5를 연구의 기본으로 지정하지 않는다.
