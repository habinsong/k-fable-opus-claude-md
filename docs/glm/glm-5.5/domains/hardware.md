## 2. 이 모델의 하드웨어 작업 운용 (잠정)
2026-11-03 기준 GLM-5.5의 공식 발표를 찾지 못했다. 모델 상태와 출시일 체크리스트는 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 출시 전에는 `glm/glm-5.3/hardware.md`를 적용한다.

**출시 후 하드웨어 작업에서 따로 확인할 것**
- GLM-5.3에는 회로·PCB·HDL 평가와 데이터시트 판독 정확도 평가가 없었다. 5.5에서도 없을 가능성이 높다. 출시 후 평가가 나오는지 확인하고, 없으면 설계 판단에는 쓰지 않는다는 규칙을 유지한다. 설계는 상위 모델 문서(`gemini-4-argon`, `claude/opus-5.5`, `gpt-6.1-sol`)를 따른다.
- 환각률과 사실 정확도(AA-Omniscience 등)의 독립 값이 5.3에서는 확인되지 않았다. 5.5의 값이 공개되면 지수 버전과 변형(max/low 등)을 명시해 읽는다. 값이 좋아도 부품 번호·핀·정격을 기억에서 꺼내게 하지 않는 규칙은 유지한다(§3.1).
- 입력 방식에 이미지가 포함되는지, 데이터시트의 작은 글씨·핀 표·타이밍 다이어그램·회로도를 읽는 정확도가 어떤지 같은 문서 세트로 상위 모델과 비교한다. 이미지에서 읽은 값은 원문 텍스트·넷리스트·ERC 보고서와 대조한다.
- 컨텍스트가 커도(5.2 계승 추정 100만 토큰) 데이터시트를 통째로 넣지 않고 필요한 장과 표만 넣는다.
- 회로도·레이아웃·펌웨어 이미지·부품 공급 정보는 영업비밀이다. 데이터 처리 위치·보관·학습 사용 조건이 공개되고 법무가 검토하기 전에는 API로 보내지 않는다.
- 인체·화재 위험 설계는 "안전하다"고 단정하지 않는다는 원칙은 모델이 바뀌어도 유지한다.

**잠정 운용**
- 출시 전 하드웨어 작업은 상위 모델을 기준선으로 하고 GLM 계열은 BOM 정규화, 로그 분류, 스크립트 초안 같은 보조에만 쓴다. 공식 발표와 독립 측정이 나오기 전에는 5.5를 하드웨어 작업의 기본으로 지정하지 않는다.
