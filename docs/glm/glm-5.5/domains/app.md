## 2. 이 모델의 앱 작업 운용 (잠정)
2026-11-03 기준 GLM-5.5의 공식 발표를 찾지 못했다. 모델 상태와 출시일 체크리스트는 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 출시 전에는 `glm/glm-5.3/app.md`를 적용하고, 경량·멀티모달 용도는 `glm/glm-5.3-flash/app.md`를 본다.

**출시 후 앱 작업에서 따로 확인할 것**
- 유출 보도는 총 1조 파라미터 이상(2.5~3.5조 주장도 있음)이라고 한다. 사실이면 기기 내 실행은 더 불가능하고 서버 호출만 가능하다. 크기가 공개되면 자체 호스팅 가능성과 운영비를 다시 계산한다. [미확인]
- 호출 경로와 약관: 5.3은 구독 우선이었고 토큰 과금 API가 단계적으로 열렸다. 개발자용 구독을 최종 사용자 앱의 백엔드로 쓰는 것이 허용되는지, 제3자 호스트를 거칠 때 데이터 경로가 어떻게 달라지는지 약관을 원문으로 확인한다.
- 라이선스: 5.3 플래그십은 대규모 모델 서비스 운영자에게 보안 심사 조항이 있는 자체 라이선스였고 Flash는 MIT였다. 5.5의 조항이 앱·서비스 배포에 영향을 주는지 원문으로 확인한다.
- 입력 방식에 이미지·영상이 포함되면 사용자 사진·영상이 서버로 가므로 개인정보 선언(Apple 개인정보 영양 표시, Google Play 데이터 보안 양식)과 처리방침을 갱신한다. 데이터 처리 위치·보관·학습 사용 조건이 공개되기 전에는 아동·민감정보를 보내지 않는다.
- 모델 교체를 앱 업데이트 없이 할 수 있게 설계한다(서버 쪽 모델 설정, 폴백 모델, 회귀 시험, 기능 플래그). 이 계열은 0.1 단위로 빠르게 갱신되고 모델 ID·가격·약관이 출처마다 달랐다.
- 모바일(Kotlin·Swift) 코드 평가는 5.3에도 없었다. 출시 후 언어별 평가가 있는지 확인하고, 없으면 컴파일·린트·단위 테스트·UI 테스트로 검증한다.
- 앱에서 직접 호출하지 않고 자체 백엔드를 두는 원칙, API 키를 바이너리에 넣지 않는 원칙은 모델이 바뀌어도 유지한다.

**잠정 운용**
- 출시 전 앱 내장 AI 기능은 GLM-5.3 계열이나 다른 후보로 구현하되 모델 이름을 코드에 박지 않는다. 공식 발표와 독립 측정이 나오기 전에는 5.5를 기본 모델로 지정하지 않는다.
