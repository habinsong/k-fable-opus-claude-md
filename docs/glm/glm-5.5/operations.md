#### 2.2 잠정 규칙: 출시 전까지는 GLM-5.3 문서를 따른다
- 같은 계열의 직전 플래그십이므로 `glm/glm-5.3/` 문서의 규칙을 그대로 쓴다. 그 규칙은 GLM-5.3에 대해 확인된 것(대부분 2차 출처)이며 GLM-5.5에서 같다는 보장은 없다. 경량·멀티모달 용도는 `glm/glm-5.3-flash/` 문서를 본다.
- 상속 가능성이 높아 보이는 항목(추정): MoE 구조, 100만 토큰급 컨텍스트, 낮은 단가를 앞세운 가격 전략, 빠른 버전 갱신, 데이터 처리 조건 정보 부족. [추정]
- 바뀔 가능성이 큰 항목(추정): 크기(자체 호스팅 가능성), 라이선스(5.3 플래그십은 MIT가 아닌 자체 라이선스에 대규모 사업자 조항, Flash는 MIT), 가중치 공개 시점(5.3은 API 출시 약 2주 뒤 공개로 보도됨), 호출 경로(5.3 초기에 구독 우선), 가격. [추정]

#### 2.3 출시 당일 확인 체크리스트 (공식 문서에서 직접, 하나씩)
1. Z.ai 공식 릴리스 로그의 발표일, 모델 ID, 별칭, 변형(max/low/flash/flashx 등), 폐기 예정일.
2. 호출 경로: 구독 전용인지 토큰 과금 API가 열렸는지, 제3자 호스트 제공 여부와 경로별 한도·병렬 도구 호출 동작.
3. 가격: 입력·출력·캐시·무료 등급·크레딧 차감 비율. 출처가 갈리면 공식 가격표를 우선한다.
4. 컨텍스트, 최대 출력, 추론 토큰이 출력 한도에 포함되는지, 지식 컷오프, 입력 방식(텍스트·이미지·영상).
5. 라이선스 원문: MIT인지 자체 라이선스인지, 대규모 사업자 조항의 임계값과 정의, AUP 유무, 상업 이용 조건.
6. 가중치 공개 일정과 공식 저장소 이름. 제3자 재업로드를 쓰지 않고 해시를 확인한다(`glm-5.3-flash` 문서의 공급망 경고).
7. 추론 노력 지정 방식(API 파라미터), 끌 수 있는지, 도구 호출·구조화 출력 지원.
8. 데이터 처리 위치·보관·학습 사용·하위 처리자(지금은 모두 찾지 못함).
9. 모델 카드와 이행 가이드의 깨지는 변경, 이전 모델(GLM-5.3 계열)의 폐기 일정.
10. 독립 평가: Artificial Analysis 등의 측정이 나올 때까지 벤더 수치는 주장으로만 취급하고, 벤치마크 버전을 명시해 인용한다(5.3에서 60과 45로 갈린 전례).
