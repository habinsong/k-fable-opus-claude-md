## 2. 모델 상태 — GLM-5.5 (2026-11-03 기준 미출시로 추정)

### 2.1 확인된 것과 확인되지 않은 것
- **공식 발표를 찾지 못했다.** 2026-10-16자 한 정리 글은 Z.ai 공식 릴리스 로그가 2026-08-26의 GLM-5.3-Flash에서 끝나고, 개발자 문서에 GLM 5.5를 언급하는 페이지가 없으며, API 모델 ID와 가격도 없다고 적었다. 다른 글은 문서·블로그의 GLM-5.5 주소가 404라고 했다. 이 환경에서는 Z.ai 공식 문서를 열 수 없어 이는 2차 출처의 서술이고, 2026-10-16 이후의 발표는 확인하지 못했다. [부분/미확인]
- **출시 시기 정보는 애널리스트 예측이다.** 2026-08 출시설은 GLM-5.2 출시 때 보도(CGTN, 로이터를 인용)에서 JPMorgan 분석가의 전망으로 나왔고 Z.ai의 약속이 아니다. 그 8월은 발표 없이 지났다. [부분]
- **이름도 확정이 아니다.** Z.ai는 올해 GLM-5부터 5.3까지 0.1 단위로 올렸고, 다음이 5.4일지 5.5일지 6일지 중국 보도에 추측이 갈린다. 이 폴더의 `glm-5.5`는 사용자가 정한 대응 대상 이름이다. [부분/미확인]
- **스펙은 유출·추정뿐이다.** 총 1조 파라미터 이상(증권사 노트를 인용한 분석가 문구, Zhipu 발표 아님), 2.5~3.5조(한 중개 사이트의 미검증 보도, 활성 파라미터 미공개), 컨텍스트 100만 토큰(GLM-5.2 계승 추정), 초점은 장시간 자율 코딩 에이전트·깊은 추론·추론 효율·아키텍처 변경 가능성. 벤치마크 수치는 찾지 못했다. 일부 유출 글은 다른 회사의 최신 모델보다 우월하다고 주장하나 근거가 없다. [미확인]
- **그래서 스펙을 쓰지 않는다.** 가격, 컨텍스트, 크기, 라이선스, 입력 방식, 호출 경로, 데이터 처리는 모두 [미확인]이다. 이 폴더의 어떤 문장도 GLM-5.5의 성능이나 동작을 단정하지 않는다.
- 출시 전에 모델 ID 문자열을 코드에 박지 않는다. 명명 규칙으로 추정한 ID가 틀릴 수 있다. Z.ai 공식 문서의 릴리스 로그와 모델 목록에서 확인한 ID만 쓴다.

### 2.2 잠정 규칙: 출시 전까지는 GLM-5.3 문서를 따른다
- 같은 계열의 직전 플래그십이므로 `glm/glm-5.3/` 문서의 규칙을 그대로 쓴다. 그 규칙은 GLM-5.3에 대해 확인된 것(대부분 2차 출처)이며 GLM-5.5에서 같다는 보장은 없다. 경량·멀티모달 용도는 `glm/glm-5.3-flash/` 문서를 본다.
- 상속 가능성이 높아 보이는 항목(추정): MoE 구조, 100만 토큰급 컨텍스트, 낮은 단가를 앞세운 가격 전략, 빠른 버전 갱신, 데이터 처리 조건 정보 부족. [추정]
- 바뀔 가능성이 큰 항목(추정): 크기(자체 호스팅 가능성), 라이선스(5.3 플래그십은 MIT가 아닌 자체 라이선스에 대규모 사업자 조항, Flash는 MIT), 가중치 공개 시점(5.3은 API 출시 약 2주 뒤 공개로 보도됨), 호출 경로(5.3 초기에 구독 우선), 가격. [추정]

### 2.3 출시 당일 확인 체크리스트 (공식 문서에서 직접, 하나씩)
1. Z.ai 공식 릴리스 로그의 발표일, 모델 ID, 별칭, 변형(max/low/flash/flashx 등), 폐기 예정일.
2. 호출 경로: 구독 전용인지 토큰 과금 API가 열렸는지, 제3자 호스트 제공 여부와 경로별 한도·병렬 도구 호출 동작.
3. 가격: 입력·출력·캐시·무료 등급·크레딧 차감 비율. 출처가 갈리면 공식 가격표를 우선한다.
4. 컨텍스트, 최대 출력, 추론 토큰이 출력 한도에 포함되는지, 지식 컷오프, 입력 방식(텍스트·이미지·영상).
5. 라이선스 원문: MIT인지 자체 라이선스인지, 대규모 사업자 조항의 임계값과 정의, AUP 유무, 상업 이용 조건.
6. 가중치 공개 일정과 공식 저장소 이름. 제3자 재업로드를 쓰지 않고 해시를 확인한다(`glm-5.3-flash` 문서의 공급망 경고).
7. 추론 노력 지정 방식(API 파라미터), 끌 수 있는지, 도구 호출·구조화 출력 지원.
8. 데이터 처리 위치·보관·학습 사용·하위 처리자(지금은 모두 찾지 못함).
9. 모델 카드와 이행 가이드의 깨지는 변경, 이전 모델(GLM-5.3 계열)의 폐기 일정.
10. 독립 평가: Artificial Analysis 등의 측정이 나올 때까지 벤더 수치는 주장으로만 취급하고, 지수 버전을 명시해 인용한다(5.3에서 60과 45로 갈린 전례).

### 2.4 비판적 점검
- **루머로 도입을 결정하지 않는다.** 출시일과 성능에 대한 글은 대부분 애널리스트 전망, 유출, 서로를 인용하는 SEO성 블로그다. 공식 발표 전에는 GLM-5.3 계열과 다른 후보로 평가를 진행한다.
- **출시 직후 측정은 얕다.** GLM-5.3도 출시일·사양·지수·가격이 출처마다 달랐다. 같은 과제·같은 예산으로 직접 비교한다.
- **이행 비용을 먼저 본다.** 이 계열은 0.1 단위로 빠르게 갱신되고 호출 경로·라이선스가 바뀌었다. 하네스와 법무 검토를 다시 해야 할 수 있다.
- **이 폴더를 출시 후 갱신한다.** 위 체크리스트를 채운 뒤 이 `general.md`의 §2를 실제 사양으로 바꾸고, 8개 분야 문서의 §2에 모델별 운용을 쓴다. 갱신 전의 이 문서는 추정을 단정으로 읽지 않기 위한 장치다.
