## 2. 이 모델의 기술 조사 운용, 그리고 이 모델을 평가할 때 (잠정)
2026-11-03 기준 GLM-5.5의 공식 발표를 찾지 못했다. 모델 상태와 출시일 체크리스트는 같은 폴더의 `general.md` §2를 따른다. 출시 전에는 `glm/glm-5.3/tech-research.md`를 적용한다.

**이 모델에게 기술 조사를 시킬 때**
- 출시 전에는 이 모델을 쓸 수 없다. 출시 후에도 분류·정리 단계에만 쓰고, 값은 사람이 확보한 1차 자료 텍스트에서 추출하게 하며 원문에 없으면 null로 둔다. 라이선스 호환성, 특허, 규정 적용 여부, 도입 권고는 단정시키지 않는다(§3.2, §3.5).

**GLM-5.5를 도입 후보로 평가할 때 (출시 후)**
- **루머로 평가하지 않는다.** 크기(1조 이상, 2.5~3.5조), 출시일(8월 전망은 이미 지남), 성능 우월 주장은 애널리스트 전망·유출·SEO성 블로그에서 나왔고 서로를 인용한다. 도입 판단 근거는 공식 문서와 독립 평가가 나온 뒤에만 쓴다. [미확인]
- **라이선스를 원문으로 확인한다.** GLM-5.3 플래그십은 MIT가 아닌 자체 라이선스(12개월 합산 매출 100억 달러 초과 모델 서비스 운영자의 보안 심사 조항 보도)였고 Flash는 MIT였다. 5.5가 어느 쪽인지, 상업 이용·재배포·파생 조건과 임계값 정의를 LICENSE 원문(공식 저장소)으로 확인한다. 해석은 라이선스에 적힌 문의처에 한다(§3.2).
- **총비용은 과제당 비용이다.** 호출 경로(구독 대 토큰 과금 대 제3자 호스트)마다 단가·한도·크레딧 차감이 다르고, 추론 토큰이 출력 한도와 청구에 들어가는지에 따라 달라진다. 5.3에서는 가격이 출처마다 달랐다. 공식 가격표와 우리 과제의 실측으로 계산한다.
- **데이터 거버넌스.** 처리 위치, 보관 기간, 학습 사용 여부, 하위 처리자와 관할이 공개됐는지 확인한다. 5.3에서는 찾지 못했다. 공개되지 않으면 개인정보·영업비밀·규제 데이터는 보내지 않고 법무·보안 검토를 거친다.
- **자체 호스팅 가능성.** 크기가 공개되면 필요한 GPU 노드와 운영비를 계산한다. 가중치 공개 시점은 5.3에서 API 출시 약 2주 뒤로 보도됐다. 공식 저장소에서만 받고 제3자 재업로드는 쓰지 않는다.
- **독립 평가의 품질을 본다.** 같은 평가 사이트에서도 지수 버전에 따라 값이 갈린다(5.3: 60 대 45). 벤치마크 버전, 변형, 하네스, 보고 주체를 명시해 같은 조건의 모델끼리 비교하고 최종 선택은 자체 실측으로 한다.
- **공급 연속성.** 이 계열은 0.1 단위로 빠르게 갱신된다. 모델 교체 절차, 폴백 모델, 회귀 시험을 도입 조건으로 둔다. 이름이 5.5가 아닐 수도 있다(5.4 또는 6 추측).
- **제공자 안전장치와 규정.** 규제 적합성은 모델이 아니라 시스템 전체에 대해 판단하고, 모델 카드나 가중치 라이선스를 규정 준수의 근거로 쓰지 않는다.

**잠정 운용**
- 출시 전 기술 선정은 GLM-5.3 계열과 다른 후보로 진행한다. 공식 발표와 독립 측정이 나오기 전에는 5.5를 도입 후보로 확정하지 않는다.
