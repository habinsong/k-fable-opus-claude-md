#### 2.1 확인된 것과 확인되지 않은 것
- **공식 발표를 찾지 못했다.** 2026-10-16자 한 정리 글은 Z.ai 공식 릴리스 로그가 2026-08-26의 GLM-5.3-Flash에서 끝나고, 개발자 문서에 GLM 5.5를 언급하는 페이지가 없으며, API 모델 ID와 가격도 없다고 적었다. 다른 글은 문서·블로그의 GLM-5.5 주소가 404라고 했다. 이 환경에서는 Z.ai 공식 문서를 열 수 없어 이는 2차 출처의 서술이고, 2026-10-16 이후의 발표는 확인하지 못했다. [부분/미확인]
- **출시 시기 정보는 애널리스트 예측이다.** 2026-08 출시설은 GLM-5.2 출시 때 보도(CGTN, 로이터를 인용)에서 JPMorgan 분석가의 전망으로 나왔고 Z.ai의 약속이 아니다. 그 8월은 발표 없이 지났다. [부분]
- **이름도 확정이 아니다.** Z.ai는 올해 GLM-5부터 5.3까지 0.1 단위로 올렸고, 다음이 5.4일지 5.5일지 6일지 중국 보도에 추측이 갈린다. 이 폴더의 `glm-5.5`는 사용자가 정한 대응 대상 이름이다. [부분/미확인]
- **스펙은 유출·추정뿐이다.** 총 1조 파라미터 이상(증권사 노트를 인용한 분석가 문구, Zhipu 발표 아님), 2.5~3.5조(한 중개 사이트의 미검증 보도, 활성 파라미터 미공개), 컨텍스트 100만 토큰(GLM-5.2 계승 추정), 초점은 장시간 자율 코딩 에이전트·깊은 추론·추론 효율·아키텍처 변경 가능성. 벤치마크 수치는 찾지 못했다. 일부 유출 글은 다른 회사의 최신 모델보다 우월하다고 주장하나 근거가 없다. [미확인]
- **그래서 스펙을 쓰지 않는다.** 가격, 컨텍스트, 크기, 라이선스, 입력 방식, 호출 경로, 데이터 처리는 모두 [미확인]이다. 이 폴더의 어떤 문장도 GLM-5.5의 성능이나 동작을 단정하지 않는다.
- 출시 전에 모델 ID 문자열을 코드에 박지 않는다. 명명 규칙으로 추정한 ID가 틀릴 수 있다. Z.ai 공식 문서의 릴리스 로그와 모델 목록에서 확인한 ID만 쓴다.
