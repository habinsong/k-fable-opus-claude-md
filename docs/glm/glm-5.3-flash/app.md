## 2. 이 모델의 앱 작업 운용
모델 전체 특성은 같은 폴더의 `general.md` §2를 따른다. 요약: 총 약 320B라 기기 내 실행 불가(FP8 가중치 약 306 GiB), 이미지·영상 입력(출처 충돌), MIT 가중치, 호출 경로마다 가격·한도·동작이 다름, 모바일 개발 독립 평가 없음.

**앱에 내장할 때**
- **기기 안에서 돌릴 모델이 아니다.** 경량이라는 이름과 달리 총 약 320B, FP8 가중치만 약 306 GiB다. 가장 공격적인 1비트 양자화(약 93 GB)도 GPU 여러 장이 필요했다는 개인 시험이 있다. 모바일 온디바이스는 `gemma-4-e2b`, `gemma-4-e4b` 문서를 본다. 앱은 서버를 거쳐 호출하는 구조만 가능하다. [부분]
- **호출 경로를 정하고 경로별 약관을 확인한다.** Z.ai 직접, 개발자 요금제, 제3자 호스트(Sarvam·OpenRouter·Vercel 등)는 가격($0.04/$0.08부터 $0.20/$0.50까지 출처마다 다름), 한도, 병렬 도구 호출 동작, 데이터 경로가 다르다. 개발자용 요금제를 최종 사용자 앱의 백엔드로 쓰는 것이 허용되는지 약관을 원문으로 읽는다. [부분, 충돌/미확인]
- **무료 등급을 운영 앱의 기본 경로로 쓰지 않는다.** 한도가 예고 없이 줄 수 있고 기간 한정 무료는 종료일이 미확인이다. 429·503 응답에 대한 재시도, 폴백 모델, 오류 UX를 설계한다. [부분]
- **API 키를 앱 바이너리나 리소스에 넣지 않는다.** 자체 백엔드에서 키 보관, 사용량 제한, 요청 검증, 로깅을 한다(§3.1 비밀 규칙). 모델 출력은 신뢰하지 않는 입력으로 취급해 서버에서 검증한 뒤 앱에 전달한다.
- **이미지·영상을 보내는 기능은 특히 조심한다.** 사용자가 올린 사진·영상에는 얼굴, 위치, 문서가 담길 수 있다. 데이터 처리 위치·보관 기간·학습 사용 조건을 찾지 못했다. [미확인] 앱의 개인정보 선언(Apple 개인정보 영양 표시, Google Play 데이터 보안 양식)과 처리방침에 반영하고, 아동·민감정보는 확인 전에 보내지 않는다. 영상 입력 지원 여부 자체가 출처마다 달라(텍스트·이미지만 vs 영상 포함) 공식 문서로 먼저 확인한다.
- **MIT 라이선스 가중치를 직접 호스팅하면 공급망을 지킨다.** 제3자 재업로드가 퍼져 있으므로 공식 조직의 저장소에서만 받고 해시를 확인한다. 고지·NOTICE를 지킨다(general.md §2.4, §1.5). [부분/추정]
- **모델 교체를 앱 업데이트 없이 할 수 있게 설계한다.** 출시일·가격·사양이 출처마다 다르고 후속(GLM-5.5)이 예고돼 있다. 서버 쪽 모델 설정, 폴백 모델, 회귀 시험, 기능 플래그를 둔다.
- **비용은 토큰 기준으로 서버에서 제한한다.** 추론 토큰이 출력 한도에 들어간다는 서술이 있어 `max_tokens`와 사용자당 한도를 서버에 두고 실제 청구서로 확인한다. [부분]

**개발 보조로 쓸 때**
- **모바일(Kotlin·Swift) 코드에 대한 독립 평가는 찾지 못했다.** [미확인] 소규모 시험(SVG, 게임, 작은 함수)만 있다. 컴파일·린트·단위 테스트·UI 테스트로 검증하고, 수명주기·권한·비동기 처리가 걸린 구현은 상위 모델 문서를 따른다(`claude/sonnet-5.5`, `gpt-6.1-sol`, `gemini-4-argon`).
- 스토어 규정은 기억으로 답하지 않고 공식 문서로 확인한다(§3.2). 서명 키, 프로파일, 스토어 제출·배포는 승인 후에만 한다.
