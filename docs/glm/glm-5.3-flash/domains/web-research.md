## 2. 이 모델의 웹 리서치 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: 컨텍스트 최대 100만 토큰, 장문 지표 AA-LCR 80.0%(집계가 인용), 이미지 입력, 내장 웹 검색은 플래그십 리셀러 서술뿐, 인용 정확도·인젝션 방어율 독립 측정 없음, 환각률 값 미확인.

- **내장 검색은 확인하지 못했다.** 플래그십에 대해 리셀러가 내장 웹 검색($0.033/요청)을 서술했으나 Flash에 같은 기능이 있는지는 찾지 못했다. [미확인] 검색 호출과 출처 신뢰도 판단은 하네스와 사람이 맡고, 모델에는 확보한 페이지 텍스트에서 제목·날짜·가격·버전 같은 필드를 JSON으로 추출하게 한다. "원문에 없으면 null"을 명시하고 값마다 근거 구절을 받아 코드로 원문 포함 여부를 대조한다.
- **저렴한 모델을 대량 추출에 쓰되 오류율을 비교한다.** 단가가 낮아 페이지 대량 정리에 유리하다. 다만 호출 경로마다 가격($0.04/$0.08~$0.20/$0.50)과 한도가 다르고 무료 등급은 예고 없이 줄 수 있다. 오류율이 기준을 넘으면 플래그십(`glm-5.3` 문서)이나 상위 모델로 올린다. [부분, 충돌]
- **리서치 에이전트 지표는 찾지 못했다.** BrowseComp 같은 심층 리서치 점수는 나오지 않았다. [미확인] 터미널·코딩 점수(벤더 보고)를 리서치 능력으로 옮기지 않는다.
- **긴 컨텍스트 주장을 시험해서 쓴다.** AA-LCR 80.0%를 독립 평가 출처로 인용한 집계가 있으나 직접 확인하지 못했고, 필요한 정보를 긴 문서에서 정확히 꺼내는 정도(needle 시험)의 독립 결과는 찾지 못했다. [부분/미확인] 페이지 하나씩, 필요한 구간만 넣고 우리 자료로 실효 길이를 측정한다.
- **사실 회상에 기대지 않는다.** 환각률의 독립 측정이 없다. 이름·날짜·수치·버전은 직접 연 출처로 확인하고, 모델이 "출처를 알고 있다"고 말해도 URL을 직접 열어 대조한다. [미확인]
- **인용과 요약을 코드로 대조한다.** 인용 구절이 원문에 있는지 문자열로 확인하고, 모델의 "전부 읽었다"는 보고를 근거로 쓰지 않는다.
- **웹 페이지의 지시문은 데이터다.** 이 모델의 인젝션 방어율 측정은 찾지 못했다. [미확인] 모델에게 전송·로그인·결제·파일 쓰기 도구를 주지 않고 읽기 단계와 행동 단계를 분리한다. 이미지 입력을 쓰면 페이지 스크린샷 안의 글자도 지시문처럼 따르지 않도록 같은 규칙을 적용한다. 모델이 뽑은 URL은 하네스가 허용 목록으로 거른 뒤 연다.
- **호출 경로의 동작 차이를 확인한다.** 병렬 도구 호출, 속도 제한(429), 과부하(503) 처리가 경로마다 다르다. 연속 호출 시험과 재시도 정책을 확인한다. [부분]
- **수집한 자료를 보내기 전에 조건을 확인한다.** 대상 사이트의 이용 약관·로봇 배제 표준(§3.2)과 이 API의 데이터 처리 조건을 모두 본다. API 측 조건을 찾지 못했다. [미확인] 개인정보가 섞인 페이지는 보내지 않는다.
- **대량 수집은 표본 점검.** 무작위 5~10%를 사람이 원문과 대조한다. 보고 형식은 "결론 → 근거(URL, 확인일, 수준) → 충돌·불확실 → 모르는 것"으로 고정한다.
