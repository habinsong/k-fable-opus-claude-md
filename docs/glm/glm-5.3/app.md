## 2. 이 모델의 앱 작업 운용
모델 전체 특성은 같은 폴더의 `general.md` §2를 따른다. 요약: 744B급 MoE라 기기 내 실행 불가, 접근 방식이 구독 우선이었다는 서술, 자체 라이선스(대규모 사업자 조항), 모바일 개발 독립 평가 없음, 데이터 처리 조건 미확인.

**앱에 내장할 때**
- **기기 안에서 돌릴 모델이 아니다.** 총 약 744B(활성 약 40B)라 모바일 온디바이스는 불가능하다. 앱은 서버를 거쳐 호출하는 구조만 가능하다. 소형 모델이 필요하면 `glm-5.3-flash`(총 약 320B)도 휴대 기기용이 아니므로 `gemma-4-e2b`, `gemma-4-e4b` 문서를 본다. [부분/추정]
- **호출 경로가 앱 임베딩을 허용하는지 약관으로 확인한다.** 출시 초기에 GLM Coding Plan·ZCode 구독이 먼저였고 토큰 과금 API는 단계적이었다는 서술이 있다. 개발자용 구독을 최종 사용자 앱의 백엔드로 쓰는 것이 허용되는지는 약관을 원문으로 읽어야 한다. 제3자 API 판매업체(리셀러)를 거치면 그쪽 약관, 데이터 경로, 가격이 추가된다. [부분/미확인]
- **API 키를 앱 바이너리나 리소스에 넣지 않는다.** 앱에서 직접 호출하지 말고 자체 백엔드에서 키 보관, 사용량 제한, 요청 검증, 로깅을 한다(§3.1 비밀 규칙). 모델 출력은 신뢰하지 않는 입력으로 취급해 서버에서 검증한 뒤 앱에 전달한다.
- **개인정보 선언과 실제 동작을 맞춘다.** 사용자 입력을 이 API로 보내면 수집·전송 항목을 앱 스토어의 개인정보 선언과 처리방침에 반영한다. 데이터 처리 위치·보관 기간·학습 사용 여부와 약관을 찾지 못했으므로 [미확인] 출시 전에 원문을 읽고, 아동·민감정보·규제 데이터는 확인 전에 보내지 않는다.
- **가중치를 직접 호스팅하는 경우 라이선스를 구분한다.** 플래그십은 MIT가 아닌 자체 라이선스이고(대규모 모델 서비스 운영자에게 보안 심사 조항이 보도됨), `glm-5.3-flash`는 MIT다. 원문으로 임계값을 확인하고 LICENSE·NOTICE를 지킨다(general.md §2.3). [부분]
- **모델 교체를 앱 업데이트 없이 할 수 있게 설계한다.** 모델 ID·가격·약관이 출시 직후 보도마다 달랐고 후속(GLM-5.5)이 예고돼 있다. 서버 쪽 모델 설정, 폴백 모델, 회귀 시험, 기능 플래그를 둔다. [부분]
- **비용은 토큰 기준으로 서버에서 제한한다.** 가격은 한 출처 기준 입력 $1.40 / 출력 $4.40(100만 토큰당)이다. 추론 토큰이 출력 한도에 들어간다는 서술이 같은 계열에서 있어 `max_tokens`와 사용자당 한도를 서버에 두고 실제 청구서로 확인한다. [부분]

**개발 보조로 쓸 때**
- **모바일(Kotlin·Swift) 코드에 대한 독립 평가는 찾지 못했다.** 집계 사이트에서 GLM-5.3의 SWE Multilingual은 "곧 공개" 상태였고 이전 세대 GLM-5가 73.3%였다. [미확인] 언어별 점수 없이 일반 코딩 점수를 모바일로 옮기지 않는다. 컴파일·린트·단위 테스트·UI 테스트로 검증한다.
- **수명주기·권한·비동기 처리가 걸린 구현은 상위 모델 문서를 따른다**(`claude/sonnet-5.5`, `gpt-6.1-sol`, `gemini-4-argon`). 긴 터미널 작업에는 GLM, 검토와 어려운 변경에는 상위 모델이라는 분업 조언이 있으나 현장 시험이 아닌 권고다. [부분]
- 스토어 규정은 기억으로 답하지 않고 공식 문서로 확인한다(§3.2). 서명 키, 프로파일, 스토어 제출·배포는 승인 후에만 한다.
