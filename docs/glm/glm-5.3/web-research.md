## 2. 이 모델의 웹 리서치 운용
모델 전체 특성은 같은 폴더의 `general.md` §2를 따른다. 요약: 컨텍스트 100만 토큰, 내장 웹 검색 기능이 있다는 리셀러 서술, BrowseComp 등 리서치 평가와 인젝션 방어율 독립 측정 없음, 환각률 값 미확인.

- **내장 검색은 리셀러의 설명뿐이다.** 한 API 리셀러(EmpirioLabs)는 모델이 답하기 전에 웹을 검색하도록 설정할 수 있고 최신성·도메인·결과 수로 좁힐 수 있으며 내장 검색이 요청당 $0.033이라고 적었다. 이는 리셀러 주장이므로 Z.ai 공식 문서로 같은 기능과 요금이 있는지 확인한다. [부분: 리셀러 주장]
- **리서치 에이전트 지표는 찾지 못했다.** GLM-5.3의 BrowseComp 같은 심층 리서치 점수는 검색에서 나오지 않았다. [미확인] 터미널·코딩 점수(벤더 보고)를 리서치 능력으로 옮기지 않는다.
- **사실 회상에 기대지 않는다.** AA-Omniscience 환각률 값은 확인하지 못했다(hardware.md). 이름·날짜·수치·버전은 직접 연 출처로 확인하고, 모델이 "출처를 알고 있다"고 말해도 URL을 직접 열어 대조한다. [미확인]
- **인용과 요약을 코드로 대조한다.** 인용 구절이 원문에 있는지 문자열로 확인하고, 모델의 "전부 읽었다"는 보고를 근거로 쓰지 않는다. 값마다 근거 구절을 받아 원문 포함 여부를 검사한다.
- **웹 페이지의 지시문은 데이터다.** 이 모델의 인젝션 방어율 측정은 찾지 못했다. 관련 논문(17개 모델, 3개 검색 에이전트 틀, 300개 시험 사례)은 추론 모델과 심층 리서치 틀이 대체로 더 강한 저항을 보인다고 보고했으나 GLM-5.3을 다룬 것은 아니다. [부분/미확인] 모델에게 전송·로그인·결제·파일 쓰기 도구를 주지 않고 읽기 단계와 행동 단계를 분리한다. 모델이 뽑은 URL은 하네스가 허용 목록으로 거른 뒤 연다.
- **긴 컨텍스트에 모두 넣지 않는다.** 컨텍스트가 100만 토큰이어도 지연·비용이 커지고 정확도는 보장되지 않는다. 페이지 하나씩, 필요한 구간만 넣고 출력 필드를 제한한다. 추론 토큰이 출력 한도에 포함된다는 서술이 있어 `max_tokens`를 충분히 잡는다. [추정/부분]
- **수집한 자료를 보내기 전에 조건을 확인한다.** 대상 사이트의 이용 약관·로봇 배제 표준(§3.2)과 이 API의 데이터 처리 조건을 모두 본다. API 측 조건을 찾지 못했다. [미확인] 개인정보가 섞인 페이지는 보내지 않는다.
- **호출 경로를 확인한다.** 구독 우선, 토큰 과금 API는 단계적이었다는 서술이 있다. 자동 수집에 쓰려는 경로의 약관이 대량 호출을 허용하는지 확인한다. [부분/미확인]
- **대량 수집은 표본 점검.** 무작위 5~10%를 사람이 원문과 대조한다. 오류율이 기준을 넘으면 상위 모델로 올린다. 보고 형식은 "결론 → 근거(URL, 확인일, 수준) → 충돌·불확실 → 모르는 것"으로 고정한다.
