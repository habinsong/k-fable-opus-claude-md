## 2. 모델 특성 — GLM-5.3 (플래그십)
이 환경에서는 Z.ai 공식 문서(docs.z.ai)와 Hugging Face 본문이 열리지 않아 검색 스니펫과 2차 출처로 썼다. 별도 표기가 없으면 [부분]이다. 같은 계열의 소형 모델은 `glm-5.3-flash` 문서, 미출시 후속은 `glm-5.5` 문서에 둔다.

### 2.1 위치와 출시 경위
- GLM-5.2의 후속으로 같은 기반 모델 위에서 나왔고 가격도 같다는 서술이 있다(한 출처). API 출시일은 8월 14일, 18일, 19일로 출처마다 다르고, 한 글은 Z.ai 릴리스 로그에 8월 18일로 적혀 있다고 한다. 가중치는 약 2주 뒤인 2026-08-28에 Hugging Face에 올라왔다는 보도가 있다. 출시 직후 Artificial Analysis가 "비공개 가중치"로 표시했다가 이후 공개로 바뀌었을 가능성이 있으나 확인하지 못했다. [부분, 충돌]
- **접근 방식이 단계적이었다는 서술이 있다.** 한 가이드는 GLM Coding Plan과 ZCode 구독에서 먼저 쓸 수 있었고 토큰 과금 API는 단계적으로 열렸다고 한다. 현재 일반 API 제공 여부와 한도는 공식 문서로 확인한다. [부분/미확인]

### 2.2 사양 (출처마다 다름)
- **MoE, 총 약 744B(출처에 따라 743B·753B), 활성 약 40B.** 컨텍스트 100만 토큰(GLM-5.2에서 이어짐), 최대 출력 약 128K 토큰. 정확한 수치는 모델 카드에서 확인한다. [부분, 충돌]
- **자체 호스팅은 대형 다중 GPU 노드가 필요한 규모다.** 개인·소규모 로컬 실행은 대상이 아니다. [추정]
- **가격**: 한 출처가 Z.ai 가격 페이지를 근거로 입력 $1.40 / 출력 $4.40 (100만 토큰당)이라고 했다. 같은 출처에서 Claude Fable 5는 $5/$25로 비교됐다. 공식 가격표는 확인하지 못했다. [부분]
- **노력 단계 변형이 있다.** 독립 평가 사이트에 `GLM-5.3 (max)`와 `(low)`가 따로 올라 있다. 추론 노력 수준을 어떻게 지정하는지(API 파라미터)는 확인하지 못했다. [미확인]

### 2.3 라이선스 — MIT가 아니다
- 플래그십 가중치는 자체 "GLM-5.3 License"를 쓰고, 소형 Flash는 MIT다. 여러 출처가 같은 내용을 전한다(Hugging Face 모델 카드가 자체 라이선스라고 확인했다는 서술 포함, 원문은 못 열었음).
- 한 분석은 텍스트가 MIT와 거의 같고 실행·배포·미세조정·파생물 제작 권리가 명시됐다고 한다. 상업 이용은 일반 기업에 폭넓게 허용된다.
- **대규모 사업자 조항.** 보도에 따르면 12개월 연속 합산 매출이 100억 달러를 넘는 모델 서비스(MaaS) 운영자는 상업 이용 전에 Z.ai의 보안 심사를 통과해야 하며 심사 범위와 방법은 Z.ai가 정한다. 해석은 라이선스 본문에 적힌 glmlicense@z.ai에 문의하라는 안내가 있다. 허용 가능 사용 정책(AUP) 절이 없다는 지적도 있다.
- → 일반 기업은 상업 이용 가능성이 높아 보이지만 임계값·정의는 본문으로 확인한다. 의존성·재배포 시 MIT인 Flash와 혼동하지 않는다(§1.5). 의심스러우면 "상업 이용 가능 여부 미확인"으로 남긴다. [부분/미확인]

### 2.4 성능 근거를 읽는 법
- **벤더 보고 수치**(Hugging Face 카드를 옮긴 보도): Terminal-Bench 2.1 88.2, Terminal-Bench 3.0 28.3, DeepSWE v1.1 66.9, AutomationBench 48.2, CyberGym 84.5. 같은 계열이라도 벤치마크 버전(2.1 대 3.0)이 달라 점수를 서로 비교할 수 없고, GLM-5.2 대비 비교값이 어느 지표에 대응하는지 스니펫만으로는 알 수 없다. 독립 확인이 없으므로 선택 근거로 쓰지 않는다. [미확인]
- **독립 지수(Artificial Analysis)**: GLM-5.3 (max)가 한 페이지에서 60, 다른 페이지에서 지수 v4.3.2 기준 45로 나온다. 지수 버전이 다르면 값이 달라지므로 다른 모델과 비교할 때 같은 버전의 값인지 확인한다. 참고로 v4.3.2에서 DeepSeek V4.1 Flash(최대 노력)도 45라는 요약이 있다. [부분, 충돌]
- **Claude와의 비교.** 비교 글들은 대체로 Claude Fable 5가 대표 코딩 지표에서 앞서고 GLM-5.3은 도구 사용 지표 하나에서 앞선다고 서술한다. 비용 대비가 주된 논거이며 BenchLM의 일부 비교는 신뢰구간이 겹친다. 대부분 벤더·집계 사이트 글이다. [부분]
- **환각·도구 호출 오류율의 독립 측정은 찾지 못했다.** [미확인]

### 2.5 이 모델을 운용하는 법
- 코딩 에이전트에서 긴 터미널 작업은 GLM, 검토와 어려운 변경은 상위 모델에 맡기자는 조언이 있으나 현장 시험이 아니라 권고다. 작은 비중의 트래픽으로 시험하고 자체 하네스에서 검증한다. [부분]
- **추론 토큰이 출력 한도에 포함된다**는 서술이 같은 계열(FlashX)에서 확인됐다. `max_tokens`를 추론 길이까지 고려해 정한다. [부분]
- **데이터 취급.** API로 보낸 데이터의 처리 위치·보관·학습 사용 조건을 찾지 못했다. [미확인] 개인정보·영업비밀은 약관을 원문으로 읽기 전에 보내지 않는다. 가중치를 직접 호스팅하는 경로는 위 라이선스를 따른다.
- **지침은 짧게.** 이 문서의 §0과 §1.2·§1.3·§1.6을 시스템 프롬프트에 두고 분야 규칙은 필요한 작업에 붙인다. 한국어 존댓말 준수는 직접 측정한다. [미확인]

### 2.6 비판적 평가
- 강점 후보: 낮은 가격, 100만 토큰 컨텍스트, 공개 가중치. 약점 후보: 독립 근거가 얕고 수치가 출처마다 다르며, 접근 방식·약관·도구 호출 신뢰도 정보가 부족하다. 모든 값은 출시 직후 보도이므로 시간이 지나면 바뀐다.
- 막히면 `claude/opus-5.5`, `gpt-6.1-sol`, `gemini-4-argon` 문서의 모델로 올린다.
