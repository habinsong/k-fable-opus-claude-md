## 2. 이 모델의 하드웨어 작업 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: 744B급 MoE, 컨텍스트 100만 토큰, 독립 평가 점수 60 또는 45(버전 충돌), 환각률 값 미확인, 하드웨어 설계 평가 없음, 데이터 처리 조건 미확인.

- **설계 판단에 쓰지 않는다.** 핀 배치, 정격, 타이밍, 수식은 틀리면 보드가 망가지거나 위험해진다. 이 모델의 회로·PCB·HDL 평가는 찾지 못했다. [미확인] 종합 지수나 코딩 점수가 높아도 회로 설계 정확도를 대표하지 않는다. 설계는 `gemini-4-argon`, `claude/opus-5.5`, `gpt-6.1-sol` 같은 상위 모델 문서를 따르고, 그 결과도 데이터시트 원문과 도구 계산으로 확인한다.
- **값 회상을 믿지 않는다.** AA-Omniscience(정확도 보상·환각 감점·거부 무벌점)의 GLM-5.3 값은 찾지 못했다. 환각률 항목이 평가 사이트에 있으나 확인 가능한 값이 없었고, 일부 페이지는 독립 평가 예정(추정치)으로 표시했다. [미확인] 따라서 부품 번호·핀 번호·레지스터 주소·정격을 모델 기억에서 가져오게 하지 않는다.
- **값은 사람이 확보한 데이터시트 텍스트에서만 꺼낸다.** 값마다 문서명·개정판·페이지를 같이 받아 원문 PDF와 한 건씩 대조하고, 원문에 없으면 null이다(§3.1). 컨텍스트가 100만 토큰이라고 데이터시트 여러 권을 통째로 넣지 말고 필요한 장과 표만 넣는다. PDF 표를 텍스트로 변환할 때 열이 어긋나기 쉬우므로 변환 결과도 대조한다. [추정]
- **써도 되는 작업.** BOM 정규화, 부품 번호 목록 변환, 시험 로그 분류, 데이터시트 텍스트에서 정해진 필드 추출, 측정·변환 스크립트(파이썬)의 초안. 스크립트는 알려진 값을 넣어 실행해 확인한다.
- **계산은 도구로 한다.** 전류 예산, 분압, 필터, 열 계산은 스크립트·시뮬레이터 출력으로 확인하고 식과 가정을 남긴다. 추론 모드로 낸 풀이도 마찬가지다.
- **이미지(회로도 사진·PCB 사진) 판독은 근거로 쓰지 않는다.** GLM-5.3 플래그십의 이미지 입력 지원은 확인하지 못했다(같은 계열 Flash는 텍스트+이미지+영상 입력으로 소개됨). [미확인] 넷리스트·ERC 보고서와 대조한다.
- **미공개 설계 자료를 API로 보내지 않는다(약관 확인 전).** 데이터 처리 위치·보관·학습 사용 조건을 찾지 못했다. [미확인] 회로도·레이아웃·펌웨어 이미지·부품 공급 정보는 영업비밀이므로 원문 약관을 읽고 승인받은 뒤에만 보낸다.
- **인체·화재 위험 설계는 "안전하다"고 단정하지 않는다.** 고전압·대전류·배터리·모터는 사람의 검토를 요청한다.
