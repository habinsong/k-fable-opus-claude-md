## 2. 이 모델의 앱 작업 운용
모델 전체 특성은 같은 폴더의 `general.md` §2를 따른다. 요약: 4비트 가중치 약 4.5 GB, 128K 컨텍스트, 이미지·오디오 입력, Google AI Edge(LiteRT-LM) 지원 모델 목록에 포함.

**앱 기능으로 내장할 때 (온디바이스 추론)**
- 모바일에 올릴 수 있는 Gemma 4 중 품질이 더 높은 쪽이다. 4비트 가중치 약 4.5 GB(BF16 약 17.9 GB)는 E2B(약 2.9 GB)보다 크다. KV 캐시와 런타임 메모리가 별도라 저사양 기기에서는 상주가 어려울 수 있다. 대상 기기 등급별로 메모리·속도·발열을 측정하고, 지원 기기 하한과 대체 동작(더 작은 모델, 서버 호출, 기능 끄기)을 정한다. [부분]
- **앱 용량·다운로드 정책을 확인한다.** 모델 파일이 수 GB이므로 최초 다운로드 크기, 저장 공간, 데이터 요금, 스토어의 앱 크기·동적 다운로드 규정을 확인한다.
- **전력·발열·메모리 압박.** 백그라운드 전환 때 모델을 내리는 정책, 저전력 모드, 추론을 메인 스레드에서 하지 않는 설계가 필요하다.
- **개인정보.** 텍스트·이미지·오디오 입력을 기기 안에서만 처리하는지 외부로 보내는지 앱의 개인정보 선언과 일치시킨다. 오디오 인식 정확도는 확인하지 못했다. [미확인]
- **라이선스 고지.** Google 모델 카드는 Apache 2.0이라고 적었다. 모델 가중치를 번들하거나 내려받게 하면 고지·NOTICE 요건을 지키고, 받는 경로(호스팅 플랫폼)의 약관도 확인한다. [부분]
- 제공자 쪽 안전장치가 없으므로 입력 필터와 출력 검증, 위험한 기능(결제, 계정 변경, 외부 전송)의 권한 제한을 앱이 직접 한다.

**개발 보조로 쓸 때**
- 앱 코드 구현에는 쓰지 않는다. E4B의 코딩·에이전트 평가는 찾지 못했다. [미확인] 크래시 로그 분류, 문자열 리소스 변환, 짧은 코드 조각에만 쓰고 파서·빌드로 검증한다. 스토어 규정은 공식 문서로 확인한다(§3.2). 서명 키, 프로파일, 스토어 제출·배포는 승인 후에만 한다.
