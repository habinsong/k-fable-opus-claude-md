## 2. 이 모델의 하드웨어 작업 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: 유효 약 4.5B, 이미지·오디오 입력, 하드웨어 설계 평가 없음, 로컬 실행으로 자료 외부 전송 없음.

- **설계 판단에 쓰지 않는다.** 핀 배치, 정격, 타이밍, 수식은 틀리면 보드가 망가지거나 위험해진다. E4B의 하드웨어 평가는 찾지 못했고 [미확인], 지수는 31B의 절반 수준(19 대 39)이다. [부분] 설계는 `gemini-4-argon`, `claude/opus-5.5`, `gpt-6.1-sol` 같은 상위 모델 문서를 따르고 그 결과도 원문과 도구 계산으로 확인한다.
- **써도 되는 좁은 일.** BOM 행의 표기 정규화, 부품 번호 목록 형식 변환, 시험 로그 분류, 데이터시트 텍스트에서 정해진 필드(패키지, 핀 수, 전원 범위의 표기) 추출. "원문에 없으면 null"을 명시하고 추출값은 원본과 한 건씩 대조한다.
- **이미지 입력(회로도 사진)의 판독은 근거로 쓰지 않는다.** 이미지를 받지만 도면 판독 정확도는 확인하지 못했다. [미확인] 넷리스트·ERC 보고서와 대조한다.
- **데이터시트 값은 원문에서 가져온다.** 핀 배치, 절대 최대 정격, 타이밍은 PDF의 개정판·페이지를 확인하고, 확인하지 못한 값은 숫자를 쓰지 않는다(§3.1).
- **계산은 도구로 한다.** 모델이 낸 숫자는 스크립트나 시뮬레이터 출력과 대조한다.
- **로컬 실행의 이점.** 미공개 설계 자료를 외부 API로 보내지 않고 단순 정리를 할 수 있다. 이 이점은 데이터 보호에 한하고 정확도를 보증하지 않는다.
- **인체·화재 위험 설계는 "안전하다"고 단정하지 않는다.**
