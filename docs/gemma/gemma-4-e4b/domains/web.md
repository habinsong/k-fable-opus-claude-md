## 2. 이 모델의 웹 작업 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: 유효 약 4.5B, 벤치마크 점수 19(2026-04 버전, 31B는 39), 128K 컨텍스트, 에이전트 구성은 약하다는 평가.

- **웹 구현의 주력으로 쓰지 않는다.** E4B의 웹 코딩 평가는 찾지 못했다. [미확인] 벤치마크 점수 19는 31B(39)의 절반 수준이다. [부분] 화면 구현·상태 관리·인가 로직은 `gemini-4-argon`, `claude/sonnet-5.5`, `gpt-6.1-sol` 같은 상위 모델 문서를 따른다.
- **써도 되는 좁은 일.** 이미지 대체 텍스트 초안, i18n 문자열 변환 초안, UI 문구 다듬기, 작은 코드 조각(정규식, 단순 마크업)과 로그·에러 메시지 분류. 결과가 린터·타입체크·테스트로 검증되는 일로 한정한다.
- **사실은 직접 확인한다.** API·CSS·브라우저 지원을 기억에서 가져오지 않는다. [추정] 공식 문서와 린터·컴파일러 출력으로 확인한다.
- **보안·접근성 판단을 맡기지 않는다.** 인가, 입력 검증, 비밀 노출, 접근성 "충족" 여부는 도구 출력과 §3.1 기준으로 사람이 점검한다.
- **에이전트 구성은 단순하게.** 큰 Gemma 4(26B A4B)도 에이전트 코딩에서 약하다는 평가가 있어 [부분], E4B에게 여러 도구를 연쇄 호출시키지 않는다. 한 번에 한 가지를 시키고 단계마다 검증한다.
- **짧은 지침을 쓴다.** §0과 §1.2·§1.3·§1.6의 핵심만 발췌하고 웹 규칙은 해당 작업에만 붙인다. 준수율을 측정한다. [권고]
- **출력을 코드로 검증한다.** 스키마를 강제하고 형식 오류는 재시도하거나 폐기한다. 대량 변환은 무작위 5~10%를 사람이 대조한다.
