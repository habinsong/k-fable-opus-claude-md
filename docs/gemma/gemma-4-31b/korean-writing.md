## 1. 이 모델에서 확인한 것 (글쓰기 제어 관점)
- 밀집 최대. 밀집 약 31B, 컨텍스트 256K. 한 사용자는 글쓰기만 보면 프런티어 모델이 필요 없을 정도라고 평했다(개인 체감) [부분].
- Apache 2.0(모델 카드), 권장 샘플링 temperature 1.0, top_p 0.95, top_k 64 [부분]. 시스템 턴을 지원하고 `<|think|>`로 생각 모드를 켠다 [부분].
- 한국어 존댓말 준수와 긴 지침 준수율은 측정된 바 없다 [미확인].

## 2. 한국어 문체에 대해 알려진 것과 모르는 것
- Gemma 4의 140개 이상 언어 지원이 소개됐지만 한국어 품질을 검증한 자료가 아니다 [부분]. 한국어 글쓰기 독립 평가는 찾지 못했다 [미확인].
- 이 문서가 모델 간 한국어 문체의 우열을 말하지 않는 이유: 사람이 평가한 독립 자료가 없고, 공개된 실측(`empirical-validation.md`)은 다른 모델 버전으로 한 것이다.

## 3. 모델 지침(md)의 근거

`md/gemma/gemma-4-31b/ko-*.md`의 '이 모델에서 지킬 점 (한국어 윤문)' 각 줄이 왜 그렇게 쓰였는지다. 순서가 같다.

1. 지침: 미공개 원고(논문 초안, 소설 원고)는 로컬에서 처리하고 외부 서비스로 보내지 않는다.
   - 근거: 같은 폴더의 `operations.md`·`critique.md`: 개인정보나 미공개 코드를 외부로 보낼 수 없는 환경이 이 모델의 용도로 꼽혔다 [부분]. 미공개 원고에 옮겼다 [추정].
2. 지침: 숫자, 고유명사, 인용, 약어, 날짜는 원문 그대로 둔다.
   - 근거: 윤문의 보존 원칙이다. 사실, 수치, 고유명사를 바꾸는 실패를 막는다. 공개 윤문 도구들도 같은 보존 규칙을 둔다(`ai-tell-projects.md` §3).
3. 지침: 결과물의 말투(존대, 평어)는 원문의 것을 끝까지 유지하고 중간에 바꾸지 않는다.
   - 근거: 경어법 일관성을 AI 신호로 보는 도구가 있고(humanizer-ko, im-not-ai E-7), 필자의 격식을 바꾸지 않는 것이 윤문의 기본 원칙이다.
4. 지침: 긴 맥락이 필요하면 설정 요약을 먼저 쓰고 그것을 기준으로 이어 쓴다.
   - 근거: KV 캐시가 긴 컨텍스트에서 지배적 비용이 될 수 있다는 분석이 있다 [부분]. 설정 요약 후 이어 쓰기로 옮겼다 [추정].
