## 2. 이 모델의 웹 작업 운용
모델 전체 특성은 같은 폴더의 `general.md` §2를 따른다. 요약: 유효 약 2.3B의 가장 작은 로컬 모델, 128K 컨텍스트, 독립 평가 없음, 런타임 도구 호출 버그 이력.

- **웹 구현의 주력으로 쓰지 않는다.** E2B에 대한 독립 코딩 평가는 찾지 못했다. [미확인] 화면 구현·상태 관리·인가 로직은 `gemini-4-argon`, `claude/sonnet-5.5`, `gpt-6.1-sol` 같은 상위 모델 문서를 따른다.
- **써도 되는 좁은 일.** 이미지 대체 텍스트 초안, i18n 문자열 변환 초안, 짧은 UI 문구 다듬기, 로그·에러 메시지 분류, 정규식·마크업의 아주 단순한 변환. 결과가 린터·타입체크·테스트로 검증되는 일로 한정한다.
- **보안·접근성 판단을 맡기지 않는다.** 인가, 입력 검증, 비밀 노출, 접근성 "충족" 여부는 도구 출력과 §3.1 기준으로 사람이 점검한다.
- **API·CSS·브라우저 지원을 기억에서 가져오지 않는다.** 소형 모델은 사실 회상이 약한 경향이 있다. [추정] 속성 이름과 지원 여부는 공식 문서와 린터 출력으로 확인한다.
- **짧은 지침을 쓴다.** 이 문서 전체를 시스템 프롬프트로 주면 소형 모델은 일부를 놓칠 수 있다. §0과 §1.2·§1.3·§1.6의 핵심만 발췌하고, 웹 규칙은 해당 작업에만 붙인다. [권고]
- **출력을 코드로 검증한다.** 스키마를 강제하고 형식 오류는 자동 재시도하거나 폐기한다. 대량 변환은 무작위 5~10%를 사람이 대조한다.
- **브라우저 안에서 돌리는 구성은 확인하지 못했다.** 웹 페이지 안에서 모델을 직접 실행하는 방식의 지원·성능은 이 조사에서 확인하지 못했다. [미확인]
