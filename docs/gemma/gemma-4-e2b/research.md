## 2. 이 모델의 연구 작업 운용
모델 전체 특성은 같은 폴더의 `general.md` §2를 따른다. 요약: 유효 약 2.3B, 오디오 입력 지원, 연구 평가 없음, 로컬 실행으로 데이터 외부 전송 없음.

- **연구의 추론, 인용, 통계 해석에 쓰지 않는다.** E2B의 연구 보조 평가는 찾지 못했다. [미확인] 소형 모델은 사실 회상과 다단계 추론에서 틀리기 쉽다. [추정] 새 가설·증명·통계 해석은 `gemini-4-argon`, `claude/opus-5.5`, `gpt-6-astra` 문서를 따르고 전문가 검토를 거친다.
- **참고문헌을 만들거나 보충하게 하지 않는다.** 26개 LLM 연구에서 검증 가능한 참고문헌 중 모든 필드가 맞은 비율은 48.3%였고 저자 목록이 가장 약했다(51.7%). E2B의 별도 측정은 찾지 못했다. [부분/미확인] 모든 인용은 Crossref·DataCite·원문에서 제목·저자·연도·권호와 주장의 실제 존재를 확인한다.
- **써도 되는 좁은 일.** 서지 정보의 서식 변환, 실험 로그·메타데이터 정리, 표 형식 변환, 논문 초록에서 정해진 필드 추출. "원문에 없으면 null"을 명시하고 추출값은 원문과 한 건씩 대조한다.
- **로컬 실행의 이점은 데이터 보호다.** 민감한 연구 자료(미공개 데이터, 개인 식별 정보)를 외부 API로 보내지 않고 단순 정리에 쓸 수 있다. 이 장점은 데이터 보호에 한하고 정확도를 보증하지 않는다. 사람 대상 자료는 연구 윤리 심의와 개인정보 동의 범위를 먼저 확인한다(§3.3).
- **오디오 입력(인터뷰 전사 등)은 사람이 검수한다.** E2B는 오디오를 받지만 전사 정확도는 확인하지 못했다. [미확인] 연구 인터뷰의 전사는 원음과 대조하고, 참여자 동의와 보관 범위를 확인한다.
- **분석 결과를 모델 설명으로 대체하지 않는다.** 통계는 코드를 다시 실행해서 확인한다. 시드, 데이터 버전, 라이브러리 버전을 기록한다.
- **전문 영역(의료, 법률, 안전) 결론에는 "전문가 검토 필요"를 붙인다.**

## 4. 근거와 한계
- 오디오 입력·크기: [Gemma 4 model card](https://ai.google.dev/gemma/docs/core/model_card_4) (스니펫만) [부분]
- 참고문헌 정확도(타 모델 포함): [Biomedical Reference Generation Remains Unreliable across 26 LLMs](https://arxiv.org/pdf/2609.14988) [부분]
- 한계: E2B의 연구 보조 정확도를 측정한 독립 자료가 없다. 사용 범위 제한은 모델 크기에서 도출한 보수적 권고다.
