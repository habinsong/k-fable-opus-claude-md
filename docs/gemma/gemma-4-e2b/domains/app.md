## 2. 이 모델의 앱 작업 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: 4비트 가중치 약 2.9 GB, 128K 컨텍스트, 오디오 입력, Google AI Edge(LiteRT-LM) 지원 모델 목록에 포함.

**앱 기능으로 내장할 때 (온디바이스 추론)**
- Google AI Edge의 LiteRT-LM 문서가 Gemma 4를 온디바이스용 모델로 소개한다. [부분] E2B는 4비트 가중치가 약 2.9 GB(BF16 약 11.4 GB)라서 모바일에 올릴 수 있는 후보지만, KV 캐시와 런타임 메모리가 별도라 실제 상주 메모리는 더 크다. 기기별로 측정한다.
- **앱 용량·다운로드 정책을 확인한다.** 모델 파일이 수 GB이므로 최초 다운로드 크기, 저장 공간, 데이터 요금, 스토어의 앱 크기·동적 다운로드 규정을 확인한다.
- **전력·발열·메모리 압박.** 백그라운드 전환 때 모델을 내리는 정책, 저전력 모드, 저사양 기기의 대체 동작을 설계한다. 메인 스레드에서 추론하지 않는다.
- **오디오 입력을 쓰면 개인정보 동의를 먼저 정한다.** 음성 데이터를 기기 안에서만 처리하는지, 외부로 보내는지 앱의 개인정보 선언과 일치시킨다. 전사·인식 정확도는 이 조사에서 확인하지 못했다. [미확인]
- **라이선스 고지.** Apache 2.0이라고 모델 카드가 적었다. 앱에 모델 가중치를 번들하거나 내려받게 하면 라이선스 고지와 NOTICE 요건을 지킨다. 받는 경로(호스팅 플랫폼)의 약관도 확인한다. [부분]
- 제공자 쪽 안전장치가 없다. 입력 필터와 출력 검증, 위험한 기능(결제, 계정 변경, 외부 전송)의 권한 제한은 앱이 직접 한다.

**개발 보조로 쓸 때**
- 앱 코드 구현에는 쓰지 않는다. E2B의 코딩 평가는 찾지 못했다. [미확인] 크래시 로그 분류, 문자열 리소스 변환 같은 좁은 일에만 쓰고 결과를 파서·빌드로 검증한다. 스토어 규정은 기억으로 답하지 말고 공식 문서로 확인한다(§3.2).
- 서명 키, 프로파일, 스토어 제출·배포는 승인 후에만 한다.
