## 2. 이 모델의 연구 작업 운용
모델 전체 특성은 같은 폴더의 `general.md` §2를 따른다. 요약: 총 25.2B 중 활성 3.8B, 독립 지수 31(2026-04 버전, 이후 척도 변경으로 충돌), 코딩 외 의사결정과 큰 입출력에서 약하다는 평가, 연구 평가 없음, 로컬 실행으로 데이터 외부 전송 없음.

- **연구의 추론과 인용은 이 모델에 맡기지 않는다.** 독립 지수는 일반 능력 지표이고 연구 보조 정확도(문헌 요약, 통계 해석)에 대한 독립 평가는 찾지 못했다. 지수 척도가 버전마다 달라 값을 서로 섞어 비교하지도 않는다(general.md §2.1). [미확인/부분] 새 가설·증명·통계 해석은 `gemini-4-argon`, `claude/opus-5.5`, `gpt-6-astra` 문서를 따르고 전문가 검토를 거친다. 코딩 외 의사결정에서 고전했다는 평가가 있어 연구 설계 판단도 맡기지 않는다. [부분]
- **참고문헌을 만들거나 보충하게 하지 않는다.** 26개 LLM 연구에서 검증 가능한 참고문헌 중 모든 필드가 맞은 비율은 48.3%였고 저자 목록이 가장 약했다(51.7%). 이 모델의 별도 측정은 찾지 못했다. [부분/미확인] 모든 인용은 Crossref·DataCite·원문에서 제목·저자·연도·권호와 주장의 실제 존재를 확인한다(§3.2).
- **써도 되는 작업.** 서지 정보 서식 변환, 실험 로그·메타데이터 정리, 표 형식 변환, 논문 초록에서 정해진 필드 추출, 분석 스크립트(파이썬)의 초안, 개인정보가 섞인 자료의 형식 점검. "원문에 없으면 null"을 명시하고 추출값은 원문과 한 건씩 대조한다. 분석 스크립트는 알려진 입력과 결과로 먼저 시험한다. 단발·소입력 작업에 맞는다는 평가에서 도출한 권고다. [부분]
- **로컬 실행의 이점은 데이터 보호다.** 미공개 데이터나 개인 식별 정보를 외부 API로 보내지 않고 정리에 쓸 수 있다. 이 장점은 정확도를 보증하지 않는다. 사람 대상 자료는 연구 윤리 심의와 개인정보 동의 범위를 먼저 확인한다(§3.3).
- **분석 결과를 모델 설명으로 대체하지 않는다.** 통계는 코드를 다시 실행해서 확인한다. 시드, 데이터 버전, 라이브러리 버전을 기록하고, 이상치 제거·필터·검정 기준이 결과에 맞춰 바뀌지 않았는지 `git diff`로 확인한다.
- **긴 논문 묶음은 발췌한다.** 컨텍스트가 256K라도 큰 입력과 큰 출력에서 성능이 급락한다는 평가가 이 모델에 있다. [부분] 논문 한 편씩, 필요한 구간만 넣고 요약 길이를 제한한다. 여러 편을 한 번에 넣어 "종합"시키지 않는다. 종합과 반증 탐색은 상위 모델이나 사람이 한다.
- **전문 영역(의료, 법률, 안전) 결론에는 "전문가 검토 필요"를 붙인다.**
