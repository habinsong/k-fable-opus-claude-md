## 2. 이 모델의 앱 작업 운용
모델 전체 특성은 같은 폴더의 `general.md` §2를 따른다. 요약: 4비트 약 14.4 GB, 총 25.2B 전체를 메모리에 올려야 함, 휴대 기기용이 아님, 앱 개발 평가 없음.

**앱에 내장할 때**
- **휴대 기기에 올릴 모델이 아니다.** 4비트 가중치만 약 14.4 GB(BF16 약 57.7 GB)이고 MoE라도 26B 전체를 메모리에 올려야 한다. 모바일 온디바이스는 Google AI Edge가 안내하는 E2B·E4B를 검토한다. 이 크기는 앱의 서버 측 로컬 추론이나 개발자 워크스테이션에 맞는다. [부분]
- 서버 측에 올릴 때는 동시 사용자 수에 따른 메모리·지연·비용을 측정하고, 개인정보가 서버를 거치는 경로를 앱의 개인정보 선언과 일치시킨다.
- **라이선스 고지.** Apache 2.0이라고 모델 카드가 적었다. 가중치를 배포·번들하면 고지·NOTICE를 지키고 받는 경로의 약관도 확인한다. [부분]
- 제공자 쪽 안전장치가 없다. 입력 필터, 출력 검증, 위험한 기능(결제, 계정 변경, 외부 전송)의 권한 제한을 앱이 직접 한다.

**개발 보조로 쓸 때**
- **단발 질문과 함수 초안에 쓴다.** 단발 코딩에는 강하지만 에이전트 코딩과 큰 입출력에서 약하다는 평가가 있다. [부분] 컴파일 오류 설명, 문자열 리소스 변환, 크래시 로그 분류, 단위 테스트 초안처럼 작은 입력의 일에 쓰고 빌드·테스트로 검증한다.
- 수명주기·권한·비동기 처리가 걸린 구현이나 긴 자율 루프는 `claude/sonnet-5.5`, `gpt-6.1-sol`, `gemini-4-argon` 같은 상위 모델 문서를 따른다. 모바일 개발에 대한 이 모델의 독립 평가는 찾지 못했다. [미확인]
- 스토어 규정은 기억으로 답하지 않고 공식 문서로 확인한다(§3.2). 서명 키, 프로파일, 스토어 제출·배포는 승인 후에만 한다.
