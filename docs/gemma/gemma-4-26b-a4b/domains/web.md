## 2. 이 모델의 웹 작업 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: 총 25.2B 중 활성 3.8B, 4비트 약 14.4 GB, 단발 코딩은 강하고 에이전트 코딩·큰 입출력에서 약하다는 평가, 도구 호출은 런타임 버전에 좌우됨.

- **단발 웹 작업에 맞는다.** 한 커뮤니티 평가에서 단발 코딩 문제는 이전 세대 상위 모델에 맞먹었다. 개인 후기다. [부분] 컴포넌트 하나의 구현·수정, 스타일 변환, 테스트 코드 초안, 정규식과 쿼리 작성처럼 입력이 작고 결과가 린터·타입체크·테스트로 검증되는 일에 쓴다.
- **웹 UI 품질에 대한 독립 평가는 찾지 못했다.** [미확인] 시각 마감은 스크린샷을 직접 대조한다. 기존 UI 체계가 우선한다(§3.1).
- **긴 에이전트 루프를 맡기지 않는다.** 같은 평가가 에이전트 코딩과 코딩 외 의사결정에서 고전했고 큰 입력·큰 출력에서 성능이 급락한다고 했다. [부분] 파일을 통째로 넣지 말고 관련 구간만 주고, 한 번에 한 가지를 시키고, 단계마다 린터·테스트로 확인한다. 같은 오류에서 두 번 막히면 `claude/sonnet-5.5`, `gpt-6.1-sol`, `gemini-4-argon` 같은 상위 모델 문서를 따른다.
- **보안·접근성 판단을 맡기지 않는다.** 인가, 입력 검증, 비밀 노출, 접근성 "충족" 여부는 도구 출력과 §3.1 기준으로 사람이 점검한다.
- **사실은 직접 확인한다.** API·CSS·브라우저 지원은 공식 문서와 린터·컴파일러 출력으로 확인한다.
- **로컬 실행의 이점과 책임.** 미공개 소스를 외부로 보내지 않는다. 대신 제공자 쪽 안전장치가 없으므로 모델이 만든 코드는 격리된 환경에서 실행하고 의존성 추가는 라이선스·유지 상태를 확인한 뒤에 한다(§1.5).
- **도구 호출 하네스는 사용 중인 런타임 버전에서 작은 시험으로 확인한다.** 출시 직후 파서·스트리밍 오류가 있었다. [부분] 샘플링은 권장값(1.0 / 0.95 / 64)에서 시작한다.
