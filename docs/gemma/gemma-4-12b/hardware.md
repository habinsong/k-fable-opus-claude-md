## 2. 이 모델의 하드웨어 작업 운용
모델 전체 특성은 같은 폴더의 `general.md` §2를 따른다. 요약: 약 11.95B, 256K 컨텍스트, GPQA Diamond 78.8%(벤더 수치), 하드웨어 설계 평가 없음, 로컬 실행으로 자료 외부 전송 없음.

- **설계 판단에 쓰지 않는다.** 핀 배치, 정격, 타이밍, 수식은 틀리면 보드가 망가지거나 위험해진다. 12B의 하드웨어 평가는 찾지 못했다. [미확인] GPQA Diamond 78.8% 같은 과학 문제 점수는 벤더 보고이며 회로 설계 정확도를 대표하지 않는다. [부분] 설계는 `gemini-4-argon`, `claude/opus-5.5`, `gpt-6.1-sol` 같은 상위 모델 문서를 따르고 그 결과도 원문과 도구 계산으로 확인한다.
- **256K 컨텍스트로 데이터시트 여러 권을 읽힐 수 있다 해도 발췌가 낫다.** 큰 입력에서 성능이 떨어진다는 평가가 큰 형제 모델(26B A4B)에 있다. [부분] 필요한 장과 표만 넣고, 값마다 문서명·개정판·페이지를 같이 받아 원문 PDF와 한 건씩 대조한다. 확인하지 못한 값은 숫자를 쓰지 않는다(§3.1).
- **써도 되는 작업.** BOM 정규화, 부품 번호 목록 변환, 시험 로그 분류, 데이터시트 텍스트에서 정해진 필드 추출, 측정 스크립트(파이썬)의 초안. "원문에 없으면 null"을 명시한다. 스크립트는 실행 결과와 알려진 값으로 확인한다.
- **계산은 도구로 한다.** 전류 예산, 분압, 필터, 열 계산은 스크립트·시뮬레이터 출력으로 확인하고 식과 가정을 남긴다.
- **이미지(회로도 사진) 판독은 근거로 쓰지 않는다.** 12B의 이미지 입력 지원 범위는 확인하지 못했다. [미확인] 넷리스트·ERC 보고서와 대조한다.
- **로컬 실행의 이점.** 미공개 설계 자료를 외부로 보내지 않고 정리할 수 있다. 이 이점은 정확도를 보증하지 않는다.
- **인체·화재 위험 설계는 "안전하다"고 단정하지 않는다.**
