## 2. 이 모델의 웹 리서치 운용
모델 전체 특성은 같은 폴더의 `general.md` §2를 따른다. 요약: 약 11.95B, 256K 컨텍스트, 내장 검색 도구 없음(로컬 실행), 사실성 측정 없음, 제공자 안전장치 없음.

- **검색은 파이프라인이 맡고, 12B는 읽고 정리한다.** 로컬에서 도는 이 모델에는 검색 grounding이 기본으로 붙지 않는다. 검색 호출과 출처 신뢰도 판단은 하네스와 사람이 하고, 12B에는 확보한 페이지 텍스트에서 제목·날짜·가격·버전 같은 필드를 JSON으로 추출하게 한다. "원문에 없으면 null"을 명시하고 값마다 근거 구절을 받아 코드로 원문 포함 여부를 대조한다.
- **사실 회상에 기대지 않는다.** 12B의 사실성·인용 측정은 찾지 못했다. [미확인] 이름·날짜·수치·버전은 직접 연 출처로 확인한다.
- **긴 입력은 발췌한다.** 256K 컨텍스트가 있어도 큰 입력과 큰 출력에서 성능이 떨어진다는 평가가 큰 형제 모델(26B A4B)에 있다. [부분] 실효 길이를 자체 입력으로 측정하고 필요한 구간만 넣는다.
- **웹 페이지의 지시문은 데이터다.** 로컬 모델에는 제공자 쪽 인젝션 방어가 없고 12B의 방어율 측정도 찾지 못했다. [미확인] 모델에게 도구(전송, 로그인, 결제, 파일 쓰기)를 주지 않고 읽기 단계와 행동 단계를 분리한다.
- **수집 규칙을 지킨다.** 로봇 배제 표준과 이용 약관, 속도 제한을 지키고 로그인·유료벽을 우회하지 않는다. 개인정보는 필요한 만큼만 다룬다.
- **도구 호출을 쓸 때.** 사용 중인 런타임 버전에서 도구 호출 파서와 스트리밍이 정상인지 작은 시험으로 확인한다. 출시 직후 Gemma 4 계열에서 오류가 보고됐다. [부분]
- **대량 수집은 표본 점검.** 무작위 5~10%를 사람이 원문과 대조한다. 오류율이 기준을 넘으면 상위 모델로 올린다. 보고 형식은 "결론 → 근거(URL, 확인일, 수준) → 충돌·불확실 → 모르는 것"으로 고정한다.
