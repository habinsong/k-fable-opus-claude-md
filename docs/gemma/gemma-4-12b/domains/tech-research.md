## 2. 이 모델의 기술 조사 운용, 그리고 이 모델을 평가할 때
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: 후속 추가 크기, Apache 2.0 가중치, 소비자 GPU 한 장 후보, 독립 평가가 얕음, 지수 척도 변경, 메모리는 2차 추정.

**이 모델에게 기술 조사를 시킬 때**
- 분류·정리 단계에만 쓴다. 후보를 정해진 기준(라이선스 유형, 지원 언어, 릴리스 날짜)으로 분류해 표로 만들 때, 값은 사람이 확보한 1차 자료 텍스트에서 추출하게 하고 원문에 없으면 null로 둔다.
- 라이선스 호환성, 특허, 규정 적용 여부, 도입 권고는 단정시키지 않는다(§3.2). 사람이나 상위 모델이 근거를 보고 판단한다.

**Gemma 4 12B를 도입 후보로 평가할 때**
- **용도 적합성.** 한 대의 소비자 GPU에서 로컬 보조(요약, 분류, 코드 초안)를 돌리고 데이터를 외부로 보내지 않아야 할 때의 후보다. 컨텍스트 약 256K, 4비트 VRAM 약 6.6~7.7 GB, FP16 약 25 GB라는 2차 추정이 있다. [부분] 장시간 자율 에이전트에는 맞지 않는다.
- **크기 선택의 근거가 약하다.** 12B는 공식 모델 카드에는 있고 출시 블로그에는 없는 후속 추가 모델이다. Google은 12B가 표준 벤치마크에서 26B MoE에 가깝다고 설명하지만 독립 비교는 얕다. 현재 지수 버전에서 12B는 14, 2026-04 버전에서 E4B 19, 26B A4B 31, 31B 39라 척도가 달라 직접 비교할 수 없다. 같은 척도의 모델과 같은 과제로 직접 비교한다. [부분]
- **라이선스.** Apache 2.0이라고 모델 카드가 적었다. 호스팅 플랫폼을 거치면 그쪽 약관이 붙는다는 지적이 있다. 수령 경로와 재배포 계획에 따라 LICENSE와 약관, 상표·사용 정책을 원문으로 확인한다. [부분]
- **총소유비용.** API 비용이 없는 대신 GPU·전력·운영·평가 비용이 든다. 동시 사용자 수와 처리량을 대상 하드웨어에서 실측한다. 같은 용도의 Qwen3.6 계열 로컬 모델, Gemma 4 E4B·26B A4B와 같은 과제로 비교한다.
- **런타임 성숙도.** Gemma 4 계열에서 출시 직후 도구 호출·토크나이저·스트리밍 버그가 보고됐고 12B에서의 상태는 확인하지 못했다. 사용할 런타임 버전에서 시험한다. [부분]
- **제공자 안전장치 부재.** 입력 필터, 출력 검증, 권한 제한을 직접 구축한다. 규제 적합성은 모델이 아니라 시스템 전체에 대해 판단한다.
