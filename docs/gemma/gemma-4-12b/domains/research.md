## 2. 이 모델의 연구 작업 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: 약 11.95B, MMLU-Pro 77.2%·GPQA Diamond 78.8%(벤더 수치), 현재 지수 14(척도 변경), 연구 평가 없음, 로컬 실행으로 데이터 외부 전송 없음.

- **연구의 추론과 인용은 이 모델에 맡기지 않는다.** MMLU-Pro와 GPQA Diamond 점수는 모델 카드를 인용한 보도이고 Google 보고 수치다. [부분] 연구 보조 정확도(문헌 요약, 통계 해석)에 대한 독립 평가는 찾지 못했다. [미확인] 새 가설·증명·통계 해석은 `gemini-4-argon`, `claude/opus-5.5`, `gpt-6-astra` 문서를 따르고 전문가 검토를 거친다.
- **참고문헌을 만들거나 보충하게 하지 않는다.** 26개 LLM 연구에서 검증 가능한 참고문헌 중 모든 필드가 맞은 비율은 48.3%였고 저자 목록이 가장 약했다(51.7%). 12B의 별도 측정은 찾지 못했다. [부분/미확인] 모든 인용은 Crossref·DataCite·원문에서 제목·저자·연도·권호와 주장의 실제 존재를 확인한다.
- **써도 되는 작업.** 서지 정보 서식 변환, 실험 로그·메타데이터 정리, 표 형식 변환, 논문 초록에서 정해진 필드 추출, 분석 스크립트(파이썬)의 초안, 개인정보가 섞인 자료의 형식 점검. "원문에 없으면 null"을 명시하고 추출값은 원문과 한 건씩 대조한다. 분석 스크립트는 알려진 입력과 결과로 먼저 시험한다.
- **로컬 실행의 이점은 데이터 보호다.** 미공개 데이터나 개인 식별 정보를 외부 API로 보내지 않고 정리에 쓸 수 있다. 이 장점은 정확도를 보증하지 않는다. 사람 대상 자료는 연구 윤리 심의와 개인정보 동의 범위를 먼저 확인한다(§3.3).
- **분석 결과를 모델 설명으로 대체하지 않는다.** 통계는 코드를 다시 실행해서 확인한다. 시드, 데이터 버전, 라이브러리 버전을 기록하고, 이상치 제거·필터·검정 기준이 결과에 맞춰 바뀌지 않았는지 `git diff`로 확인한다.
- **긴 논문 묶음은 발췌한다.** 256K 컨텍스트가 있어도 큰 입력에서 성능이 떨어진다는 평가가 큰 형제 모델에 있다. [부분]
- **전문 영역(의료, 법률, 안전) 결론에는 "전문가 검토 필요"를 붙인다.**
