## 2. 이 모델의 앱 작업 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: 4비트에서 약 6~8 GB(2차 추정), 256K 컨텍스트, 휴대 기기용으로는 큰 모델, 앱 개발 평가 없음.

**앱에 내장할 때**
- **휴대폰 온디바이스 후보로는 크다.** 4비트 가중치가 약 6~8 GB(2차 추정)이고 KV 캐시가 추가되어, 일반 스마트폰의 상주 메모리로는 부담이다. 온디바이스는 E2B·E4B가 Google AI Edge의 안내 대상이다. 12B는 태블릿·노트북·온프레미스 서버 같은 큰 기기나 앱의 서버 측 로컬 추론에 맞춰 검토한다. [부분/추정]
- 서버 측에 올릴 때는 동시 사용자 수에 따른 메모리·지연·비용을 측정하고, 개인정보가 서버를 거치는 경로를 앱의 개인정보 선언과 일치시킨다.
- **라이선스 고지.** Apache 2.0이라고 모델 카드가 적었다. 가중치를 배포·번들하면 고지·NOTICE를 지키고 받는 경로의 약관도 확인한다. [부분]
- 제공자 쪽 안전장치가 없다. 입력 필터, 출력 검증, 위험한 기능(결제, 계정 변경, 외부 전송)의 권한 제한을 앱이 직접 한다.

**개발 보조로 쓸 때**
- 앱 코드 구현의 주력으로 쓰지 않는다. 12B의 모바일 개발 평가는 찾지 못했다. [미확인] 크래시 로그 분류, 문자열 리소스 변환, 짧은 코드 조각, 테스트 초안에 쓰고 파서·빌드·테스트로 검증한다. 수명주기·권한·비동기 처리가 걸린 구현은 상위 모델 문서(`claude/sonnet-5.5`, `gpt-6.1-sol`, `gemini-4-argon`)를 따른다.
- 스토어 규정은 기억으로 답하지 않고 공식 문서로 확인한다(§3.2). 서명 키, 프로파일, 스토어 제출·배포는 승인 후에만 한다.
