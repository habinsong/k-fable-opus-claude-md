## 2. 이 모델의 연구 작업 운용
모델 전체 특성은 같은 폴더의 `general.md` §2를 따른다. 요약: 클라우드 API 모델, GPQA Diamond 90.9(벤더 보고), 독립 지수 40~45(버전 충돌), 사실 회상이 약하다고 가정, 연구 보조 독립 평가 없음, 데이터 처리 조건 미확인.

- **연구의 추론과 인용은 이 모델에 맡기지 않는다.** GPQA Diamond 90.9는 DeepSeek이 보고한 수치이고 독립 확인이 없다. 독립 지수(Artificial Analysis)도 40과 45로 갈려 어느 버전의 값인지 확인해야 한다. [부분, 충돌] 시험 문제 풀이 점수는 가설 설계, 통계 해석, 문헌 종합의 정확도를 대신하지 않으며 연구 보조 정확도에 대한 독립 평가는 찾지 못했다. [미확인] 새 가설·증명·통계 해석은 `gemini-4-argon`, `claude/opus-5.5`, `gpt-6-astra` 문서를 따르고 전문가 검토를 거친다.
- **참고문헌을 만들거나 보충하게 하지 않는다.** 26개 LLM 연구에서 검증 가능한 참고문헌 중 모든 필드가 맞은 비율은 48.3%였고 저자 목록이 가장 약했다(51.7%). 이 모델의 별도 측정은 찾지 못했다. 사실 질문 평가에서도 모르는 것을 모른다고 답하는 능력이 강하다는 근거가 없다(general.md §2.3). [부분/미확인] 모든 인용은 Crossref·DataCite·원문에서 제목·저자·연도·권호와 주장의 실제 존재를 확인한다(§3.2).
- **써도 되는 작업.** 서지 정보 서식 변환, 실험 로그·메타데이터 정리, 표 형식 변환, 논문 초록에서 정해진 필드 추출, 분석 스크립트(파이썬)의 초안. "원문에 없으면 null"을 명시하고 추출값은 원문과 한 건씩 대조한다. 가격이 낮아 대량 정리에 유리하나 토큰 사용량이 많았던 측정이 있어 실비용을 확인한다. [부분]
- **수학·정량 풀이는 코드로 재검산한다.** 추론 모드로 푼 풀이도 틀릴 수 있다. 식은 스크립트·기호 계산 도구로 다시 계산하고 단계를 사람이 읽는다.
- **연구 데이터를 API로 보내기 전에 조건을 확인한다.** 데이터 처리 위치·보관·학습 사용 조건을 찾지 못했다. [미확인] 사람 대상 자료, 개인정보, 미공개 데이터, 기관 규정이 있는 자료는 연구 윤리 심의와 동의 범위, 데이터 이용 허가(§3.3)를 먼저 확인하고, 확인 전에는 보내지 않는다. 필요하면 MIT 가중치를 승인된 인프라에 올리는 방안을 비교한다.
- **분석 결과를 모델 설명으로 대체하지 않는다.** 통계는 코드를 다시 실행해서 확인한다. 시드, 데이터 버전, 라이브러리 버전을 기록하고, 이상치 제거·필터·검정 기준이 결과에 맞춰 바뀌지 않았는지 `git diff`로 확인한다.
- **같은 이름으로 동작이 바뀐다.** `deepseek-flash`가 1017로 갱신됐다. 재현성이 필요한 연구는 사용한 모델 이름, 호출 날짜, 가능하면 스냅샷 ID, 추론 모드, 샘플링 설정을 기록한다. 이를 기록하지 않으면 결과를 재현할 수 없다.
- **전문 영역(의료, 법률, 안전) 결론에는 "전문가 검토 필요"를 붙인다.**
