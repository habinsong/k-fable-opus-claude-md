## 2. 이 모델의 기술 조사 운용, 그리고 이 모델을 평가할 때
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: 클라우드 API 모델, 매우 낮은 가격(출처마다 다름), MIT 가중치(보도), 파라미터·가격 충돌, 같은 이름으로 갱신, 독립 평가가 얕음, 데이터 처리 조건 미확인.

**이 모델에게 기술 조사를 시킬 때**
- 분류·정리 단계에만 쓴다. 후보를 정해진 기준(라이선스 유형, 지원 언어, 릴리스 날짜)으로 분류해 표로 만들 때, 값은 사람이 확보한 1차 자료 텍스트에서 추출하게 하고 원문에 없으면 null로 둔다.
- 라이선스 호환성, 특허, 규정 적용 여부, 도입 권고는 단정시키지 않는다(§3.2, §3.5). 후보를 지나치게 높게 평가하는 경향(아첨)이 있는지는 측정된 바 없으므로 사람이나 상위 모델이 근거를 보고 판단한다.
- 사실 회상이 약하다고 가정하고 모델이 알려 주는 버전·날짜·가격·라이선스는 모두 1차 출처로 다시 확인한다(README.md가 안내하는 개요·운용 문서.3).

**DeepSeek V4.1 Flash(1017)를 도입 후보로 평가할 때**
- **용도 적합성.** 대량 분류·추출·초안, 비용 민감한 에이전트 보조, 코드 초안(검증 전제)에 후보다. 출처 없는 사실 조회, 규제 데이터 처리(약관 확인 전), 재현성이 필요한 작업(스냅샷 고정 불가 시)에는 맞지 않는다.
- **벤더 수치로 결정하지 않는다.** GPQA Diamond 90.9, DeepSWE 74.2→77.0, "이전 대비 3.8~43.3% 향상"은 벤더 보고나 이를 옮긴 집계이고 독립 확인이 없다. 독립 평가 점수는 40과 45로 갈린다. 후보 비교는 같은 과제, 같은 조건의 자체 실측으로 한다. [부분/미확인]
- **총비용은 단가가 아니라 과제당 비용이다.** 단가는 출처마다 다르다(입력 $0.30 / 출력 $1.20 대 $0.15 / $0.60, 피크·비피크 차등, 캐시 읽기 $0.003). 이전 측정에서 출력 토큰이 비교군의 약 두 배였고, 한 비교에서는 더 낫지만 토큰을 더 써서 청구액이 거의 같아졌다. 1017이 출력을 줄였다고 주장하므로 우리 과제로 재측정해 과제당 비용을 비교한다. 공식 가격표는 확인하지 못했다. [부분, 충돌]
- **가격 정책의 변동성.** 한 변경 이력 사이트는 V4-Pro가 이 모델로 흡수됐다고 서술하고, 일부 페이지에는 이전의 프로모션 가격이 남아 있다. 가격 변경과 모델 폐기 공지를 추적할 담당과 재검토 시점을 정한다. [부분: 단일 2차]
- **라이선스.** 가중치가 MIT라는 보도가 있다(1017 가중치 포함 여부는 보도 한 건). 모델 저장소의 LICENSE 원문, 데이터·사용 정책 별도 조항, 파생·증류 제한, 서비스 약관(API)이 각각 다르므로 원문으로 확인한다(§3.2). "가중치가 MIT"를 "API 이용 데이터가 안전"이나 "학습 데이터가 깨끗"하다는 뜻으로 읽지 않는다. 학습 데이터 출처와 저작권 이슈는 확인하지 못했다. [부분/미확인]
- **데이터 거버넌스.** API로 보낸 데이터의 처리 위치, 보관 기간, 학습 사용 여부, 하위 처리자와 관할 법원을 찾지 못했다. [미확인] 개인정보·영업비밀·규제 데이터를 다루면 이 항목이 도입 여부를 좌우한다. 약관과 개인정보 처리방침을 원문으로 읽고 법무·보안 검토를 거친다. 대안으로 MIT 가중치를 자체 인프라에 올릴 수 있지만 가중치가 수백 GB(총 552B 보도, FP8 약 485B)라 다중 GPU 노드가 필요하고 운영비가 크다. [추정]
- **공급 연속성과 버전 관리.** 같은 이름 `deepseek-flash`가 예고 없이 갱신되고, 이전 이름은 2026-07-24에 폐기됐으며, 9월 베타 ID는 만료일(09-10)이 정해진 임시 식별자였다(베타 기간은 출처에 따라 이틀 등으로 다름). 이런 이력은 모델 ID 변경과 폐기가 잦다는 증거다. 날짜 스냅샷, 회귀 시험, 폴백 모델, 모델 교체 절차를 도입 조건으로 둔다. [부분]
- **계보 혼선.** 출처마다 "V4 Flash 0423 / 0731 / V4.1 Flash"를 섞고 총 파라미터도 284B와 552B로 다르다(README.md가 안내하는 개요·운용 문서.1). 비교 자료를 인용할 때 빌드를 명시한다. 1017 이후 독립 평가가 있는지 도입 시점에 다시 확인한다.
- **제공자 안전장치와 규정.** 규제 적합성은 모델이 아니라 시스템 전체에 대해 판단하고, 모델 카드나 가중치 라이선스를 규정 준수의 근거로 쓰지 않는다.
