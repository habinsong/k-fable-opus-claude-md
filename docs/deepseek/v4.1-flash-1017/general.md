## 2. 모델 특성 — DeepSeek V4.1 Flash (1017 업데이트)
이 환경에서는 DeepSeek 공식 문서 본문과 주요 보도 호스트가 열리지 않아 공식 도메인 검색 스니펫과 2차 출처로 썼다. 별도 표기가 없으면 [부분]이다.

### 2.1 위치와 연혁
- **2026-09-08~10에 짧은 제한 베타**로 처음 나왔다. 임시 식별자(`deepseek-v4.1-flash-expires-on-0910`)가 쓰였고 이후 정식 제공됐다. 새 구조와 네이티브 멀티모달(텍스트+이미지)을 내세웠고 베타 시점에 기술 보고서나 성능 사양표가 없었다는 보도가 있다.
- **2026-10-17에 1017 업데이트**(사후 학습 갱신)가 나왔다. 웹·앱·API 모두 같은 이름 `deepseek-flash`로 제공되고 호출 방식이 그대로라, 코드를 바꾸지 않아도 동작이 바뀐다. DeepSeek은 이전(9월) 버전보다 점수가 높고, 작업을 더 빨리 끝내고, 출력이 짧아졌다고 설명한다. 이는 벤더 주장이며 독립 측정은 찾지 못했다.
- **계보.** 이전 세대 V4 Flash는 2026-04경 나왔고(NVIDIA 카탈로그 기준 총 284B·활성 13B의 MoE, 컨텍스트 100만), 한 2차 출처는 2026-07-31에 정식(GA) 빌드 0731이 나왔다고 서술한다. 9월의 V4.1 Flash는 새 구조라고 소개돼 이전 세대와 파라미터 수(552B 대 284B)가 다르다. 출처마다 "V4 Flash 0423 / 0731 / V4.1 Flash"를 섞어 쓰므로, 수치를 인용할 때 어느 빌드의 값인지 확인한다. [부분]
- 보도에 따르면 이 모델이 이전 상위 모델 V4-Pro의 트래픽을 흡수했다(한 변경 이력 사이트의 서술이며 DeepSeek 공식 공지는 확인하지 못했다). [부분: 단일 2차 출처]
- 기존 이름 `deepseek-chat`·`deepseek-reasoner`는 2026-07-24에 폐기되며 각각 `deepseek-v4-flash`의 비추론·추론 모드에 대응한다는 공식 문서 스니펫이 있다.

### 2.2 사양 (출처마다 다름)
- 컨텍스트 100만 토큰(OpenRouter 1,048,576), 최대 출력 약 384K 토큰. 가중치는 MIT 라이선스로 Hugging Face와 ModelScope에 공개됐다고 보도됐다(1017 가중치 공개 여부는 보도 한 건).
- **파라미터 수가 일치하지 않는다.** 총 5,520억(552B)이라는 보도, FP8 가중치 484.6B라는 수치가 함께 있고, 활성 파라미터도 "입력 처리 80억, 출력 생성 160억"이라는 이례적인 서술이 있다. 이 문서는 정확한 활성 수를 쓰지 않는다. [미확인/충돌]
- **자체 호스팅은 사실상 불가능한 규모다.** 가중치만 수백 GB라 다중 GPU 노드가 필요하다. 개인·소규모 로컬 실행은 대상이 아니다. [추정]
- 가격은 출처가 갈린다. 가장 많은 곳이 인용한 값은 입력 $0.30 / 출력 $1.20 (100만 토큰당, 피크 시간대), 비피크는 절반이다. OpenRouter는 입력 $0.15 / 출력 $0.60, 캐시 읽기 $0.003으로 표기했다(제3자 제공 경로의 가격은 DeepSeek API와 다를 수 있다). 공식 가격표 본문은 확인하지 못했다. [부분, 충돌]

### 2.3 성능 근거를 읽는 법
- **벤더 보고 수치**: GPQA Diamond 90.9, DeepSWE v1.1 74.2(1017에서 77.0), 이전 버전 대비 3.8~43.3% 향상. 한 집계가 인용했고 다른 검색에서는 DeepSWE를 확인하지 못했다. 독립 확인이 없으므로 선택 근거로 쓰지 않는다. [미확인]
- **독립 지수(Artificial Analysis)**: 추론(최대 노력) 변형이 AA 페이지에 40, 다른 요약에 45(지수 버전 v4.3.2)로 달라 어느 버전의 값인지 확인해야 한다. 비추론 변형은 25 안팎. 1017 이전 실행인지 이후인지 확인하지 못했다. [부분, 충돌]
- **토큰을 많이 쓴다(1017 이전 측정 추정).** 추론 변형은 지수 평가에서 출력 2.5억 토큰으로 비교군 중앙값 1.3억의 약 두 배였다. 1017이 출력이 짧아졌다고 주장하므로 개선 여부는 재측정이 필요하다. 가격이 싸도 토큰이 많으면 실비용이 올라간다. [부분]
- **사실 회상은 약하다고 가정한다.** AA-Omniscience에서 V4.1 Flash 비추론 변형은 정확도 28.4%, 비환각률 46.0%가 한 표에 올라 있다. 반면 이전 세대 V4 Flash(이전 빌드 라벨) 값은 비환각률이 최대 노력 3.9% / 높음 11.0% / 비추론 5.5%로 훨씬 낮았고 정확도는 36.8%(최대 노력)였다. 세대·빌드·지표 정의가 달라 두 값을 같은 선에 놓을 수 없으며, 어느 쪽이든 모르는 것을 모른다고 답하는 능력이 강하다는 근거는 없다. 추론 변형의 V4.1 값은 찾지 못했다. [부분, 충돌]

### 2.4 이 모델을 운용하는 법
- **같은 이름으로 동작이 바뀐다.** `deepseek-flash`는 1017로 조용히 갱신됐다. 날짜가 붙은 스냅샷 ID를 제공하는 경로(예: OpenRouter의 `deepseek-v4.1-flash-20260910` 같은 날짜 ID)가 있으면 재현성이 필요한 작업에 고정해서 쓰고, 업데이트 전후로 자체 회귀 테스트를 돌린다. [부분]
- **추론 모드는 명시한다.** 한 이관 가이드는 V4 계열이 기본으로 추론을 켠다고 하며, 이름만 바꾸면 지연과 응답 형태가 달라질 수 있다고 한다. 추론 켜기·끄기를 요청마다 명시한다. 도구 호출 루프에서 추론 내용(`reasoning_content`)을 다음 요청에 돌려줘야 한다는 서술도 같은 가이드에 있으나 공식 도구 호출 문서로 확인하지 못했으므로 작업 전에 공식 문서로 확인한다. [부분/미확인]
- **호환 API.** OpenAI Chat Completions와 Anthropic 형식을 지원하고 JSON 출력과 도구 호출이 있다는 서술이 있다. 사용 중인 SDK 버전에서 작은 시험으로 확인한다. [부분]
- **이미지 입력의 제공 상태는 확인하지 못했다.** 모델 사양에는 텍스트+이미지가 있으나 API에서 이미지 입력이 일반 제공인지(베타인지)는 찾지 못했다. [미확인]
- **데이터 취급.** API에 보낸 데이터의 처리 위치, 보관, 학습 사용 여부를 확인하지 못했다. [미확인] 개인정보·영업비밀·미공개 코드는 이용 약관과 개인정보 처리방침을 원문으로 읽고, 필요하면 MIT 가중치를 신뢰할 수 있는 인프라에 직접 올리는 방안을 비교한다.
- **지침은 짧게.** 이 문서의 §0과 §1.2·§1.3·§1.6을 시스템 프롬프트에 두고 분야 규칙은 필요한 작업에 붙인다. 한국어 존댓말 준수는 직접 측정한다. [미확인]

### 2.5 비판적 평가
- **강점 후보**: 매우 낮은 가격, 100만 토큰 컨텍스트, MIT 가중치. 이 셋이 사실이면 비용 대비 유용하다.
- **약점 후보**: 벤더 수치 외 독립 근거가 얕고, 파라미터·가격이 출처마다 다르며, 같은 이름의 모델이 예고 없이 바뀌고, 토큰 사용량이 많고, 사실 회상이 약하다.
- **쓰는 용도**: 대량 분류·추출·초안, 비용 민감한 에이전트 보조, 코드 초안(검증 전제). **쓰지 않는 용도**: 출처 없는 사실 조회, 규제 데이터 처리(약관 확인 전), 재현성이 필요한 작업(스냅샷 고정 불가 시).
- 막히면 `claude/opus-5.5`, `gpt-6.1-sol`, `gemini-4-argon` 문서의 모델로 올린다.
