## 2. 이 모델의 연구 작업 운용 (잠정)
2026-11-03 기준 Grok 5의 공식 발표를 찾지 못했다. 모델 상태와 출시일 체크리스트는 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 출시 전에는 `grok/grok-4.7/research.md`를 적용한다(4.8이 먼저 나오면 `grok/grok-4.8/research.md`).

**출시 후 연구 작업에서 따로 확인할 것**
- "AGI" 같은 표현과 규모(6조, 2.1조라는 미검증 수치)는 연구 근거가 아니다. 인용하려는 능력 주장은 벤치마크 이름·버전·노력 단계·하네스·보고 주체를 확인하고, 벤더 수치는 "벤더 보고"로 표기하며 독립 지수와 구분한다. Grok 4.7은 벤더 벤치마크가 공개되지 않아 독립 지수만 인용할 수 있었다.
- 연구 보조 정확도(문헌 요약, 통계 해석)의 독립 평가가 나오는지 확인한다. 없으면 새 가설·증명·통계 해석은 상위 모델 문서(`claude/opus-5.5`, `gemini-4-argon`, `gpt-6-astra`)를 따르고 전문가 검토를 거친다.
- 참고문헌 생성은 모델 전반의 약점으로 보고돼 있다(26개 LLM 연구에서 모든 필드가 맞은 비율 48.3%). 규모가 커져도 개선된다는 보장이 없으므로 5의 별도 측정이 나오기 전에는 모든 인용을 Crossref·DataCite·원문으로 확인한다(§3.2). 환각 값이 공개되면 지수 버전과 노력 단계를 명시해 읽는다.
- 서버 측 웹 검색·X 검색을 문헌 조사의 1차 수단으로 쓰지 않는다. 검색식과 선택 과정을 완전히 노출하지 않을 수 있어 재현성이 떨어진다. 검색식은 하네스가 직접 실행하고 기록한다.
- 수학·정량 풀이는 코드로 재검산한다. 더 큰 모델의 긴 추론도 틀릴 수 있다.
- 연구 데이터를 API로 보내기 전에 데이터 처리 조건(학습 사용, 보관, ZDR)과 연구 윤리 심의·동의 범위(§3.3)를 확인한다. Grok 계열은 학습 사용·보관 정보가 2차 출처뿐이었다.
- 재현성을 위해 모델 이름, 노력 단계, 호출 날짜, 호출 경로, 사용한 도구와 호출 수, 샘플링 설정을 기록한다. 이 계열은 두 달 간격으로 갱신됐다.
- 안전 문서가 나오면 위험 능력 평가와 거부 범주를 읽는다. 생명과학·화학·보안 연구가 거부될 수 있고, 분류기를 통과했다는 사실이 연구 윤리 심의를 대신하지 않는다. [추정]

**잠정 운용**
- 출시 전 연구 작업은 상위 모델을 기준선으로 하고 Grok 계열은 서식 변환, 로그 정리, 정해진 필드 추출 같은 보조에만 쓴다. 공식 발표와 독립 측정이 나오기 전에는 Grok 5를 연구의 기본으로 지정하지 않는다.
