## 2. 이 모델의 웹 리서치 운용 (잠정)
2026-11-03 기준 Grok 5의 공식 발표를 찾지 못했다. 모델 상태와 출시일 체크리스트는 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 출시 전에는 `grok/grok-4.7/web-research.md`를 적용한다(4.8이 먼저 나오면 `grok/grok-4.8/web-research.md`).

**출시 후 웹 리서치에서 따로 확인할 것**
- Grok API의 특징은 xAI 서버에서 실행되는 웹 검색·X 검색 도구와 출처 URL 반환이다. 5에서도 같은 방식인지, 요금(1,000회당 $5는 4.3·4.5 시기 자료)과 과다 검색 경향이 달라졌는지 공식 문서와 호출 수로 확인한다. 호출 횟수·호출당 예산 한도는 하네스에서 계속 건다.
- X 검색 결과는 1차 출처가 아니다. 모델이 좋아져도 게시글만으로 사실을 확정하지 않고 공식 발표·명세·소스 저장소로 확인한다는 출처 순서를 유지한다. 이 모델에 대한 소문(출시일, 규모, AGI 주장)도 같은 규칙으로 취급한다.
- 환각 값(AA-Omniscience, "1 − 환각률")이 공개되면 지수 버전과 노력 단계를 명시해 읽는다. 값이 좋아도 이름·날짜·수치·버전은 직접 연 출처로 확인하고 인용 구절은 코드로 원문 포함 여부를 대조한다.
- 인젝션 방어율의 독립 측정이 나오는지 확인한다. 서버 측 도구는 검색 결과를 모델 컨텍스트에 직접 넣으므로 읽기 단계와 행동 단계의 분리, 허용 목록 필터는 모델과 무관하게 유지한다(§3.1).
- 서버 측 도구가 로봇 배제 표준과 이용 약관을 따르는지, 어떤 사용자 에이전트로 접근하는지 확인한다. 공개되기 전에는 로그인·유료벽 뒤 자료를 검색시키지 않는다(§3.2).
- 심층 리서치 지표(BrowseComp 등)의 독립 결과가 나오는지 확인한다. 점수가 나와도 고정 말뭉치 여부와 노력 단계를 읽는다.
- 규모가 커진 모델의 지연·토큰 소비·장문 요금 문턱을 확인하고 페이지 하나씩 필요한 구간만 넣는다. 대량 수집·추출은 더 싼 모델로 처리하고 판단이 필요한 종합만 Grok 5에 맡기는 분업을 시험한다. [추정]
- 수집한 자료를 보내기 전에 대상 사이트의 이용 약관과 이 API의 데이터 처리 조건(학습 사용, 보관, ZDR)을 함께 본다.

**잠정 운용**
- 출시 전 웹 리서치는 현재 확인된 Grok 모델과 상위 모델을 기준선으로 한다. 공식 발표와 독립 측정이 나오기 전에는 Grok 5를 리서치의 기본으로 지정하지 않는다.
