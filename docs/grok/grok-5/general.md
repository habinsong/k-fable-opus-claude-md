## 2. 모델 상태 — Grok 5 (2026-11-03 기준 미출시로 추정)

### 2.1 확인된 것과 확인되지 않은 것
- **공식 출시 발표를 찾지 못했다.** 이 환경의 검색은 2026-09 말까지의 자료만 보여 주므로 10월 이후 발표가 있었는지는 확인하지 못했다. xAI 공식 문서와 공지 페이지는 열리지 않는다. 2026-08 시점 한 분석은 공개 모델, API 엔드포인트, 모델 카드가 없다고 정리했다. [미확인]
- **일정은 계속 어긋났다.** 2025년 말~2026년 1분기 목표가 지났고 xAI 공식 계정은 2분기를 가장 유력한 시기로 언급했으며, 2026-08-05 통화에서 머스크는 올해(2026) 안에 나온다고만 말했다. xAI는 구체적 날짜를 낸 적이 없다. 이 환경에서 확인한 가장 최근 로드맵(2026-09-14, 2차 전달)은 Grok 5 앞에 두 모델(4.8, 이어서 4.9)을 두어, 2026년 안 출시가 가능한지 의문이 생긴다. [부분: 2차, 추정 포함]
- **학습은 진행 중으로 서술된다.** 2026-01 시리즈 E 발표에서 xAI가 Colossus 2(멤피스의 기가와트급 슈퍼클러스터)에서 학습 중이라고 확인했다는 서술이 있다. 이것도 2차 출처다. [부분]
- **규모는 공개되지 않았다.** 6조 파라미터라는 안내 글, 머스크의 주장이라는 2.1조 수치가 있으나 둘 다 미검증이다. 4.8이 약 2.5조라는 서술과 맞추면 5의 규모는 더 커야 할 것 같지만 이는 추정이다. AGI 주장과 결합된 홍보성 서술이 많다. [미확인]
- **예측 시장 수치는 쓰지 않는다.** 2026-08 시점 일부 시장이 10월 1일 이전 출시 68%, 연말 이전 82%를 가리켰다는 서술이 있으나 그 시점이 지났고 출시 소식이 확인되지 않았다. 예측 시장과 SNS는 근거가 아니다. [미확인]
- **그래서 스펙을 쓰지 않는다.** 가격, 컨텍스트, 크기, 입력 방식, 도구, 안전 문서, 데이터 처리는 모두 [미확인]이다. 이 폴더의 어떤 문장도 Grok 5의 성능이나 동작을 단정하지 않는다.
- 출시 전에 모델 ID 문자열을 코드에 박지 않는다. 명명 규칙으로 추정한 ID가 틀릴 수 있다. xAI 공식 문서의 모델 목록에서 확인한 ID만 쓴다.

### 2.2 잠정 규칙: 출시 전까지는 Grok 4.7 문서(또는 확정되면 4.8)를 따른다
- 현재 확인 가능한 최신 모델은 Grok 4.7이므로 `grok/grok-4.7/` 문서의 규칙을 그대로 쓴다. 4.8이 먼저 출시되면 `grok/grok-4.8/` 문서를 적용하고 그 이후에 이 문서를 갱신한다. 이 규칙은 4.7에 대해 확인된 것(대부분 2차 출처)이며 Grok 5에서 같다는 보장은 없다.
- 상속 가능성이 높아 보이는 항목(추정): 폐쇄형 API, 서버 측 검색 도구(웹·X)와 별도 과금, 노력 단계 변형, 모델 카드·안전 문서 지연 경향, 빠른 갱신 주기. [추정]
- 바뀔 가능성이 큰 항목(추정): 가격·장문 요금 문턱, 토큰 소비, 컨텍스트, 호출 경로, 안전 문서의 범위(규모가 클수록 위험 평가 요구가 커짐), 데이터 정책. [추정]

### 2.3 출시 당일 확인 체크리스트 (공식 문서에서 직접, 하나씩)
1. xAI 공식 공지·문서의 발표일, 모델 ID, 별칭, 변형과 호출 경로(공개 API, Grok Build, Cursor), 이전 모델의 폐기 일정.
2. 가격: 입력·출력·캐시·장문 요금 문턱과 요율, 서버 측 도구 호출당 요금.
3. 컨텍스트, 최대 출력, 입력 방식(텍스트·이미지·음성·영상), 추론 노력 지정 방식과 단계별 토큰 소비.
4. 모델 카드·시스템 카드 존재 여부와 내용(위험 능력 평가, 거부·탈옥 강건성, 평가 조건). "AGI" 같은 표현은 평가 정의를 확인한다.
5. 벤더 벤치마크의 조건(노력 단계, 하네스, 보고 주체)과 독립 평가(Artificial Analysis 등)의 지수 버전.
6. 데이터 정책: API 입력·출력의 학습 사용, 보관, ZDR, DPA. 회사명 표기(xAI, SpaceXAI)와 계약 주체.
7. 안전장치와 거부 범주, 안전 평가 보고서 공개 여부.
8. 이행 가이드의 깨지는 변경과 라이선스·약관 변경.

### 2.4 비판적 점검
- **루머로 도입을 결정하지 않는다.** 출시일·규모·성능·AGI 주장은 머스크 발언의 재인용, 예측 시장, SEO성 블로그가 대부분이고 이전 일정이 모두 어긋났다. 공식 발표 전에는 현재 확인된 모델과 다른 후보로 평가를 진행한다.
- **"AGI" 같은 표현을 평가 결과로 읽지 않는다.** 정의와 측정 방법이 없는 주장이다. 독립 평가와 우리 과제의 실측으로 판단한다. [추정]
- **출시 직후 측정은 얕다.** 4.7도 출시 직후 벤더 벤치마크가 없었고 모델 카드가 확인되지 않았다. 같은 과제·같은 예산으로 직접 비교한다.
- **이 폴더를 출시 후 갱신한다.** 위 체크리스트를 채운 뒤 이 `general.md`의 §2를 실제 사양으로 바꾸고, 8개 분야 문서의 §2에 모델별 운용을 쓴다. 갱신 전의 이 문서는 추정을 단정으로 읽지 않기 위한 장치다.
