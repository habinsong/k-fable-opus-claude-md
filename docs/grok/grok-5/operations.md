#### 2.2 잠정 규칙: 출시 전까지는 Grok 4.7 문서(또는 확정되면 4.8)를 따른다
- 현재 확인 가능한 최신 모델은 Grok 4.7이므로 `grok/grok-4.7/` 문서의 규칙을 그대로 쓴다. 4.8이 먼저 출시되면 `grok/grok-4.8/` 문서를 적용하고 그 이후에 이 문서를 갱신한다. 이 규칙은 4.7에 대해 확인된 것(대부분 2차 출처)이며 Grok 5에서 같다는 보장은 없다.
- 상속 가능성이 높아 보이는 항목(추정): 폐쇄형 API, 서버 측 검색 도구(웹·X)와 별도 과금, 노력 단계 변형, 모델 카드·안전 문서 지연 경향, 빠른 갱신 주기. [추정]
- 바뀔 가능성이 큰 항목(추정): 가격·장문 요금 문턱, 토큰 소비, 컨텍스트, 호출 경로, 안전 문서의 범위(규모가 클수록 위험 평가 요구가 커짐), 데이터 정책. [추정]

#### 2.3 출시 당일 확인 체크리스트 (공식 문서에서 직접, 하나씩)
1. xAI 공식 공지·문서의 발표일, 모델 ID, 별칭, 변형과 호출 경로(공개 API, Grok Build, Cursor), 이전 모델의 폐기 일정.
2. 가격: 입력·출력·캐시·장문 요금 문턱과 요율, 서버 측 도구 호출당 요금.
3. 컨텍스트, 최대 출력, 입력 방식(텍스트·이미지·음성·영상), 추론 노력 지정 방식과 단계별 토큰 소비.
4. 모델 카드·시스템 카드 존재 여부와 내용(위험 능력 평가, 거부·탈옥 강건성, 평가 조건). "AGI" 같은 표현은 평가 정의를 확인한다.
5. 벤더 벤치마크의 조건(노력 단계, 하네스, 보고 주체)과 독립 평가(Artificial Analysis 등)의 지수 버전.
6. 데이터 정책: API 입력·출력의 학습 사용, 보관, ZDR, DPA. 회사명 표기(xAI, SpaceXAI)와 계약 주체.
7. 안전장치와 거부 범주, 안전 평가 보고서 공개 여부.
8. 이행 가이드의 깨지는 변경과 라이선스·약관 변경.
