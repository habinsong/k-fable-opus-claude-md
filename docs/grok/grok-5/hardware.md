## 2. 이 모델의 하드웨어 작업 운용 (잠정)
2026-11-03 기준 Grok 5의 공식 발표를 찾지 못했다. 모델 상태와 출시일 체크리스트는 같은 폴더의 `general.md` §2를 따른다. 출시 전에는 `grok/grok-4.7/hardware.md`를 적용한다(4.8이 먼저 나오면 `grok/grok-4.8/hardware.md`).

**출시 후 하드웨어 작업에서 따로 확인할 것**
- Grok 계열에는 회로·PCB·HDL 평가와 데이터시트 판독 정확도 평가가 없었다. 5에서도 없을 가능성이 높다. 출시 후 평가가 나오는지 확인하고, 없으면 설계 판단에는 쓰지 않는다는 규칙을 유지한다. 설계는 상위 모델 문서(`gemini-4-argon`, `claude/opus-5.5`, `gpt-6.1-sol`)를 따른다.
- 규모가 크다는 사실이 값 회상의 정확성을 뜻하지 않는다. 환각 값(AA-Omniscience, "1 − 환각률")이 공개되면 지수 버전과 노력 단계를 명시해 읽고, 값이 좋아도 부품 번호·핀·정격을 기억에서 꺼내게 하지 않는다(§3.1). [추정]
- 서버 측 웹 검색·X 검색이 돌려주는 URL은 제조사 원문이 아닐 수 있다. 정격과 핀 배치는 개정판마다 다르므로 URL을 직접 열어 개정판과 페이지를 확인한다.
- 입력 방식에 이미지가 포함되면 데이터시트의 작은 글씨·핀 표·타이밍 다이어그램·회로도를 읽는 정확도를 같은 문서 세트로 상위 모델과 비교한다. 이미지에서 읽은 값은 원문 텍스트·넷리스트·ERC 보고서와 대조한다.
- 데이터시트를 통째로 넣지 않는다. 장문 요금 문턱과 토큰 소비를 공식 문서로 확인한다.
- 회로도·레이아웃·펌웨어 이미지·부품 공급 정보는 영업비밀이다. 데이터 처리 조건(학습 사용, 보관, ZDR)이 공개되고 법무가 검토하기 전에는 API로 보내지 않는다.
- 안전 문서(모델 카드, 위험 평가)와 탈옥 우회 보고를 확인한다. 인체·화재 위험 설계를 "안전하다"고 단정하지 않는다는 원칙은 모델이 바뀌어도 유지한다.

**잠정 운용**
- 출시 전 하드웨어 작업은 상위 모델을 기준선으로 하고 Grok 계열은 BOM 정규화, 로그 분류, 스크립트 초안 같은 보조에만 쓴다. 공식 발표와 독립 측정이 나오기 전에는 Grok 5를 하드웨어 작업의 기본으로 지정하지 않는다.
