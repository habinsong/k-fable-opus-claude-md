## 2. 이 모델의 웹 리서치 운용 (잠정)
2026-11-03 기준 Grok 4.8의 공식 발표를 찾지 못했다. 모델 상태와 출시일 체크리스트는 같은 폴더의 `general.md` §2를 따른다. 출시 전에는 `grok/grok-4.7/web-research.md`를 적용한다.

**출시 후 웹 리서치에서 따로 확인할 것**
- 서버 측 웹 검색·X 검색 도구가 4.8에서 같은 방식으로 동작하는지, 요금(1,000회당 $5는 4.3·4.5 시기 자료)과 출처 URL 반환 방식이 바뀌었는지 공식 문서로 확인한다. 한 응답에서 내부 검색이 여러 번 일어나 모두 과금되고 에이전트가 필요 이상으로 검색한다는 4.7 시기 보고가 줄었는지 호출 수로 본다. 호출 횟수·호출당 예산 한도는 하네스에서 계속 건다.
- X 검색 결과는 1차 출처가 아니다. 모델이 좋아져도 게시글만으로 사실을 확정하지 않고 공식 발표·명세·소스 저장소로 확인한다는 출처 순서를 유지한다.
- 환각 값(AA-Omniscience, "1 − 환각률")이 4.7에서는 확인되지 않았다. 4.8의 값이 공개되면 지수 버전과 노력 단계를 명시해 읽고, 값이 좋아도 이름·날짜·수치·버전은 직접 연 출처로 확인하며 인용 구절은 코드로 원문 포함 여부를 대조한다.
- 인젝션 방어율의 독립 측정이 나오는지 확인한다. 서버 측 도구는 검색 결과를 모델 컨텍스트에 직접 넣으므로 읽기 단계와 행동 단계의 분리, 허용 목록 필터는 모델과 무관하게 유지한다(§3.1).
- 서버 측 도구가 로봇 배제 표준과 이용 약관을 따르는지, 어떤 사용자 에이전트로 접근하는지 4.7에서는 확인하지 못했다. 공개되는지 확인하고, 그 전에는 로그인·유료벽 뒤 자료를 검색시키지 않는다(§3.2).
- 심층 리서치 지표(BrowseComp 등)의 독립 결과가 나오는지 확인한다. 점수가 나와도 고정 말뭉치 여부와 노력 단계를 읽는다.
- 컨텍스트가 커도 4.7은 프롬프트 20만 토큰부터 요청 전체에 장문 요금이 적용된다는 서술이 있었다. 페이지 하나씩 필요한 구간만 넣고, 4.8의 토큰 소비(4.7은 비교군의 두 배 이상)에 맞춰 `max_tokens`를 제한한다.
- 수집한 자료를 보내기 전에 대상 사이트의 이용 약관과 이 API의 데이터 처리 조건(학습 사용, 보관, ZDR)을 함께 본다. 4.7 시기에는 2차 출처뿐이었다.

**잠정 운용**
- 출시 전 웹 리서치는 Grok 4.7과 상위 모델을 기준선으로 한다. 공식 발표와 독립 측정이 나오기 전에는 4.8을 리서치의 기본으로 지정하지 않는다.
