## 2. 이 모델의 연구 작업 운용 (잠정)
2026-11-03 기준 Grok 4.8의 공식 발표를 찾지 못했다. 모델 상태와 출시일 체크리스트는 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 출시 전에는 `grok/grok-4.7/research.md`를 적용한다.

**출시 후 연구 작업에서 따로 확인할 것**
- 규모(미확인 서술상 약 2.5조 파라미터)와 강화학습 단계라는 서술은 연구 근거가 아니다. 독립 지수를 인용할 때는 지수 버전과 노력 단계를 함께 쓰고, 벤더 수치는 "벤더 보고"로 표기하며 조건(노력 단계, 하네스, 날짜)을 밝힌다. 4.7은 벤더 벤치마크가 공개되지 않았고 모델 카드가 확인되지 않아 인용 가능한 근거가 독립 지수뿐이었다.
- 연구 보조 정확도(문헌 요약, 통계 해석)의 독립 평가가 나오는지 확인한다. 없으면 새 가설·증명·통계 해석은 상위 모델 문서(`claude/opus-5.5`, `gemini-4-argon`, `gpt-6-astra`)를 따르고 전문가 검토를 거친다.
- 환각 값이 공개되면 지수 버전과 노력 단계를 명시해 읽는다. 참고문헌 생성은 모델 전반의 약점으로 보고돼 있다(26개 LLM 연구에서 모든 필드가 맞은 비율 48.3%). 4.8의 별도 측정이 나오기 전에는 모든 인용을 Crossref·DataCite·원문으로 확인한다(§3.2).
- 서버 측 웹 검색·X 검색을 문헌 조사의 1차 수단으로 쓰지 않는다. 검색식과 선택 과정을 완전히 노출하지 않을 수 있어 재현성이 떨어진다. 검색식은 하네스가 직접 실행하고 기록한다.
- 노력 단계별 이득과 토큰 소비를 다시 측정한다. 4.7은 `high`와 `xhigh`의 독립 지수가 같았다. 대량 처리는 실비용을 먼저 실측한다.
- 연구 데이터를 API로 보내기 전에 데이터 처리 조건(학습 사용, 보관, ZDR)과 연구 윤리 심의·동의 범위(§3.3)를 확인한다. 4.7 시기에는 학습 사용·보관 정보가 2차 출처뿐이었다.
- 재현성을 위해 모델 이름, 노력 단계, 호출 날짜, 호출 경로, 사용한 도구와 호출 수, 샘플링 설정을 기록한다. 이 계열은 두 달 사이에 세 번 갱신됐다.

**잠정 운용**
- 출시 전 연구 작업은 상위 모델을 기준선으로 하고 Grok 계열은 서식 변환, 로그 정리, 정해진 필드 추출 같은 보조에만 쓴다. 공식 발표와 독립 측정이 나오기 전에는 4.8을 연구의 기본으로 지정하지 않는다.
