## 2. 이 모델의 웹 리서치 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: API에 웹 검색·X 검색 서버 측 도구가 내장(출처 URL 반환), 도구 호출 1,000회당 $5 별도 과금, 에이전트의 과다 검색 보고, 환각·사실성 값 미확인, 인젝션 방어율 독립 측정 없음, 출력 토큰 소비 많음.

- **내장 도구가 있다는 점이 이 모델의 특징이다.** 웹 검색과 X 검색은 xAI 서버에서 실행되고 API가 출처 URL을 돌려주며 한 요청에서 함께 쓸 수 있다는 공식 문서 스니펫이 있다. 이 도구가 4.7에서 같은 방식으로 동작하는지는 확인하지 못했다(자료는 4.3·4.5 시기). [부분/미확인] 도구를 쓰는 요청은 토큰 요금에 더해 도구 호출 요금이 별도로 청구된다.
- **비용: 호출 1,000회당 $5, 한 응답에 내부 검색이 여러 번 일어나 모두 과금된다.** 개발자들이 에이전트가 한 번이면 될 검색을 세 번 하는 식으로 필요 이상으로 검색한다고 보고했다. 검색 호출 횟수 한도와 호출당 예산을 하네스에서 걸고 응답에 포함된 도구 호출 수를 기록한다. [부분: 개인 후기]
- **출처 URL을 직접 연다.** 도구가 돌려준 URL이 주장과 맞는지는 별개 문제다. 인용 구절이 원문에 있는지 문자열로 대조하고, 모델의 "전부 읽었다"는 보고를 근거로 쓰지 않는다. 수치·날짜·버전·가격은 원문에서 직접 대조한다(§3.1).
- **X(옛 트위터) 검색의 신뢰도는 낮은 출처로 취급한다.** X 검색은 이 API의 차별점이지만 게시글은 1차 출처가 아니고 루머·광고·조작이 섞인다. 공식 발표를 확인하는 용도로만 쓰고 게시글만으로 사실을 확정하지 않는다. 출처 순서(공식 문서·명세 > 공식 발표 > 신뢰할 만한 언론 > 블로그 > 커뮤니티)를 유지한다. [추정]
- **사실 회상에 기대지 않는다.** AA-Omniscience와 "1 − 환각률" 값을 찾지 못했다. [미확인] 이름·날짜·수치·버전은 직접 연 출처로 확인한다. 이 문서 저장소가 다루는 모델 정보처럼 빠르게 바뀌는 사실은 검색을 쓰더라도 기준일을 붙인다.
- **웹 페이지·게시글의 지시문은 데이터다.** 서버 측 도구는 검색 결과를 모델 컨텍스트에 직접 넣으므로 인젝션 경로가 열려 있다. 이 모델의 인젝션 방어율 측정은 찾지 못했다. [미확인] 모델에게 전송·로그인·결제·파일 쓰기 도구를 함께 주지 않고 읽기 단계와 행동 단계를 분리한다. 모델이 뽑은 URL은 하네스가 허용 목록으로 거른 뒤 연다.
- **수집 규칙은 xAI 서버가 지킨다고 가정하지 않는다.** 서버 측 도구가 어떤 사용자 에이전트로 접근하는지, 로봇 배제 표준과 이용 약관을 따르는지는 확인하지 못했다. [미확인] 로그인·유료벽 뒤 자료를 검색시키지 않고, 도구 결과에서 개인정보가 나오면 저장하거나 재배포하지 않는다(§3.2).
- **긴 입력은 발췌한다.** 컨텍스트가 50만 토큰이어도 프롬프트가 20만 토큰에 이르면 요청 전체에 장문 요금이 적용된다는 서술이 있다. 페이지 하나씩 필요한 구간만 넣는다. 출력 토큰 소비가 많았던 측정(비교군 중앙값의 두 배 이상)이 있어 `max_tokens`와 필드 수를 제한한다. [부분]
- **조사 결과를 보내기 전에 약관을 확인한다.** API 입력·출력의 학습 사용과 보관(기본 30일 서술)은 2차 출처뿐이다. [부분, 충돌] 개인정보가 섞인 자료는 보내지 않는다.
- **대량 수집은 표본 점검.** 무작위 5~10%를 사람이 원문과 대조한다. 오류율이 기준을 넘으면 상위 모델로 올린다. 보고 형식은 "결론 → 근거(URL, 확인일, 수준) → 충돌·불확실 → 모르는 것"으로 고정한다.
