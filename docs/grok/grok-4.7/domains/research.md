## 2. 이 모델의 연구 작업 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: 폐쇄형 API 모델, 독립 지수 46(`high`=`xhigh`), 환각·사실성 값 미확인, 벤더 벤치마크 미공개, 출력 토큰 소비 많음, 모델 카드 부재, 연구 보조 독립 평가 없음.

- **연구의 추론과 인용은 이 모델에 맡기지 않는다.** 독립 지수 46은 일반 능력 지표이며 가설 설계, 통계 해석, 문헌 종합의 정확도를 대신하지 않는다. 이 지수의 구성(HLE, SciCode, CritPt 등 과학·추론 평가 포함)을 보아도 연구 보조 정확도를 직접 재지는 않는다. 연구 보조 정확도의 독립 평가는 찾지 못했다. [부분/미확인] 새 가설·증명·통계 해석은 `claude/opus-5.5`, `gemini-4-argon`, `gpt-6-astra` 문서를 따르고 전문가 검토를 거친다.
- **벤더 벤치마크가 공개되지 않았다는 점을 연구 근거의 공백으로 본다.** 한 집계 페이지는 점수 집계 중으로 표시했고 모델 카드도 확인되지 않았다. 인용할 수 있는 수치는 독립 지수와 코딩 에이전트 지수(원문 미확인)뿐이다. 모델의 능력을 논문·보고서에 쓰려면 조건(노력 단계, 하네스, 날짜)과 함께 독립 출처를 밝힌다. [부분]
- **참고문헌을 만들거나 보충하게 하지 않는다.** 26개 LLM 연구에서 검증 가능한 참고문헌 중 모든 필드가 맞은 비율은 48.3%였고 저자 목록이 가장 약했다(51.7%). 이 모델의 별도 측정은 찾지 못했고 환각 값도 확인하지 못했다. [부분/미확인] 모든 인용은 Crossref·DataCite·원문에서 제목·저자·연도·권호와 주장의 실제 존재를 확인한다(§3.2). 내장 웹 검색이 돌려준 URL도 논문의 정식 서지(DOI)로 되돌려 확인한다.
- **내장 X 검색·웹 검색을 문헌 조사의 1차 수단으로 쓰지 않는다.** 체계적 조사는 검색 데이터베이스, 검색식, 날짜, 포함·제외 기준을 기록해야 재현된다(§3.2). 서버 측 도구는 내부 검색식과 선택 과정을 완전히 노출하지 않을 수 있어 재현성이 떨어진다. 검색식은 하네스가 직접 실행하고 기록한다. [추정]
- **써도 되는 작업.** 서지 정보 서식 변환, 실험 로그·메타데이터 정리, 표 형식 변환, 논문 초록에서 정해진 필드 추출, 분석 스크립트(파이썬)의 초안. "원문에 없으면 null"을 명시하고 추출값은 원문과 한 건씩 대조한다. 출력 토큰 소비가 많았으므로 대량 처리는 실비용을 먼저 실측한다. [부분]
- **그림·차트 이미지에서 값을 읽을 때는 원자료와 대조한다.** 이미지 입력을 지원하나 차트 판독 정확도 평가를 찾지 못했다. [미확인] 수치를 잘못 읽거나 축 단위를 놓칠 수 있으므로 본문 수치·보충 자료·원자료와 한 건씩 대조한다.
- **수학·정량 풀이는 코드로 재검산한다.** `xhigh` 단계의 긴 추론으로 푼 풀이도 틀릴 수 있다. 식은 스크립트·기호 계산 도구로 다시 계산하고 단계를 사람이 읽는다.
- **연구 데이터를 API로 보내기 전에 조건을 확인한다.** 여러 집계가 API 입력·출력을 학습에 쓰지 않고 기본 30일 보관이라고 정리하나 원문을 읽지 못했고 ZDR 조건 서술이 갈린다. [부분, 충돌] 사람 대상 자료, 개인정보, 미공개 데이터, 기관 규정이 있는 자료는 연구 윤리 심의와 동의 범위, 데이터 이용 허가(§3.3)를 먼저 확인하고 확인 전에는 보내지 않는다.
- **분석 결과를 모델 설명으로 대체하지 않는다.** 통계는 코드를 다시 실행해서 확인한다. 시드, 데이터 버전, 라이브러리 버전을 기록하고, 이상치 제거·필터·검정 기준이 결과에 맞춰 바뀌지 않았는지 `git diff`로 확인한다.
- **재현성을 위해 호출 조건을 기록한다.** 모델 이름, 노력 단계(`low`/`high`/`xhigh`), 호출 날짜, 호출 경로, 사용한 도구와 호출 수, 샘플링 설정을 남긴다. 직전 3개 버전이 두 달 사이에 나왔다. [부분]
- **전문 영역(의료, 법률, 안전) 결론에는 "전문가 검토 필요"를 붙인다.**
