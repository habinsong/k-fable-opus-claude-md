## 2. 이 모델의 하드웨어 작업 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: 폐쇄형 API 모델, 독립 평가 점수 46, 환각·사실성 값 미확인, 출력 토큰 소비 많음, 이미지 입력, 모델 카드 부재, 하드웨어 설계 평가 없음.

- **설계 판단에 쓰지 않는다.** 핀 배치, 정격, 타이밍, 수식은 틀리면 보드가 망가지거나 위험해진다. 이 모델의 회로·PCB·HDL 평가는 찾지 못했다. [미확인] 독립 평가 점수 46과 코딩 점수는 일반 능력 지표이고 회로 설계 정확도를 대표하지 않는다. 설계는 `gemini-4-argon`, `claude/opus-5.5`, `gpt-6.1-sol` 같은 상위 모델 문서와 같은 과제로 비교하고, 그 결과도 데이터시트 원문과 도구 계산으로 확인한다.
- **값 회상을 믿지 않는다.** AA-Omniscience와 "1 − 환각률" 값을 찾지 못했다. [미확인] 부품 번호, 핀 번호, 레지스터 주소, 정격을 모델 기억에서 가져오게 하지 않는다. 값은 사람이 확보한 데이터시트 텍스트에서만 꺼내게 하고, 값마다 문서명·개정판·페이지를 같이 받아 원문 PDF와 한 건씩 대조한다. 원문에 없으면 null이다(§3.1).
- **내장 웹 검색을 데이터시트 값의 출처로 쓰지 않는다.** API는 웹 검색 도구를 내장하고 출처 URL을 돌려주지만, 부품 정격은 개정판마다 다르고 검색 결과에 유사 부품·재판매 사이트·구 개정판이 섞인다. 돌려받은 URL을 제조사 원문으로 직접 열어 개정판과 페이지를 확인한다. 검색 호출은 1,000회당 $5가 별도 과금되고 에이전트가 필요 이상으로 검색한다는 보고가 있다. [부분]
- **긴 컨텍스트에 데이터시트를 통째로 넣지 않는다.** 컨텍스트가 50만 토큰이어도 프롬프트가 20만 토큰에 이르면 요청 전체에 장문 요금이 적용된다는 서술이 있다. 필요한 장과 표만 넣고 PDF 표를 텍스트로 변환한 결과도 원문과 대조한다. [부분]
- **이미지(회로도 사진·PCB 사진) 판독은 근거로 쓰지 않는다.** 이미지 입력을 지원하나 판독 정확도 평가를 찾지 못했다. [미확인] 읽은 값은 원문 텍스트·넷리스트·ERC 보고서와 대조하고, 읽기 어려운 부분은 추측하지 말고 "판독 불가"로 표시하게 한다.
- **써도 되는 작업.** BOM 정규화, 부품 번호 목록 변환, 시험 로그 분류, 데이터시트 텍스트에서 정해진 필드 추출, 측정·변환 스크립트(파이썬)의 초안. 스크립트는 알려진 값을 넣어 실행해 확인한다. 출력 토큰 소비가 많았던 측정이 있어($2/$6라는 단가보다 실비용이 클 수 있음) 대량 정리는 비용을 먼저 실측한다. [부분]
- **계산은 도구로 한다.** 전류 예산, 분압, 필터, 열 계산은 스크립트·시뮬레이터 출력으로 확인하고 식과 가정을 남긴다. 추론 모드로 낸 풀이도 마찬가지다.
- **미공개 설계 자료를 API로 보내지 않는다(약관 확인 전).** 여러 집계는 API 입력·출력을 학습에 쓰지 않고 기본 30일 보관한다고 정리하나 xAI 약관·DPA 원문을 읽지 못했고 ZDR 조건 서술이 갈린다. [부분, 충돌] 회로도·레이아웃·펌웨어 이미지·부품 공급 정보는 영업비밀이므로 원문 약관을 읽고 승인받은 뒤에만 보낸다.
- **인체·화재 위험 설계는 "안전하다"고 단정하지 않는다.** 고전압·대전류·배터리·모터는 사람의 검토를 요청한다. 모델 카드와 위험 평가가 공개되지 않았으므로 모델의 거부·경고 동작에 기대지 않는다.
