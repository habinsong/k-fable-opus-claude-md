## 2. 이 모델의 웹 리서치 운용
모델 전체 특성은 같은 폴더의 `general.md` §2를 따른다. 요약: 컨텍스트 100만 토큰, 입력 $0.15 / 출력 $0.60(인하 보도), 환각률 93% 보도(모르는 질문에도 답을 시도), 인용·인젝션 방어 독립 측정 없음, 데이터 정책 서술 충돌.

- **사실 조회와 인용 생성에는 쓰지 않는다.** 독립 측정에서 모르는 질문에도 거절하지 않고 답을 시도해 환각률이 93%라는 보도가 있다(2차, AA 원문 수치 미확인). 웹 리서치의 핵심 위험인 "출처 없는 사실 단정"과 정확히 겹친다. 이름·날짜·수치·버전의 회상, 출처가 있는 것처럼 보이는 문장 생성, 충돌하는 자료의 조정은 상위 모델이나 사람이 맡는다. [부분: 2차/추정]
- **쓴다면 "주어진 텍스트에서만" 추출하는 좁은 용도에 한정한다.** 검색 호출과 출처 신뢰도 판단은 하네스와 사람이 맡고, 모델에는 확보한 페이지 텍스트에서 제목·날짜·가격·버전 같은 필드를 JSON으로 추출하게 한다. "원문에 없으면 null"을 명시하되 그 준수를 가정하지 않고, 값마다 근거 구절을 받아 코드로 원문 포함 여부를 대조해 포함되지 않은 값은 폐기한다. 대량 처리라도 무작위 5~10%를 사람이 원문과 대조한다. [추정]
- **내장 검색은 확인하지 못했다.** MiniMax API가 검색 grounding을 제공하는지 찾지 못했다. [미확인] 모델이 URL이나 출처를 말해도 하네스가 직접 열어 대조한다. 존재하지 않는 URL·논문·인용을 지어낼 수 있다는 전제로 다룬다.
- **작업당 비용이 낮은 점은 반복 검증과 궁합이 좋다.** 작업당 약 $0.22(M3 $0.51)라 추출 결과를 코드로 검증하고 실패분만 상위 모델로 올리는 2단 구조가 비용상 현실적이다. 단가는 출시 후 인하 보도가 있어 현재 요율을 확인한다. [부분]
- **리서치 에이전트의 독립 평가는 찾지 못했다.** BrowseComp류 지표의 독립 결과가 보도에 나오지 않았다. DeepSWE v1.1 73.7%(벤더)는 코딩 지표이며 리서치 능력으로 옮기지 않는다. [미확인]
- **웹 페이지의 지시문은 데이터다.** 이 모델의 인젝션 방어율 측정은 찾지 못했다. [미확인] 모델에게 전송·로그인·결제·파일 쓰기 도구를 주지 않고 읽기 단계와 행동 단계를 분리한다. 모델이 뽑은 URL은 하네스가 허용 목록으로 거른 뒤 연다.
- **긴 입력은 발췌한다.** 컨텍스트가 100만 토큰이어도 페이지 하나씩 필요한 구간만 넣고 출력 필드를 제한한다. [추정]
- **수집한 자료를 보내기 전에 조건을 확인한다.** 대상 사이트의 이용 약관·로봇 배제 표준(§3.2)과 이 API의 데이터 조건을 모두 본다. 싱가포르 법인·미국 저장이라는 독립 안내와 중국을 가리키는 오래된 정책이 충돌하고 학습 제외 약속과 ZDR이 확인되지 않는다. [부분, 충돌] 개인정보가 섞인 페이지는 보내지 않는다.
- **보고 형식**은 "결론 → 근거(URL, 확인일, 수준) → 충돌·불확실 → 모르는 것"으로 고정한다.
