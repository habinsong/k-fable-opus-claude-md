## 2. 이 모델의 웹 작업 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: 경량 변형(파라미터 미확인), 입력 $0.15 / 출력 $0.60(인하 보도), 독립 지수 42, 작업당 비용 $0.22(M3 $0.51), 환각률 93% 보도, DeepSWE v1.1 73.7%(벤더), 가중치 공개 여부 충돌.

- **웹 UI 생성의 독립 평가는 찾지 못했다.** [미확인] 컴포넌트 단위 수정, 새 화면, 스크린샷 재현을 우리 코드베이스에서 `minimax-m3`와 상위 모델을 포함해 같은 조건으로 비교하고, 스크린샷 대조와 린터·타입체크·테스트 출력으로 판정한다. 기존 UI 체계가 우선한다(§3.1).
- **싼 단가 덕분에 UI 수정 반복 시도가 현실적이다.** 작업당 비용이 M3의 절반 수준(독립 측정 57% 감소)이라 린터·타입체크·테스트로 자동 검증되는 소규모 수정을 여러 번 시도하는 흐름에 맞다. 다만 MiniMax가 말한 70% 절감보다 독립 측정의 감소 폭이 작다는 점을 비용 계획에 반영한다. [부분]
- **환각 경향 때문에 API·라이브러리 사용법을 모델 기억에 맡기지 않는다.** 모르는 질문에도 답을 시도해 환각률이 93%라는 보도가 있다(2차, 원문 미확인). 존재하지 않는 CSS 속성, 컴포넌트 API, 패키지 이름을 지어낼 수 있으므로 린터·타입체크·컴파일러 출력으로 검증하고 새 패키지는 실제 존재와 라이선스를 확인한 뒤 추가한다(§3.1). [부분: 2차]
- **DeepSWE v1.1 73.7%는 벤더 제공값이다.** 독립 재현이 없고 웹 UI 품질과 다른 지표다. [부분: 벤더 주장]
- **프리뷰와 정식 ID를 구분한다.** 프리뷰는 MiniMax Code와 Token Plan에서만 쓸 수 있었고 정식은 API로 나왔다. CI와 코드 생성 파이프라인에는 정식 API의 약관과 한도를 확인한다. [부분]
- **스크린샷 입력은 확인하지 못했다.** 이 모델의 이미지 입력 지원과 UI 재현 정확도는 찾지 못했다. 시각 검수는 사람이나 비전 모델이 한다. [미확인]
- **보안·접근성 판단을 맡기지 않는다.** 인가, 입력 검증, 비밀 노출, 접근성 "충족" 여부는 도구 출력과 §3.1 기준으로 사람이 점검한다. API·CSS·브라우저 지원은 공식 문서와 린터·컴파일러 출력으로 확인한다.
- **미공개 소스를 보내기 전에 데이터 조건을 확인한다.** 싱가포르 법인·미국 저장이라는 독립 안내와 중국을 가리키는 오래된 정책이 충돌하고 학습 제외 약속과 ZDR이 확인되지 않는다(README.md가 안내하는 개요·운용 문서.4). [부분, 충돌] 확인 전에는 비밀·고객 데이터가 담긴 코드를 보내지 않는다(§1.6).
