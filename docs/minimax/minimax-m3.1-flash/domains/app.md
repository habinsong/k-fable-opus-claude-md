## 2. 이 모델의 앱 작업 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: 경량 변형이지만 파라미터·가중치 공개 여부 미확인, 환각률 93% 보도, 입력 $0.15 / 출력 $0.60(인하 보도), 데이터 정책 서술 충돌, 모바일 개발 독립 평가 없음.

**앱에 내장할 때**
- **기기 안에서 돌릴 모델이 아니다.** 이름이 Flash여도 파라미터 수가 공개되지 않았고(428B·23B는 M3의 수치일 수 있다는 경고), 가중치 공개 여부도 출처마다 어긋난다. 휴대 기기 안에서 돈다는 근거가 없다. 앱은 서버를 거쳐 호출하는 구조만 가능하다. 모바일 온디바이스는 `gemma-4-e2b`, `gemma-4-e4b` 문서를 본다. [부분/미확인]
- **API 키를 앱 바이너리나 리소스에 넣지 않는다.** 자체 백엔드에서 키 보관, 사용량 제한, 요청 검증, 로깅을 한다(§3.1 비밀 규칙). 모델 출력은 신뢰하지 않는 입력으로 취급해 서버에서 검증한 뒤 앱에 전달한다.
- **사용자에게 사실을 말하는 기능에는 쓰지 않는다.** 환각률 93%라는 보도(2차, 원문 미확인)는 모르는 질문에도 답하려는 경향을 뜻한다. 챗봇의 사실 답변, 요약 속 수치, 출처 인용이 사용자에게 그대로 전달되는 구조는 위험하다. 필드 추출·분류·태깅처럼 결과를 서버 코드로 검증하는 기능이나, 답변 근거 문서를 함께 주고 근거 구절 포함 여부를 대조하는 구조에 한정한다. 거절·불확실 응답을 UX에 반영한다. [부분: 2차/추정]
- **개인정보 선언과 실제 동작을 맞춘다.** 싱가포르 법인·미국 저장이라는 독립 안내와 중국을 가리키는 오래된 정책이 충돌하고 포괄적 학습 제외 약속과 ZDR이 공개 문서로 확인되지 않는다. [부분, 충돌] 출시 전에 약관과 개인정보 정책을 원문으로 읽고 앱의 개인정보 선언(Apple 개인정보 영양 표시, Google Play 데이터 보안 양식)과 처리방침에 전송 항목과 국외 이전을 반영한다. 소비자 제품 정책과 API 정책을 혼동하지 않는다. 아동·민감정보는 확인 전에 보내지 않는다.
- **비용은 과제당으로 서버에서 제한한다.** 단가는 입력 $0.15 / 출력 $0.60이고 출시 후 인하 보도가 있어 현재 가격을 공식 가격표로 확인한다. 독립 측정에서 작업당 비용이 M3의 약 43% 수준($0.22 대 $0.51)이었다. 사용자당 한도, `max_tokens`, 요청 빈도 제한을 서버에 두고 실제 청구서로 확인한다. [부분, 충돌]
- **가중치를 직접 호스팅하려면 공개 여부와 라이선스를 먼저 확인한다.** 공개 가중치 여부가 충돌하므로 공식 릴리스 노트와 저장소를 확인하기 전에는 계획에 넣지 않는다. 공개된다면 상위 M3와 같은 MiniMax Community License(용도 금지 조항)일 수 있다는 점은 추정이다. [부분, 충돌/추정]
- **모델 교체를 앱 업데이트 없이 할 수 있게 설계한다.** 프리뷰(9월)에서 정식(10월)까지 한 달 만에 가격이 바뀌었다. 서버 쪽 모델 설정, 폴백 모델, 회귀 시험, 기능 플래그를 둔다.

**개발 보조로 쓸 때**
- **모바일(Kotlin·Swift) 코드에 대한 독립 평가는 찾지 못했다.** [미확인] 환각 경향이 있으므로 존재하지 않는 SDK 함수·권한 이름을 지어낼 수 있다. 컴파일·린트·단위 테스트·UI 테스트로 검증하고, 플랫폼 API는 공식 문서로 확인한다. 수명주기·권한·비동기 처리가 걸린 구현은 상위 모델 문서(`claude/sonnet-5.5` 이상, `gpt-6.1-sol`, `gemini-4-argon`)와 같은 과제로 비교한다.
- 스토어 규정은 기억으로 답하지 않고 공식 문서로 확인한다(§3.2). 서명 키, 프로파일, 스토어 제출·배포는 승인 후에만 한다.
