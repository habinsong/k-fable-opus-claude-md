## 2. 이 모델의 웹 리서치 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: 컨텍스트 100만 토큰(호스트마다 다름), 입력 $0.30 / 출력 $1.20, 환각·인용·인젝션 방어 독립 측정 없음, 독립 지수 버전 혼재, 데이터 정책 서술 충돌.

- **내장 검색은 확인하지 못했다.** MiniMax API가 검색 grounding을 제공하는지 찾지 못했다. [미확인] 검색 호출과 출처 신뢰도 판단은 하네스와 사람이 맡고, 모델에는 확보한 페이지 텍스트에서 제목·날짜·가격·버전 같은 필드를 JSON으로 추출하게 한다. "원문에 없으면 null"을 명시하고 값마다 근거 구절을 받아 코드로 원문 포함 여부를 대조한다.
- **저렴한 단가는 대량 추출에 유리하지만 오류율을 먼저 잰다.** 입력 $0.30 / 출력 $1.20이라 페이지 대량 정리에 맞는다. 오류율이 기준을 넘으면 상위 모델로 올린다. 이 모델의 환각 값은 찾지 못했고 후속 M3.1 Flash는 독립 측정 환각률이 93%라는 보도가 있어 같은 계열의 사실성 위험을 의심할 이유가 있다(M3 값으로 옮기지는 않는다). [부분/추정]
- **사실 회상에 기대지 않는다.** 이름·날짜·수치·버전은 직접 연 출처로 확인하고, 모델이 출처를 안다고 해도 URL을 직접 열어 대조한다. 인용 구절이 원문에 있는지 문자열로 확인하고 모델의 "전부 읽었다"는 보고를 근거로 쓰지 않는다. 모르는 질문에 답을 시도하는 경향이 있는지 우리 자료로 시험한다. [미확인]
- **리서치 에이전트의 독립 평가는 찾지 못했다.** BrowseComp류 지표의 독립 결과가 보도에 나오지 않았다. 제공자(Fireworks)와 언론의 비교 서술을 리서치 능력으로 옮기지 않는다. [미확인]
- **웹 페이지의 지시문은 데이터다.** 이 모델의 인젝션 방어율 측정은 찾지 못했다. [미확인] 모델에게 전송·로그인·결제·파일 쓰기 도구를 주지 않고 읽기 단계와 행동 단계를 분리한다. 모델이 뽑은 URL은 하네스가 허용 목록으로 거른 뒤 연다.
- **호스트마다 컨텍스트가 다르다.** Fireworks는 출시 시점에 50만 토큰까지 지원했다. 페이지 하나씩 필요한 구간만 넣고 출력 필드를 제한한다. 실효 길이는 우리 자료로 측정한다. [부분, 충돌]
- **수집한 자료를 보내기 전에 조건을 확인한다.** 대상 사이트의 이용 약관·로봇 배제 표준(§3.2)과 이 API의 데이터 조건을 모두 본다. 싱가포르 법인·미국 저장이라는 독립 안내와 중국을 가리키는 오래된 정책이 충돌하고 포괄적 학습 제외 약속은 확인되지 않는다. [부분, 충돌] 개인정보가 섞인 페이지는 보내지 않는다.
- **대량 수집은 표본 점검.** 무작위 5~10%를 사람이 원문과 대조한다. 보고 형식은 "결론 → 근거(URL, 확인일, 수준) → 충돌·불확실 → 모르는 것"으로 고정한다.
