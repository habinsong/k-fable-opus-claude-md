## 2. 이 모델의 웹 작업 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: 428B MoE(활성 약 23B), 입력 $0.30 / 출력 $1.20, 제한적 커뮤니티 라이선스, 독립 지수가 버전마다 다름, SWE-Bench Pro 59.0%(Opus 4.8 69.2%), 호스트마다 컨텍스트 차이.

- **웹 UI 생성의 독립 평가는 찾지 못했다.** [미확인] 컴포넌트 단위 수정, 새 화면, 스크린샷 재현을 우리 코드베이스에서 상위 모델과 같은 조건으로 비교하고, 스크린샷 대조와 린터·타입체크·테스트 출력으로 판정한다. 기존 UI 체계가 우선한다(§3.1).
- **싼 단가가 곧 싼 과제당 비용은 아니다.** 입력 $0.30 / 출력 $1.20은 낮지만 과제당 토큰 사용량과 재시도 횟수가 비용을 정한다. 지수 실행 비용이 약 $203.86이었다(버전·조건 불명). 컴포넌트 수정 한 건당 입력·출력 토큰과 도구 호출 수를 기록해 비교한다. [부분]
- **SWE-Bench Pro에서 상위 모델에 뒤진다는 보도가 있다.** 59.0%로 Opus 4.8의 69.2%에 못 미쳤다. 복잡한 다중 파일 변경은 상위 모델 문서(`claude/sonnet-5.5` 이상, `gpt-6.1-sol`, `gemini-4-argon`)와 같은 과제로 비교하고, 컴포넌트 단위의 단순 작업에 먼저 시험한다. [부분: 언론]
- **호스트마다 컨텍스트가 다르다.** Fireworks는 출시 시점에 50만 토큰까지만 지원했다. 큰 저장소를 넣는 UI 작업은 사용하는 호스트의 실제 한도를 확인하고, 관련 파일만 넣는다. [부분, 충돌]
- **스크린샷 입력은 확인하지 못했다.** 이 모델의 이미지 입력 지원 여부와 UI 재현 정확도는 찾지 못했다. 시각 검수는 사람이나 비전 모델이 한다. [미확인]
- **직접 호스팅은 웹 개발 보조로 타당성이 낮다.** 총 428B라 다중 GPU 노드가 필요하다. 호스트 서비스를 쓰면 호스트의 데이터 조건이 적용된다. [부분]
- **용도 제한이 있는 라이선스를 확인한다.** 가중치를 번들하거나 서비스에 노출하는 경우 군사 용도·유해 허위 정보·혐오 표현 금지 조항이 사용자 콘텐츠에 걸릴 수 있다. LICENSE 원문을 읽기 전에는 사용자에게 모델 접근을 제공하는 웹 제품에 넣지 않는다(README.md가 안내하는 개요·운용 문서.2). [부분: 2차 요약/미확인]
- **보안·접근성 판단을 맡기지 않는다.** 인가, 입력 검증, 비밀 노출, 접근성 "충족" 여부는 도구 출력과 §3.1 기준으로 사람이 점검한다. 미공개 소스를 API로 보내기 전에는 데이터 조건(싱가포르 법인·미국 저장 서술, 학습 사용 불명)을 원문으로 확인한다(§1.6). [부분, 충돌]
