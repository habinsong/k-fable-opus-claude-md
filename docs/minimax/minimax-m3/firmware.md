## 2. 이 모델의 펌웨어 작업 운용
모델 전체 특성은 같은 폴더의 `general.md` §2를 따른다. 요약: 428B MoE라 기기 내 실행 불가, 임베디드 평가 없음, 환각 값 부재, 제한적 커뮤니티 라이선스, 데이터 정책 서술 충돌.

- **기기 안에서 돌릴 모델이 아니다.** 총 428B라 MCU는 물론 임베디드 리눅스 SBC에도 올릴 수 없다. 개발 워크스테이션에서 API로 쓰는 보조 도구로만 쓴다. 기기 내 추론이 필요하면 소형 모델 문서(`gemma-4-e2b`, `gemma-4-e4b`)를 본다. [부분]
- **펌웨어 코드를 직접 쓰거나 고치게 하지 않는다.** 레지스터 값, 인터럽트, 부트·업데이트 경로, 서명 검증은 환각이 장치 고장이나 보안 구멍이 된다. 임베디드·펌웨어 평가는 찾지 못했다. [미확인] SWE-Bench Pro 59.0%(Opus 4.8 69.2%)는 소프트웨어 엔지니어링 지표이고 장치 쓰기나 실시간 제약과 무관하다. 이 영역은 `gemini-4-argon`, `claude/sonnet-5.5` 이상, `gpt-6.1-sol` 문서를 따른다. [부분: 언론]
- **레지스터·타이밍을 모델의 기억에서 가져오지 않는다.** 이 모델의 환각 값을 찾지 못했다. 데이터시트·레퍼런스 매뉴얼의 개정판과 페이지를 사람이 확보한 텍스트로 주고, 확인하지 못했으면 값을 쓰지 않는다(§3.1). [미확인]
- **써도 되는 작업.** UART·RTT 로그 분류, 맵 파일 요약, 컴파일러 경고 그룹화, 변경 이력 요약, 호스트에서 돌리는 테스트 코드(하드웨어 추상화 뒤쪽 로직)의 초안. 입력은 관련 구간만 준다. 출력은 원본 로그·맵 파일과 한 건씩 대조한다. 단가가 낮아 대량 로그 분류에 유리하다. [부분]
- **에이전트에게 장치 접근을 열어 주지 않는다.** 플래시 소거, 퓨즈·OTP, 보호 비트, 부트로더 덮어쓰기, 디버그 포트 잠금은 사람이 대상 장치와 이미지를 확인한 뒤 실행한다. 프로그래머·시리얼 제어 도구는 읽기 전용부터 연결하고 권한·훅으로 쓰기 명령을 차단한다.
- **변경 후 검증을 강제한다.** 호스트 단위 테스트와 정적 분석을 직접 돌려 출력을 읽고, 경고를 억제하라는 제안은 따르지 않는다. 실제 보드에서 확인하지 못했으면 "하드웨어 미검증"이라고 쓴다.
- **펌웨어 소스·로그·서명 키·양산 이미지를 API로 보내지 않는다(약관 확인 전).** 싱가포르 법인·미국 저장이라는 독립 안내와 중국을 가리키는 오래된 정책이 충돌하고 포괄적 학습 제외 약속이 확인되지 않는다. [부분, 충돌] 서명 키와 디버그 인증 정보는 약관과 무관하게 보내지 않는다(§3.4). 수출 통제·고객 계약상 국외 이전이 제한된 코드는 법무 확인 전에 보내지 않는다.
- **임베디드 제품에 모델 가중치를 포함하지 않는다.** 428B라 불가능하며 커뮤니티 라이선스의 용도 금지 조항(군사 등)이 제품 사용처에 걸릴 수 있다. 서버 쪽 도구에서만 쓴다(general.md §2.2). [부분: 2차 요약/미확인]
