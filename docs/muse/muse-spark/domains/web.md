## 2. 이 모델의 웹 작업 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: 폐쇄형 API 모델(버전이 1.1→1.2→1.3으로 계속 갱신), 컨텍스트 100만 토큰, 입력 $1.25 / 출력 $4.25, 1.3은 토큰 절감 주장과 반대로 작업당 비용이 올랐다는 독립 보고, 독립 지수 값 충돌, 데이터 약관 불분명.

- **웹 UI 생성 품질의 독립 평가는 찾지 못했다.** [미확인] 검색에서 나온 것은 출시 홍보, 벤치마크 인용, 접근 방법 안내뿐이었다. 한 안내 글이 풀스택 앱 개발을 용도로 든 것은 마케팅성 서술이다. 컴포넌트 단위 수정, 새 화면, 스크린샷 재현을 우리 코드베이스에서 상위 모델과 같은 조건으로 돌려 비교하고, 스크린샷 대조와 린터·타입체크·테스트 출력으로 판정한다. 기존 UI 체계가 우선한다(§3.1).
- **Meta의 코딩 대표 수치는 일반 제공 단계보다 높은 노력으로 잰 것이다.** 1.3의 DeepSWE 75.4%는 `max` 단계 결과이고 개발자가 쓸 수 있는 최고는 `xhigh`다. 이 점수를 웹 개발 능력으로 옮기지 않는다. [부분: 벤더 주장]
- **과제당 비용을 직접 잰다.** 단가가 1.2와 같아도 AA는 1.3이 에이전트 평가에서 입력 토큰을 약 57% 더 써서 작업당 비용이 $0.40에서 $0.55로 올랐다고 했다. 컴포넌트 수정 한 건당 입력·출력 토큰과 도구 호출 수를 기록한다. [부분]
- **Muse Code(터미널 코딩 에이전트)를 쓰려면 권한 경계를 먼저 둔다.** 파일 쓰기·셸 실행 범위, 작업 디렉터리, 파괴적 명령 차단(권한·훅)을 설정하고, 완료 보고는 린터·타입체크·테스트 출력과 `git diff`로 확인한다. Muse Code는 8월 초 베타로 시작했으므로 동작이 바뀔 수 있다. [부분]
- **버전을 고정한다.** 1.1(7월), 1.2(8월), 1.3(9월)로 한두 달마다 갱신됐다. UI 생성 프롬프트와 템플릿의 회귀 시험(스냅샷·시각 비교)을 업데이트 전후에 돌리고, 구버전 폐기 일정을 공식 문서로 확인한다. [부분]
- **보안·접근성 판단을 맡기지 않는다.** 인가, 입력 검증, 비밀 노출, 접근성 "충족" 여부는 도구 출력과 §3.1 기준으로 사람이 점검한다. API·CSS·브라우저 지원은 공식 문서와 린터·컴파일러 출력으로 확인한다.
- **미공개 소스를 보내기 전에 약관을 확인한다.** 데이터 처리 서술이 충돌하고 보관 기간·영 보관 등급이 공개돼 있지 않다(README.md가 안내하는 개요·운용 문서.4). [미확인] 값싼 "Contributor" 등급($0.10/$0.20)은 트래픽이 학습에 쓰일 수 있다는 서술이 있어 제품 코드·고객 데이터에는 쓰지 않는다. 확인 전에는 비밀·고객 데이터가 담긴 코드를 보내지 않는다(§1.6).
- **오픈 가중치(Spark Open)로 직접 호스팅하면 제품에 표기 의무가 생길 수 있다.** "Built with Muse Spark Open" 표시 서술이 있다. 라이선스 원문을 확인한다(README.md가 안내하는 개요·운용 문서.5). [부분/미확인]
