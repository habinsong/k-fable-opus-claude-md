## 2. 이 모델의 하드웨어 작업 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: 폐쇄형 API 모델, 이미지 입력(비전 수치는 오픈 변형의 자체 보고), 컨텍스트 100만 토큰, 환각 수치는 벤더 보고, 하드웨어 설계 평가 없음, 데이터 약관 불분명.

- **설계 판단에 쓰지 않는다.** 핀 배치, 정격, 타이밍, 수식은 틀리면 보드가 망가지거나 위험해진다. 이 모델의 회로·PCB·HDL 평가는 찾지 못했다. [미확인] 종합 지수나 코딩 점수가 높아도 회로 설계 정확도를 대표하지 않는다. 설계는 `gemini-4-argon`, `claude/opus-5.5`, `gpt-6.1-sol` 같은 상위 모델 문서나 `muse-wonder` 문서를 따르고, 그 결과도 데이터시트 원문과 도구 계산으로 확인한다.
- **비전 수치를 데이터시트·회로도 판독 능력으로 옮기지 않는다.** BabyVision 80.2%, SimpleVQA 73.6%, ZeroBench(도구 포함) 50%는 Muse Spark Open의 Meta 자체 보고이고 폐쇄형 Spark의 값이 아니다. Meta의 멀티모달 점수는 ZeroBench, WorldVQA, SimpleVQA, CharXiv 등 10개 벤치마크의 평균으로 정의된다고 한다. 작은 글씨의 핀 표, 타이밍 다이어그램, 회로도의 정확도를 측정한 자료는 찾지 못했다. [부분: 벤더·변형 혼동 주의/미확인]
- **환각 수치는 벤더 보고이고 한 가지 시험이다.** 이미지가 빠진 CharXiv 질문에서 환각률 35.0%가 비교 모델 가운데 최고라는 Meta의 보고가 있다. 이는 "그림이 없는데 있다고 답하는" 한 상황의 비율이지 부품 번호·정격을 기억에서 정확히 꺼내는 능력이 아니다. 부품 번호, 핀 번호, 레지스터 주소, 정격을 모델 기억에서 가져오게 하지 않는다. [부분: 벤더 주장]
- **값은 사람이 확보한 데이터시트 텍스트에서만 꺼낸다.** 값마다 문서명·개정판·페이지를 같이 받아 원문 PDF와 한 건씩 대조하고, 원문에 없으면 null이다(§3.1). 컨텍스트가 100만 토큰이어도 필요한 장과 표만 넣는다. 이미지에서 읽은 값은 원문 텍스트·넷리스트·ERC 보고서와 반드시 대조하고, 읽기 어려운 부분은 추측하지 말고 "판독 불가"로 표시하게 한다.
- **써도 되는 작업.** BOM 정규화, 부품 번호 목록 변환, 시험 로그 분류, 데이터시트 텍스트에서 정해진 필드 추출, 측정·변환 스크립트(파이썬)의 초안. 스크립트는 알려진 값을 넣어 실행해 확인한다.
- **계산은 도구로 한다.** 전류 예산, 분압, 필터, 열 계산은 스크립트·시뮬레이터 출력으로 확인하고 식과 가정을 남긴다. 추론 모드(`xhigh` 등)로 낸 풀이도 마찬가지다.
- **미공개 설계 자료를 API로 보내지 않는다(약관 확인 전).** 데이터 처리 서술이 충돌하고 보관 기간이 공개돼 있지 않다. [미확인, 충돌] 회로도·레이아웃·펌웨어 이미지·부품 공급 정보는 영업비밀이므로 원문 약관을 읽고 승인받은 뒤에만 보낸다. 값싼 "Contributor" 등급은 트래픽이 학습에 쓰일 수 있다는 서술이 있어 쓰지 않는다.
- **인체·화재 위험 설계는 "안전하다"고 단정하지 않는다.** 고전압·대전류·배터리·모터는 사람의 검토를 요청한다.

## 4. 근거와 한계
- 비전·환각 수치(Meta 자체 보고, 오픈 변형 포함): [Muse Spark Safety & Preparedness Report](https://arxiv.org/pdf/2606.12429), [Muse Spark 1.2 멀티모달 평가 방법론](https://research.meta.ai/static/muse-spark-1-2-multimodal-evaluation-methodology), [BenchmarkList: Muse Spark Open](https://benchmarklist.com/models/meta-muse-spark-open/) (스니펫만, arxiv.org는 이 환경에서 열리지 않음) [부분: 벤더·집계]
- 한계: 하드웨어 설계와 데이터시트 판독에 대한 평가가 없다. "쓰지 않는다"는 일반 지표의 부재에서 도출한 보수적 권고다.
