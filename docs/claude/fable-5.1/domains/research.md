## 2. 이 모델의 연구 작업 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: 긴 컨텍스트와 다단계 조사에 강점이라고 설명됨, 요약에서 인용 표시를 빼먹을 수 있음, 생성 텍스트에 워터마크.

- **어려운 추론과 긴 자료 종합에 쓴다.** 이 모델은 어려운 추론과 장시간 작업용으로 위치가 정해져 있고, 1M 컨텍스트 전 구간이 표준 요금이다. [확인] 긴 논문 묶음에서 세부를 연결하는 능력은 Anthropic의 설명이다. [확인: 벤더 서술] 모델이 연결한 주장은 해당 논문의 해당 위치를 직접 열어 확인한다.
- **인용은 필드 단위로 검증한다.** 26개 LLM을 비교한 2026년 연구에서 검증 가능한 참고문헌 중 모든 필드가 맞은 비율은 48.3%였고 저자 목록이 가장 약했다(51.7%). Fable 5.1에 대한 별도 측정은 찾지 못했다. [부분/미확인] Crossref·DataCite·원문에서 제목·저자·연도·권호를 대조하고 인용한 주장이 실제로 있는지 읽어서 확인한다. 확인하지 못한 항목은 목록에서 분리한다.
- **원문 구절을 표시 없이 옮기지 않는다.** 요약 중 원문 문장을 따옴표 없이 옮기는 경향이 보고됐다. [확인] 저작권·표절 규칙(§1.5)에 따라 요약은 자기 말로 쓰고 직접 인용은 짧게 따옴표로 표시한다. 보고서를 내기 전에 원문과 겹치는 긴 구절을 검사한다.
- **분석은 코드를 다시 실행해서 확인한다.** 추론이 항상 켜져 있다고 결과가 맞는다는 보장은 없다. 통계 설명이나 결론은 근거가 아니다. 시드, 데이터 버전, 라이브러리 버전을 기록하고, 이상치 제거·필터·검정 기준이 결과에 맞춰 바뀌지 않았는지 `git diff`로 확인한다.
- **테스트나 기대값에 맞추는 해법을 경계한다.** 분석 코드가 특정 입력에서만 맞게 하드코딩되지 않았는지 확인한다. 작업이 불가능하거나 기대값이 틀렸으면 우회하지 말고 알리게 한다. [확인]
- **긴 산출물은 `max_tokens`를 넉넉히.** `xhigh`·`max`에서 논문 전체 같은 긴 산출물을 시키면 생각 속에서 초안을 쓰고 다시 쓰므로 시간이 늘고 잘릴 수 있다. `high`로 돌리거나 한도를 크게 잡는다. [확인]
- **AI 사용 고지.** 출력 텍스트에 워터마크가 들어간다. 투고 대상(학술지·arXiv)의 AI 사용 정책을 확인하고 따른다. arXiv는 검증 없는 LLM 출력의 명백한 증거에 대해 제출 금지를 적용한다고 발표했다. [확인(워터마크) / 부분(정책)]
- **전문 영역(의료, 법률, 안전) 결론에는 "전문가 검토 필요"를 붙인다.** 안전장치는 생물학 관련 질문을 막을 수 있다. 정당한 생명과학 연구는 Anthropic 검증 프로그램을 확인한다. [확인]
- **비용.** 입력 $10 / 출력 $50이므로 문헌 분류·서식 변환 같은 단순 작업은 Haiku 5.5나 Sonnet 5.5로 한다.
