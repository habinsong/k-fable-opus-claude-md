#### 2.1 위치와 사양
- "대량·지연에 민감한 작업(분류, 추출, 라우팅, 하위 에이전트, 요약, 브라우저 사용)"용이다. 가격은 입력 $0.10부터 / 출력 $0.50부터(100만 토큰당)이고 "부터"의 기준은 긴 프롬프트 요금이다. 컨텍스트 1M, 최대 출력 128K, 지식 컷오프 2026-06. 공식 가격 페이지(2026-11-03에 직접 읽음)는 프롬프트가 100,000 토큰을 넘는 요청을 입력 $0.50 / 출력 $2.50(캐시 읽기 $0.05)으로 받는다. 프롬프트 길이에는 캐시 읽기·쓰기 토큰도 들어가고 요청마다 따로 계산한다. [확인: 공식 가격 페이지, [`xcheck.md`](xcheck.md) 참조]
- 기본 effort는 **`medium`**이고 Haiku 중 처음으로 effort 레벨(`low` / `medium` / `high` / `xhigh` / `max`)을 가진다. 적응형 추론이 기본이고, 추론을 끄려면 `thinking: {"type":"disabled"}`를 `high` 이하에서만 쓸 수 있다. 토크나이저는 Haiku 4.5보다 같은 글에서 약 30% 더 많은 토큰을 낸다. 최소 캐시 가능 프롬프트는 512토큰이다.
