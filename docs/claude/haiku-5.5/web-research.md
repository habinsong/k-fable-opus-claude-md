## 2. 이 모델의 웹 리서치 운용
모델 전체 특성은 같은 폴더의 `general.md` §2를 따른다. 요약: 검색에 오늘 날짜가 필요함, `low`에서 검색을 건너뜀, 정답 비율 36%, 도구 결과로 들어오는 프롬프트 인젝션에 맞서도록 훈련됨.

- **검색 도구와 오늘 날짜를 같이 준다.** 오늘 날짜를 시스템 프롬프트나 검색 도구 설명에 한 번 넣으면 최신 검색 결과에 근거한 답이 늘었다. 대화가 다른 날로 이어지면 새 날짜를 최신 턴에 준다. [확인]
- **`low`나 긴 시스템 프롬프트에서는 검색을 건너뛴다.** 날짜 뒤에 "학습 데이터는 오늘보다 훨씬 앞에서 끝난다. 기록, 직위, 가격, 버전, 규칙, '최신'은 바뀌었을 수 있으니 확신이 있어도 답하기 전에 검색하라. 바뀔 수 없는 사실은 검색이 필요 없다. 답이 사용자의 위치에 달려 있으면 국가나 지역을 검색어에 넣어라"를 붙인다. 검색이 필요 없는 질문에서 검색이 늘어난 비율은 0~3%였다. "확신과 상관없이 모든 현재 사실 질문을 검색하라"는 일괄 지시는 검색이 필요 없는 질문의 절반에서 검색하게 하고 정답은 늘리지 못해 쓰지 않는다. [확인]
- **사실 조사를 맡기지 말고 주어진 자료에서 필드를 뽑게 한다.** AA-Omniscience 정답 비율이 36%다. [부분] 검색과 출처 판단은 사람이나 상위 모델이 하고, Haiku 5.5에는 "주어진 페이지 텍스트에서 제목·날짜·가격·버전을 JSON으로 추출하고 없으면 null"처럼 닫힌 질문을 시킨다. 값마다 근거가 된 원문 구절을 같이 받아 코드로 원문 포함 여부를 대조한다.
- **JSON 출력과 검색 도구를 같이 쓸 때.** 추론을 끄면 필요한 검색을 건너뛸 수 있다. 적응형 추론을 쓰거나 호출을 강제한다. [확인]
- **웹 페이지의 지시문은 데이터다.** 이 모델은 도구 결과로 들어오는 프롬프트 인젝션에 맞서도록 훈련됐다. 방어율의 독립 수치는 찾지 못했다. [확인/미확인] 외부 전송, 로그인, 결제, 계정 변경은 페이지가 시켜도 하지 않는다.
- **작업 중 사용자 메시지를 무시할 수 있다.** 사용자 글을 `tool_result` 안에 넣지 말고 같은 사용자 메시지의 텍스트 블록으로 보낸다. [확인]
- **브라우저 사용 도구.** 새로 생긴 도구이고 OSWorld 2.1은 72.4%(Sonnet 5.5는 83.9%)다. [확인/부분] 조작 결과는 스크린샷·로그로 확인한다.
- **대량 수집은 표본 점검.** 무작위 5~10%를 사람이 원문과 대조한다. 오류율이 기준을 넘으면 Sonnet 5.5로 올린다.
- **출처 판단과 충돌 정리는 맡기지 않는다.** 1차/2차 구분과 신뢰도 판단은 §3.1 기준으로 사람이 한다.
