## 2. 이 모델의 펌웨어 작업 운용 (잠정)
2026-11-03 기준 Fable 5.5는 공식 목록에 없다. 모델 상태와 출시일 체크리스트는 같은 폴더의 `general.md` §2를 따른다. 출시 전에는 `claude/fable-5.1/firmware.md`를 적용한다.

**출시 후 펌웨어 작업에서 따로 확인할 것**
- 자율 진행 지침과 정지점. Fable 5.1은 "되돌릴 수 있는 일은 묻지 말고 진행, 파괴적 동작에서만 멈춰라"는 블록이 필요했다. 5.5에서 이 블록 없이도 중간에 멈추는지, 반대로 이 블록으로 파괴적 동작을 멈추는 범위가 바뀌는지 확인한다. 이 저장소의 정지점(플래시 소거, 퓨즈·OTP, 보호 비트, 부트로더 덮어쓰기, 디버그 포트 잠금, 양산 이미지 서명)은 모델이 바뀌어도 목록으로 고정한다.
- 상태를 바꾸는 명령 전에 증거를 확인하는 습관. 로그 속 알려진 고장과 비슷한 신호에 반응해 설정을 바꾸지 않는지 브링업 사례로 시험한다.
- 도구 출력이 사용자 화면에 보이지 않는 구성에서 모델이 출력을 다시 보여 주려고 불필요한 명령을 실행하지 않는지.
- 작업 중 설명의 양. HIL 실행 중 보드에 쓰기 직전의 의도 설명이 나오는지, 아니면 침묵하는지.
- 안전장치. 펌웨어 바이너리 분석 같은 사이버 인접 작업이 거부되는지, 어느 범주로 거부되는지.
- 레지스터·타이밍 기억 의존. 알려진 정답이 있는 레지스터 질문으로 5.5의 기억 답과 데이터시트를 대조한다.
- 장시간 세션 요약에서 레지스터 값·주소·클럭 설정이 의역되지 않는지.

**잠정 운용**
- 출시 전 펌웨어 작업은 Fable 5.1과 Opus 5.5로 진행한다. 실제 보드에서 확인하지 못했으면 "하드웨어 미검증"이라고 쓴다.
