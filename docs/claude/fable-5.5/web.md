## 2. 이 모델의 웹 작업 운용 (잠정)
2026-11-03 기준 Fable 5.5는 공식 목록에 없다. 모델 상태와 출시일 체크리스트는 같은 폴더의 `general.md` §2를 따른다. 출시 전에는 `claude/fable-5.1/web.md`를 적용한다.

**출시 후 웹 작업에서 따로 확인할 것**
- Fable 5.1은 작은 수정에도 파일 전체를 다시 쓰려는 경향이 있어 "필요한 부분만 고쳐라"가 필요했다. 5.5에서도 이 경향이 남아 있는지 `git diff --stat`으로 확인한다. [Fable 5.1 기준 확인 / 5.5 미확인]
- Fable 5.1은 요청하지 않은 근처 코드 수정과 테스트 파일을 덧붙이는 경향이 있었다. 범위 억제 지시 없이 같은 과제를 돌려 이 경향의 변화를 본다.
- 프런트엔드 기본 디자인 수렴 패턴이 바뀌었는지 확인한다. 기존 프로젝트에서는 기존 UI 체계가 우선한다는 규칙(§3.1)은 모델이 바뀌어도 유지한다.
- 진행 알림이 어디로 오는지(`thinking` 블록, `display` 옵션)를 확인한다. UI가 작업 중 침묵하지 않는지 점검한다.
- 이미지 입력(스크린샷 검수)에서 자르기·확대 도구가 여전히 필요한지 같은 화면으로 비교한다.
- 서버 쪽 인가, 입력 검증, 비밀 노출 점검은 모델의 자기 판단이 아니라 도구 출력으로 확인한다는 원칙은 그대로다.

**잠정 운용**
- 출시 전 평가는 Opus 5.5(기본 `medium`)를 기준선으로 한다. 공식 발표와 독립 측정이 나오기 전에는 5.5를 웹 작업의 기본으로 지정하지 않는다.
- 출시 후에도 Fable 5.1과 같은 과제로 effort 레벨별 작업당 토큰과 비용을 비교한다.
