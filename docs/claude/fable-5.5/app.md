## 2. 이 모델의 앱 작업 운용 (잠정)
2026-11-03 기준 Fable 5.5는 공식 목록에 없다. 모델 상태와 출시일 체크리스트는 같은 폴더의 `general.md` §2를 따른다. 출시 전에는 `claude/fable-5.1/app.md`를 적용한다.

**출시 후 앱 작업에서 따로 확인할 것**
- 컴퓨터 사용(시뮬레이터·에뮬레이터 조작)의 도구 버전. Opus 5.5·Sonnet 5.5·Haiku 5.5는 `computer_toolset_20260801`을 쓰고 이전 버전이 Claude API에서 400이다. Fable 5.1에 대해서는 직접 확인하지 못했다. 5.5가 지원하는 도구 버전을 이행 가이드에서 확인한다.
- 낮은 effort에서 검색을 덜 하고 기억으로 답하는 경향(Fable 5.1)이 남아 있는지. 스토어 정책 같은 최신 사실을 `low`에서 묻는 과제로 확인한다.
- 토크나이저 변경 여부. 빌드·테스트 로그 예산과 `max_tokens`가 달라진다.
- 독립 호출을 한 턴에 묶는지, 턴마다 하나씩 보내는지. bash·편집기 하네스에서 같은 과제로 턴 수를 센다.
- 하위 에이전트를 쓸 때 리드가 기다리지 않는 구성이 여전히 이득인지.
- 데이터 보관·ZDR 조건. 사용자 데이터가 섞인 코드·로그를 보내기 전에 확인한다.
- 서명 키, 프로파일, 스토어 제출·배포는 모델이 바뀌어도 사람이 승인한 뒤에만 한다.

**잠정 운용**
- 출시 전 앱 작업은 Opus 5.5·Sonnet 5.5로 평가를 진행한다. 5.5를 바로 기본으로 지정하지 않는다.
