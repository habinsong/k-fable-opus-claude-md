## 2. 이 모델의 하드웨어 작업 운용 (잠정)
2026-11-03 기준 Fable 5.5는 공식 목록에 없다. 모델 상태와 출시일 체크리스트는 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 출시 전에는 `claude/fable-5.1/hardware.md`를 적용한다.

**출시 후 하드웨어 작업에서 따로 확인할 것**
- 컨텍스트 요금 구조. Fable 5.1은 1M 토큰 전 구간이 표준 요금이라 데이터시트 여러 권을 한 번에 읽혀도 할증이 없었다. 5.5에서도 같은지 가격 페이지에서 확인한다. 다른 제공자는 약 27만 토큰을 넘으면 요청 전체에 할증이 붙는 경우가 있다.
- 비전 정확도. 핀 배치표·타이밍 다이어그램·밀도 높은 차트를 자르기·확대 도구 없이 읽히고 원문 PDF의 같은 페이지와 대조해, 오독 비율이 줄었는지 직접 센다. 벤더 설명은 측정이 아니다.
- 낮은 effort에서 부품 사양을 기억으로 답하는 경향. 알려진 정답이 있는 부품 질문(데이터시트로 확인 가능한 것)으로 측정한다.
- 계산 오류율. 알려진 정답이 있는 레퍼런스 회로의 전류 예산·분압·필터 계산으로 5.5의 답을 점검한다.
- 비용. 입력 $10 / 출력 $50이던 Fable 5.1 대비 가격이 바뀌었는지 확인하고, 반복 작업은 Opus 5.5·Sonnet 5.5로 처리할 수 있는지 비교한다.
- 인체·화재 위험 설계는 모델이 바뀌어도 "안전하다"고 단정하지 않는다. 인증 통과 여부는 시험 결과로만 말한다.

**잠정 운용**
- 출시 전 하드웨어 작업은 Fable 5.1과 Opus 5.5로 진행한다. 데이터시트 값은 모델의 기억이 아니라 원문에서 가져온다.
