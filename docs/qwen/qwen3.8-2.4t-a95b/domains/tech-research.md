## 2. 이 모델의 기술 조사 운용, 그리고 이 모델을 평가할 때
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: 공개 가중치(텍스트 전용, 이미지 입력·비추론 모드 없음), 자체 라이선스(모델 제공자 조항), 전체 가중치 TB 규모, 이 체크포인트의 독립 평가 없음, 호스트 경유가 현실적.

**이 모델에게 기술 조사를 시킬 때**
- 분류·정리 단계에만 쓴다. 후보를 정해진 기준(라이선스 유형, 지원 언어, 릴리스 날짜)으로 분류해 표로 만들 때, 값은 사람이 확보한 1차 자료 텍스트에서 추출하게 하고 원문에 없으면 null로 둔다.
- 라이선스 호환성, 특허, 규정 적용 여부, 도입 권고는 단정시키지 않는다(§3.2, §3.5). 후보를 지나치게 높게 평가하는 경향(아첨)은 측정된 바 없으므로 사람이나 상위 모델이 근거를 보고 판단한다.

**Qwen3.8-2.4T-A95B를 도입 후보로 평가할 때**
- **어느 Qwen3.8인지 구분한다.** API 전용 `qwen3.8-max`(비전 포함, 네이티브 100만 컨텍스트), 이 체크포인트(텍스트 전용, 네이티브 262,144, 자체 라이선스), `qwen3.8-27b`(밀집 VLM, Apache 2.0이라는 서술)는 서로 다른 모델이다. 한 자료의 점수와 라이선스를 다른 모델에 옮기지 않는다. 일부 보도는 이 체크포인트를 "가중치가 공개된 첫 Qwen-Max급"이라 부르는데 API Max 자체의 가중치가 공개됐다는 뜻이 아니다. [부분, 충돌]
- **라이선스를 원문으로 확인한다 — 이 모델 도입의 최우선 항목이다.** 자체 "Qwen3.8-Max" 라이선스이고 2차 요약에 따르면 12개월에 5,000만 달러를 넘게 버는 모델 제공자는 Alibaba Cloud의 상업 라이선스가 필요하며 일부 매우 큰 제품에는 표시 의무가 있다. 임계값·모델 제공자 정의·파생 모델(미세조정, 증류) 조건은 LICENSE 원문(공식 저장소)으로 확인한다. "가중치 공개"를 "오픈소스"나 "자유로운 상업 이용"으로 읽지 않는다(§3.2). [부분: 2차 요약/미확인]
- **독립 평가가 없다.** 이 체크포인트의 독립 지수와 벤더 수치를 찾지 못했다. 클라우드 Max의 값(독립 지수 45~58, Terminal-Bench 2.1 86.6)을 옮기지 않는다. 도입 시험은 같은 과제로 직접 하고 비교 대상에 `qwen3.8-27b`와 상위 모델을 넣는다. [미확인]
- **총비용은 운영비까지 포함한다.** 전체 가중치가 약 4.89 TB, 4비트에서도 약 1.5 TB급(계산기 추정), 1비트에서도 400 GB 이상이다. GPU 노드 임대·전력·운영 인력과 호스트 서비스 가격, API Max($2/$6) 가격을 과제당으로 비교한다. 직접 호스팅이 타당한 경우는 데이터를 외부로 보낼 수 없고 이 규모가 필요한 경우로 제한된다. [부분, 충돌/추정]
- **호스트 경유 시 데이터 거버넌스는 호스트가 정한다.** 호스트의 학습 사용·보관·지역 조건을 원문으로 읽고 법무·보안 검토를 거친다. 이 체크포인트를 쓰는 호스트가 여럿일 수 있어 호스트별 조건이 다르다. [부분]
- **공급 연속성.** 발표(8월 3일)와 가중치 공개(8월 12일)가 다르고 날짜 서술이 갈린다. 공식 저장소의 커밋 해시를 고정하고 모델 교체 절차, 폴백 모델, 회귀 시험을 도입 조건으로 둔다. [부분]
- **공급망.** 공식 조직 저장소에서만 받고 제3자 재업로드와 양자화 변환본은 출처를 확인하기 전에는 쓰지 않는다. [추정]
- **제공자 안전장치와 규정.** 공개 가중치에는 제공자 쪽 안전장치가 없다. 입력 필터, 출력 검증, 권한 제한을 직접 구축하고 규제 적합성은 시스템 전체에 대해 판단한다.
