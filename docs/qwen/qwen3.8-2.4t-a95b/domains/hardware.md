## 2. 이 모델의 하드웨어 작업 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: 공개 가중치(텍스트 전용), 독립 평가 없음, 환각 값 미확인, 하드웨어 설계 평가 없음, 자체 호스팅 시 데이터가 외부로 나가지 않으나 TB 규모 장비 필요.

- **설계 판단에 쓰지 않는다.** 핀 배치, 정격, 타이밍, 수식은 틀리면 보드가 망가지거나 위험해진다. 이 모델의 회로·PCB·HDL 평가는 찾지 못했다. [미확인] 클라우드 Max의 독립 평가 점수(45~58)와 코딩 점수는 이 체크포인트의 값이 아니며 회로 설계 정확도를 대표하지도 않는다. 설계는 `gemini-4-argon`, `claude/opus-5.5`, `gpt-6.1-sol` 같은 상위 모델 문서와 같은 과제로 비교하고, 그 결과도 데이터시트 원문과 도구 계산으로 확인한다.
- **값 회상을 믿지 않는다.** 환각·사실성 값을 찾지 못했다. [미확인] 부품 번호, 핀 번호, 레지스터 주소, 정격을 모델 기억에서 가져오게 하지 않는다. 값은 사람이 확보한 데이터시트 텍스트에서만 꺼내게 하고, 값마다 문서명·개정판·페이지를 같이 받아 원문 PDF와 한 건씩 대조한다. 원문에 없으면 null이다(§3.1).
- **이미지(회로도·PCB 사진) 판독은 이 체크포인트로 할 수 없다.** 텍스트 입력만 지원한다. 회로도·데이터시트 그림은 텍스트(넷리스트, ERC 보고서, 표 텍스트)로 변환해 주거나 비전 모델(`qwen3.8-27b` 등)과 사람이 처리한다. [부분]
- **데이터가 밖으로 나가지 않는 정리 작업이 이 모델의 유일한 이점이다.** 자체 인프라에 올리면 미공개 설계 자료를 외부 API로 보내지 않고 BOM 정규화, 부품 번호 목록 변환, 시험 로그 분류, 데이터시트 텍스트에서 정해진 필드 추출, 측정·변환 스크립트 초안을 할 수 있다. 다만 4비트에서도 약 1.5 TB급(계산기 추정), 1비트에서도 400 GB 이상의 장비가 필요해 이런 보조 작업에는 과하다. 소형 모델(`qwen3.8-27b`, `gemma-4-26b-a4b`)로 같은 작업을 시험한다. [부분, 충돌/추정]
- **호스트 서비스를 쓰면 설계 자료가 호스트로 나간다.** 호스트의 학습 사용·보관 조건을 원문으로 읽고 법무·보안 승인을 받은 뒤에만 보낸다. 회로도·레이아웃·펌웨어 이미지·부품 공급 정보는 영업비밀이다. [부분]
- **계산은 도구로 한다.** 전류 예산, 분압, 필터, 열 계산은 스크립트·시뮬레이터 출력으로 확인하고 식과 가정을 남긴다. 추론 모드로 낸 풀이도 마찬가지다.
- **인체·화재 위험 설계는 "안전하다"고 단정하지 않는다.** 고전압·대전류·배터리·모터는 사람의 검토를 요청한다.
