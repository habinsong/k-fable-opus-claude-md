## 2. 이 모델의 웹 작업 운용
모델 전체 특성은 같은 폴더의 `general.md` §2를 따른다. 요약: 공개 가중치(텍스트 전용, 이미지 입력·비추론 모드 없음), 자체 라이선스(모델 제공자 조항), 전체 가중치 TB 규모, 이 체크포인트의 독립 평가 없음.

- **웹 UI 생성의 독립 평가는 찾지 못했다.** [미확인] API Max의 수치를 이 체크포인트에 옮기지 않는다. 컴포넌트 단위 수정, 새 화면 생성을 우리 코드베이스에서 상위 모델과 같은 조건으로 돌려 비교하고 린터·타입체크·테스트 출력으로 판정한다. 기존 UI 체계가 우선한다(§3.1).
- **스크린샷 입력은 불가능하다.** 텍스트 입력·텍스트 출력만 지원하므로 디자인 시안·스크린샷 재현 작업에는 이 체크포인트를 쓰지 않는다. 시각 입력이 필요하면 API 전용 `qwen3.8-max`나 `qwen3.8-27b`(비전 언어 모델), 상위 모델 문서를 본다. 시각 검수는 사람이나 별도 모델이 한다. [부분]
- **비추론 모드가 없으면 단순 수정에도 추론 비용이 든다.** 클라우드 Max에 있는 비추론 모드가 없다는 서술이 있다. 작은 CSS 수정 같은 일에는 지연·토큰이 과할 수 있으므로 작은 모델이나 `qwen3.8-27b`로 라우팅하는 방안을 시험한다. [부분/추정]
- **직접 호스팅은 웹 개발 보조용으로 타당성이 낮다.** 4비트에서도 약 1.5 TB급 메모리 추정, 1비트에서도 400 GB 이상이다. 호스트 서비스를 쓰면 데이터 처리 조건은 호스트 약관이 정한다. [부분, 충돌]
- **보안·접근성 판단을 맡기지 않는다.** 인가, 입력 검증, 비밀 노출, 접근성 "충족" 여부는 도구 출력과 §3.1 기준으로 사람이 점검한다. API·CSS·브라우저 지원은 공식 문서와 린터·컴파일러 출력으로 확인한다.
- **라이선스를 확인하고 쓴다.** 모델 제공자 조항(12개월 5,000만 달러 초과 시 상업 라이선스라는 2차 요약)은 웹 서비스에 모델을 노출하는 형태에 영향을 줄 수 있다. 원문을 읽기 전에는 사용자에게 모델 접근을 제공하는 제품에 넣지 않는다(general.md §2.2). [부분/미확인]
