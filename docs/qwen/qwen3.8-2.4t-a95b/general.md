## 2. 모델 특성 — Qwen3.8-2.4T-A95B (공개 가중치, 텍스트 전용)
이 환경에서는 Hugging Face와 Alibaba 공식 문서가 열리지 않아 검색 스니펫과 2차 출처로 썼다. 별도 표기가 없으면 [부분]이다. API 전용 `qwen3.8-max`와 같은 세대지만 별개 모델이다(`qwen3.8-max` 문서).

### 2.1 위치와 공개 상태
- Qwen3.8-Max 세대의 공개 가중치 체크포인트로, 총 약 2.4조 파라미터 MoE에 활성 약 950억이다. 발표는 2026-08-03이고 가중치는 8월 12일에 올라왔다는 서술이 있으며 Vercel은 8월 3일이라고 적어 날짜가 갈린다. [부분, 충돌]
- **클라우드 Max와 기능이 다르다.** 공개 체크포인트는 텍스트 입력·텍스트 출력만 지원하고 이미지 입력과 비추론(non-thinking) 모드가 없다는 서술이 있다. 한 보고는 추론 모드가 필수라고 하나 다른 곳에서 그 근거를 찾지 못했다. 컨텍스트는 네이티브 262,144 토큰(확장 시 약 100만 1만 토큰이라는 서술)이며 API Max의 100만 네이티브와 다르다. [부분, 충돌]
- Hugging Face·ModelScope 외에 Vercel AI Gateway 같은 호스트가 제공한다. [부분]

### 2.2 라이선스 — Apache 2.0이 아니다
- 자체 "Qwen3.8-Max" 라이선스를 쓴다는 서술이 있다. Vercel FAQ는 12개월에 5,000만 달러를 넘게 버는 **모델 제공자(model provider)**가 Alibaba Cloud의 상업 라이선스를 받아야 한다고 요약하고, 일부 매우 큰 제품에는 표시 의무가 추가된다는 보도가 있다. 이는 모두 2차 요약이고 라이선스 본문을 읽지 못했다. [부분: 2차 요약, 원문 미확인]
- → 모델 서비스를 제공하거나 재판매하는 형태라면 법무가 LICENSE 원문(공식 저장소)으로 임계값·정의·표시 의무를 확인한다. 내부 사용만 하는 경우도 원문을 읽기 전에는 "상업 이용 가능"으로 단정하지 않는다(§1.5). `qwen3.8-27b`와 라이선스가 다를 수 있으므로 혼동하지 않는다.

### 2.3 하드웨어 — 사실상 대규모 노드 전용
- 전체 가중치가 약 4.89 TB(Vercel)라는 서술, 4비트 빌드(Q4_K_M) VRAM 약 1,468 GB라는 계산기 추정(llmrun, 검증된 측정이 아님), 1비트에서도 최소 약 400 GB라는 서술이 있다. 소비자 GPU 한 장으로는 불가능하고 다중 GPU·전문 장비가 필요하다. 전체 체크포인트 실행 요건이 공식적으로 상세히 공개되지 않았다는 글도 있다. [부분, 충돌]
- 현실적인 사용 경로는 호스트 서비스 경유이며, 그 경우 데이터 처리 조건은 호스트의 약관이 정한다.

### 2.4 성능·평가
- 이 가중치 체크포인트 자체의 독립 평가는 찾지 못했다. API Max의 독립 지수(45~58)와 벤더 수치를 이 체크포인트의 성능으로 옮기지 않는다. 비전과 비추론 모드가 빠졌고 컨텍스트도 다르다. [미확인]
- 환각·도구 호출 오류율의 독립 측정도 찾지 못했다. [미확인]

### 2.5 운용
- **공식 저장소에서만 받고 해시를 확인한다.** 제3자 재업로드와 양자화 변환본은 출처·변조를 확인하기 전에는 쓰지 않는다. 로더가 신뢰하지 않는 코드를 실행하지 않는 형식을 쓰고 격리 환경에서 시험한다. [추정]
- **직접 호스팅 비용을 먼저 계산한다.** 4비트에서도 TB 단위 메모리가 필요하다. API Max($2/$6)나 호스트 가격과 비교해 직접 호스팅이 비용·운영 면에서 타당한지 따진다. [추정]
- **지침은 짧게.** 이 문서의 §0과 §1.2·§1.3·§1.6을 시스템 프롬프트에 두고 분야 규칙은 필요한 작업에 붙인다. 한국어 존댓말 준수는 직접 측정한다. [미확인]

### 2.6 비판적 평가
- 강점 후보: 가중치를 자체 인프라에 둘 수 있다(데이터가 외부로 나가지 않음), 활성 파라미터 대비 큰 용량. 약점 후보: 자체 라이선스와 모델 제공자 조항, 전체 가중치 TB 규모, 클라우드 Max와 기능 차이, 독립 평가 없음, 하드웨어 요건 서술 불일치.
- 막히면 `qwen3.8-27b`(밀집 27B)나 상위 모델 문서(`claude/opus-5.5`, `gpt-6.1-sol`, `gemini-4-argon`)의 모델로 간다.
