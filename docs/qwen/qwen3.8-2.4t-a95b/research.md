## 2. 이 모델의 연구 작업 운용
모델 전체 특성은 같은 폴더의 `general.md` §2를 따른다. 요약: 공개 가중치(텍스트 전용), 이 체크포인트의 독립 평가 없음, 환각 값 미확인, 자체 호스팅 시 연구 데이터가 외부로 나가지 않으나 TB 규모 장비 필요, 자체 라이선스.

- **연구의 추론과 인용은 이 모델에 맡기지 않는다.** 클라우드 Max의 독립 지수와 벤더 수치는 이 체크포인트의 값이 아니다. 이 체크포인트의 연구 보조 정확도와 일반 능력의 독립 평가는 찾지 못했다. [미확인] 새 가설·증명·통계 해석은 `claude/opus-5.5`, `gemini-4-argon`, `gpt-6-astra` 문서를 따르고 전문가 검토를 거친다.
- **참고문헌을 만들거나 보충하게 하지 않는다.** 26개 LLM 연구에서 검증 가능한 참고문헌 중 모든 필드가 맞은 비율은 48.3%였고 저자 목록이 가장 약했다(51.7%). 이 체크포인트의 별도 측정은 찾지 못했다. [부분/미확인] 모든 인용은 Crossref·DataCite·원문에서 제목·저자·연도·권호와 주장의 실제 존재를 확인한다(§3.2).
- **자체 호스팅의 이점은 연구 데이터 보호다.** 미공개 데이터나 개인 식별 정보를 외부 API로 보내지 않고 정리할 수 있다. 이 장점은 정확도를 보증하지 않으며 4비트에서도 약 1.5 TB급(계산기 추정) 장비가 필요하다. 사람 대상 자료는 연구 윤리 심의와 동의 범위, 데이터 이용 허가(§3.3)를 먼저 확인한다. 정리·추출 수준의 작업은 `qwen3.8-27b` 같은 작은 모델로 먼저 시험한다. [부분, 충돌/추정]
- **호스트 서비스를 쓰면 연구 데이터가 호스트로 나간다.** 호스트의 학습 사용·보관 조건을 원문으로 읽고 기관 규정(연구비 기관의 국외 이전 제한 포함)을 확인한 뒤에만 보낸다. [부분]
- **텍스트 전용이다.** 논문의 그림·차트 이미지를 직접 읽히지 못한다. 그림에서 값을 읽는 작업은 비전 모델과 사람이 하고 읽은 값은 본문 수치·원자료와 대조한다. [부분]
- **써도 되는 작업.** 서지 정보 서식 변환, 실험 로그·메타데이터 정리, 표 형식 변환, 논문 초록에서 정해진 필드 추출, 분석 스크립트(파이썬)의 초안. "원문에 없으면 null"을 명시하고 추출값은 원문과 한 건씩 대조한다.
- **수학·정량 풀이는 코드로 재검산한다.** 추론 모드가 필수라는 서술이 있어 긴 풀이가 기본이지만 틀릴 수 있다. 식은 스크립트·기호 계산 도구로 다시 계산하고 단계를 사람이 읽는다. [부분]
- **분석 결과를 모델 설명으로 대체하지 않는다.** 통계는 코드를 다시 실행해서 확인한다. 시드, 데이터 버전, 라이브러리 버전을 기록하고, 이상치 제거·필터·검정 기준이 결과에 맞춰 바뀌지 않았는지 `git diff`로 확인한다.
- **재현성을 위해 호출 조건을 기록한다.** 가중치 저장소의 커밋 해시, 양자화 방식, 서빙 런타임과 버전, 샘플링 설정을 남긴다. 양자화 수준(4비트·1비트)에 따라 결과가 달라질 수 있다. [추정]
- **전문 영역(의료, 법률, 안전) 결론에는 "전문가 검토 필요"를 붙인다.**
