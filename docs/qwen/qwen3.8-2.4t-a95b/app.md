## 2. 이 모델의 앱 작업 운용
모델 전체 특성은 같은 폴더의 `general.md` §2를 따른다. 요약: 공개 가중치(총 약 2.4조), 텍스트 전용, 자체 라이선스(모델 제공자 조항), 전체 가중치 TB 규모, 호스트 서비스 경유가 현실적, 모바일 개발 독립 평가 없음.

**앱에 내장할 때**
- **기기 안에서 돌릴 모델이 아니다.** 가중치만 수 TB 규모다. 앱은 서버를 거쳐 호출하는 구조만 가능하다. 모바일 온디바이스는 `gemma-4-e2b`, `gemma-4-e4b` 문서를 본다. [부분]
- **앱이 최종 사용자에게 모델 접근을 제공하는 형태인지 먼저 판단한다.** 라이선스 요약에는 12개월에 5,000만 달러를 넘게 버는 "모델 제공자"가 상업 라이선스를 받아야 한다는 조항과 일부 매우 큰 제품의 표시 의무가 있다. 앱에 채팅형 기능으로 노출하는 것이 이 정의에 해당하는지는 법무가 LICENSE 원문(공식 저장소)으로 판단한다. [부분: 2차 요약/미확인]
- **자체 호스팅과 호스트 경유를 구분한다.** 직접 호스팅하면 사용자 데이터가 자사 인프라에 머무르지만 운영비가 매우 크다. 호스트(Vercel AI Gateway 등)를 쓰면 호스트의 데이터 처리·보관·학습 조건이 적용되므로 그 약관을 읽고 앱의 개인정보 선언(Apple 개인정보 영양 표시, Google Play 데이터 보안 양식)과 처리방침에 반영한다. [부분]
- **API 키를 앱 바이너리나 리소스에 넣지 않는다.** 앱에서 직접 호출하지 말고 자체 백엔드에서 키 보관, 사용량 제한, 요청 검증, 로깅을 한다(§3.1 비밀 규칙). 모델 출력은 신뢰하지 않는 입력으로 취급해 서버에서 검증한 뒤 앱에 전달한다.
- **텍스트 전용이다.** 사진·화면 이해 기능은 이 체크포인트로 만들 수 없다. 이미지 입력이 필요하면 `qwen3.8-27b`(비전 언어 모델)나 API 전용 `qwen3.8-max`를 검토한다. [부분]
- **추론 모드가 항상 켜져 있다는 서술이 있어 지연과 비용이 크다.** 클라우드 Max의 비추론 모드가 없다는 서술이 있다. 모바일 UX의 응답 지연이 맞는지 측정하고, 단순 질의는 작은 모델로 라우팅한다. 스트리밍, 타임아웃, 폴백 UX를 설계한다. [부분/추정]
- **모델 교체를 앱 업데이트 없이 할 수 있게 설계한다.** 서버 쪽 모델 설정, 폴백 모델, 회귀 시험, 기능 플래그를 둔다.

**개발 보조로 쓸 때**
- **모바일(Kotlin·Swift) 코드에 대한 독립 평가는 찾지 못했다.** [미확인] 컴파일·린트·단위 테스트·UI 테스트로 검증하고, 수명주기·권한·비동기 처리가 걸린 구현은 상위 모델 문서(`claude/sonnet-5.5` 이상, `gpt-6.1-sol`, `gemini-4-argon`)와 같은 과제로 비교한다.
- 스토어 규정은 기억으로 답하지 않고 공식 문서로 확인한다(§3.2). 서명 키, 프로파일, 스토어 제출·배포는 승인 후에만 한다.
