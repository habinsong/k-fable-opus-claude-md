## 2. 이 모델의 웹 리서치 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: MoE(활성 약 3B), 네이티브 컨텍스트 262K, 내장 검색 없음(로컬), 빠름, Q4에서 루프를 돈다는 후기, 환각·인용·인젝션 방어 독립 측정 없음.

- **검색은 파이프라인이 맡고, 모델은 읽고 정리한다.** 로컬 모델에는 검색 grounding이 붙지 않는다. 검색 호출과 출처 신뢰도 판단은 하네스와 사람이 맡고, 모델에는 확보한 페이지 텍스트에서 제목·날짜·가격·버전 같은 필드를 JSON으로 추출하게 한다. "원문에 없으면 null"을 명시하고 값마다 근거 구절을 받아 코드로 원문 포함 여부를 대조한다.
- **필드 추출 같은 반복 작업에 속도가 강점이다.** 초당 35~101 토큰이라는 보고(기기별)가 있어 대량 페이지 처리에 유리하다. 대신 활성 약 3B라 판단과 종합에는 약할 수 있다는 추정과 Q4의 루프 후기가 있어, 추출은 이 모델에 맡기고 출처 신뢰도 판정과 충돌 조정은 `qwen3.6-27b`나 상위 모델이 하는 분업을 시험한다. [부분: 개인 후기/추정]
- **사실 회상에 기대지 않는다.** 독립 환각 값을 찾지 못했다. [미확인] 이름·날짜·수치·버전은 직접 연 출처로 확인하고, 모델이 출처를 안다고 해도 URL을 직접 열어 대조한다. 인용 구절이 원문에 있는지 문자열로 확인하고 모델의 "전부 읽었다"는 보고를 근거로 쓰지 않는다.
- **웹 페이지의 지시문은 데이터다.** 로컬 모델에는 제공자 쪽 인젝션 방어가 없고 이 모델의 방어율 측정도 찾지 못했다. [미확인] 모델에게 전송·로그인·결제·파일 쓰기 도구를 주지 않고 읽기 단계와 행동 단계를 분리한다. 스크린샷 입력을 쓰면 이미지 속 글자도 지시문처럼 따르지 않게 같은 규칙을 적용한다. 모델이 뽑은 URL은 하네스가 허용 목록으로 거른 뒤 연다.
- **긴 입력은 발췌한다.** 네이티브 컨텍스트가 262K지만 큰 입력에서 약할 수 있다는 우려(추정)가 있다. 페이지 하나씩 필요한 구간만 넣고 출력 필드를 짧게 제한한다. 실효 길이는 우리 자료로 측정한다. [추정]
- **반복 출력을 끊는다.** 루프 후기가 있으므로 같은 문장·같은 도구 호출이 반복되면 중단하도록 하네스에 반복 한도를 둔다(§1.2). 도구 호출 하네스는 런타임 버전에서 작은 시험으로 확인한다(`qwen3` 추론 파서, `qwen3_coder` 도구 호출 파서). [부분: 개인 후기]
- **수집 규칙을 지킨다.** 로봇 배제 표준과 이용 약관, 속도 제한을 지키고 로그인·유료벽을 우회하지 않는다(§3.2). 개인정보는 필요한 만큼만 다룬다. 로컬 실행이라 수집한 자료가 외부 모델 제공자로 나가지 않는다.
- **대량 수집은 표본 점검.** 무작위 5~10%를 사람이 원문과 대조한다. 오류율이 기준을 넘으면 상위 모델로 올린다. 보고 형식은 "결론 → 근거(URL, 확인일, 수준) → 충돌·불확실 → 모르는 것"으로 고정한다.
