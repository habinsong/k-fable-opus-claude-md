## 2. 이 모델의 연구 작업 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: 밀집 27B 비전 언어 모델, 독립 평가 점수 `xhigh` 52(비추론 35), 환각 값 미확인, 연구 보조 독립 평가 없음, 로컬 실행으로 데이터 외부 전송 없음.

- **연구의 추론과 인용은 이 모델에 맡기지 않는다.** 독립 평가 점수는 일반 능력 지표이며 가설 설계, 통계 해석, 문헌 종합의 정확도를 대신하지 않는다. 연구 보조 정확도의 독립 평가는 찾지 못했다. 벤치마크 버전(v4.1.1, v4.3)이 섞여 있어 다른 모델과의 비교에는 같은 버전인지 확인이 필요하다. [부분, 충돌/미확인] 새 가설·증명·통계 해석은 `claude/opus-5.5`, `gemini-4-argon`, `gpt-6-astra` 문서를 따르고 전문가 검토를 거친다.
- **참고문헌을 만들거나 보충하게 하지 않는다.** 26개 LLM 연구에서 검증 가능한 참고문헌 중 모든 필드가 맞은 비율은 48.3%였고 저자 목록이 가장 약했다(51.7%). 이 모델의 별도 측정은 찾지 못했다. [부분/미확인] 모든 인용은 Crossref·DataCite·원문에서 제목·저자·연도·권호와 주장의 실제 존재를 확인한다(§3.2).
- **로컬 실행의 이점은 데이터 보호다.** 미공개 데이터나 개인 식별 정보를 외부 API로 보내지 않고 정리에 쓸 수 있다. 이 장점은 정확도를 보증하지 않는다. 사람 대상 자료는 연구 윤리 심의와 개인정보 동의 범위를 먼저 확인한다(§3.3). 4비트로 24 GB GPU에 올릴 수 있다는 서술이 있어 연구실 워크스테이션에서 실행 가능하다. [부분]
- **그림·차트·스캔 논문 이미지를 읽히는 용도는 직접 시험한다.** 비전 언어 모델이라 입력은 가능하나 차트 판독 정확도를 측정한 자료는 찾지 못했다. 읽은 값은 본문 수치·보충 자료·원자료와 한 건씩 대조하고 읽기 어려운 부분은 추측하지 말고 "판독 불가"로 표시하게 한다. [부분/미확인]
- **써도 되는 작업.** 서지 정보 서식 변환, 실험 로그·메타데이터 정리, 표 형식 변환, 논문 초록에서 정해진 필드 추출, 분석 스크립트(파이썬)의 초안. "원문에 없으면 null"을 명시하고 추출값은 원문과 한 건씩 대조한다. 분석 스크립트는 알려진 입력과 결과로 먼저 시험한다.
- **수학·정량 풀이는 코드로 재검산한다.** 추론이 기본으로 켜져 있어도 풀이가 틀릴 수 있다. 식은 스크립트·기호 계산 도구로 다시 계산하고 단계를 사람이 읽는다.
- **분석 결과를 모델 설명으로 대체하지 않는다.** 통계는 코드를 다시 실행해서 확인한다. 시드, 데이터 버전, 라이브러리 버전을 기록하고, 이상치 제거·필터·검정 기준이 결과에 맞춰 바뀌지 않았는지 `git diff`로 확인한다.
- **재현성을 위해 호출 조건을 기록한다.** 가중치 저장소의 커밋 해시, 양자화 방식, 서빙 런타임과 버전, 추론/비추론 설정, 샘플링 설정을 남긴다. 양자화 수준에 따라 결과가 달라질 수 있다. [추정]
- **긴 논문 묶음은 발췌한다.** 네이티브 262,144 토큰이어도 KV 캐시와 지연이 커지므로 논문 한 편씩 필요한 구간만 넣는다. 종합과 반증 탐색은 상위 모델이나 사람이 한다.
- **전문 영역(의료, 법률, 안전) 결론에는 "전문가 검토 필요"를 붙인다.**
