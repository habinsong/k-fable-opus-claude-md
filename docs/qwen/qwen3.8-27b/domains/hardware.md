## 2. 이 모델의 하드웨어 작업 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: 밀집 27B 비전 언어 모델, 독립 지수 `xhigh` 52, 환각 값 미확인, 하드웨어 설계 평가 없음, 로컬 실행으로 설계 자료 외부 전송 없음.

- **설계 판단에 쓰지 않는다.** 핀 배치, 정격, 타이밍, 수식은 틀리면 보드가 망가지거나 위험해진다. 이 모델의 회로·PCB·HDL 평가는 찾지 못했다. [미확인] 독립 지수와 벤더 코딩 점수는 일반 능력 지표이고 회로 설계 정확도를 대표하지 않는다. 설계는 `gemini-4-argon`, `claude/opus-5.5`, `gpt-6.1-sol` 같은 상위 모델 문서와 같은 과제로 비교하고, 그 결과도 데이터시트 원문과 도구 계산으로 확인한다.
- **값 회상을 믿지 않는다.** AA-Omniscience 값을 찾지 못했다. [미확인] 부품 번호, 핀 번호, 레지스터 주소, 정격을 모델 기억에서 가져오게 하지 않는다. 값은 사람이 확보한 데이터시트 텍스트에서만 꺼내게 하고, 값마다 문서명·개정판·페이지를 같이 받아 원문 PDF와 한 건씩 대조한다. 원문에 없으면 null이다(§3.1).
- **데이터시트·회로도 그림을 읽히는 용도는 이 모델이 시험해 볼 만한 이점이다.** 비전 언어 모델이라 핀 표 이미지, 타이밍 다이어그램, 회로도 사진을 입력으로 줄 수 있고 로컬이라 설계 자료가 외부로 나가지 않는다. 다만 작은 글씨·표·다이어그램의 판독 정확도를 측정한 자료는 찾지 못했다. 읽은 값은 원문 텍스트·넷리스트·ERC 보고서와 반드시 대조하고, 읽기 어려운 부분은 추측하지 말고 "판독 불가"로 표시하게 한다. 이미지 해상도와 입력 토큰 한도에 따라 결과가 달라진다. [부분/미확인]
- **컨텍스트가 커도 데이터시트를 통째로 넣지 않는다.** 네이티브 262,144 토큰이어도 긴 컨텍스트의 KV 캐시가 메모리를 더 쓴다. 필요한 장과 표만 넣고 PDF 표를 텍스트로 변환한 결과도 원문과 대조한다. [부분]
- **써도 되는 작업.** BOM 정규화, 부품 번호 목록 변환, 시험 로그 분류, 데이터시트 텍스트에서 정해진 필드 추출, 측정·변환 스크립트(파이썬)의 초안. 스크립트는 알려진 값을 넣어 실행해 확인한다.
- **계산은 도구로 한다.** 전류 예산, 분압, 필터, 열 계산은 스크립트·시뮬레이터 출력으로 확인하고 식과 가정을 남긴다. 추론이 기본으로 켜져 있어도 그 풀이를 그대로 신뢰하지 않는다.
- **로컬 모델이 만든 스크립트는 격리 환경에서 실행한다.** 측정 장비·전원·프로그래머를 제어하는 스크립트는 사람이 읽고 승인하기 전에 실제 장비에 연결하지 않는다. 제공자 쪽 안전장치가 없다.
- **인체·화재 위험 설계는 "안전하다"고 단정하지 않는다.** 고전압·대전류·배터리·모터는 사람의 검토를 요청한다.
