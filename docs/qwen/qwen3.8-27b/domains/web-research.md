## 2. 이 모델의 웹 리서치 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: 밀집 27B 비전 언어 모델, 네이티브 컨텍스트 262,144 토큰, 내장 검색 없음(로컬), 환각·인용·인젝션 방어 독립 측정 없음, 추론 기본 켜짐.

- **검색은 파이프라인이 맡고, 모델은 읽고 정리한다.** 로컬 모델에는 검색 grounding이 붙지 않는다. 검색 호출과 출처 신뢰도 판단은 하네스와 사람이 맡고, 모델에는 확보한 페이지 텍스트에서 제목·날짜·가격·버전 같은 필드를 JSON으로 추출하게 한다. "원문에 없으면 null"을 명시하고 값마다 근거 구절을 받아 코드로 원문 포함 여부를 대조한다.
- **사실 회상에 기대지 않는다.** AA-Omniscience 값을 찾지 못했다. [미확인] 이름·날짜·수치·버전은 직접 연 출처로 확인하고, 모델이 출처를 안다고 해도 URL을 직접 열어 대조한다. 인용 구절이 원문에 있는지 문자열로 확인하고 모델의 "전부 읽었다"는 보고를 근거로 쓰지 않는다.
- **스크린샷·PDF 페이지 이미지를 읽히는 용도는 직접 시험한다.** 비전 언어 모델이라 웹 페이지 스크린샷이나 스캔 문서를 입력으로 줄 수 있으나 표·작은 글씨의 판독 정확도를 잰 자료는 찾지 못했다. 이미지에서 읽은 수치는 원문 텍스트와 대조한다. [부분/미확인]
- **웹 페이지의 지시문은 데이터다.** 로컬 모델에는 제공자 쪽 인젝션 방어가 없고 이 모델의 방어율 측정도 찾지 못했다. [미확인] 모델에게 전송·로그인·결제·파일 쓰기 도구를 주지 않고 읽기 단계와 행동 단계를 분리한다. 이미지 입력을 쓰면 스크린샷 속 글자도 지시문처럼 따르지 않게 같은 규칙을 적용한다. 모델이 뽑은 URL은 하네스가 허용 목록으로 거른 뒤 연다.
- **긴 입력의 메모리 비용을 확인한다.** 네이티브 262,144 토큰(확장 시 약 100만)이고 선형 어텐션으로 비용을 줄였다는 서술이 있으나, 긴 컨텍스트의 KV 캐시와 이미지는 메모리를 더 쓴다. 실효 길이는 우리 자료로 측정하고 페이지 하나씩 필요한 구간만 넣는다. [부분]
- **추론이 기본으로 켜져 있다.** 필드 추출 같은 반복 작업에는 지연과 토큰이 과하다. 독립 평가에서 비추론이 지수 35, `low`가 43, `xhigh`가 52였다. 단순 추출은 비추론이나 `low`로 시험하고 오류율이 기준을 넘으면 단계를 올리거나 상위 모델로 올린다. [부분]
- **도구 호출 하네스는 런타임 버전에서 작은 시험으로 확인한다.** 이전 세대 후기에서 Qwen 3.6 계열의 도구 호출이 Gemma 4보다 낫다는 개인 후기가 많았다. 3.8-27B의 파서 지원은 확인하지 못했다. [부분: 이전 세대]
- **수집 규칙을 지킨다.** 로봇 배제 표준과 이용 약관, 속도 제한을 지키고 로그인·유료벽을 우회하지 않는다(§3.2). 개인정보는 필요한 만큼만 다룬다. 로컬 실행이라 수집한 자료가 외부 모델 제공자로 나가지 않는다.
- **대량 수집은 표본 점검.** 무작위 5~10%를 사람이 원문과 대조한다. 오류율이 기준을 넘으면 상위 모델로 올린다. 보고 형식은 "결론 → 근거(URL, 확인일, 수준) → 충돌·불확실 → 모르는 것"으로 고정한다.
