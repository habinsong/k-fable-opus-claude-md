## 2. 이 모델의 웹 작업 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: API 전용, 한 세대 전(후속 `qwen3.8-max`), 컨텍스트 100만 토큰, 경로별 가격 차이, 독립 평가 점수 46.0 또는 56.6(충돌), 35시간 자율 실행 주장(벤더).

- **웹 UI 생성의 독립 평가는 찾지 못했다.** [미확인] 컴포넌트 단위 수정, 새 화면, 스크린샷 재현을 우리 코드베이스에서 `qwen3.8-max`와 상위 모델을 포함해 같은 조건으로 비교하고, 스크린샷 대조와 린터·타입체크·테스트 출력으로 판정한다. 기존 UI 체계가 우선한다(§3.1).
- **새 도입이라면 이 모델을 고르지 않는다.** 석 달 뒤 후속이 같은 가격대에서 나왔다. 기존 파이프라인이 이미 이 모델로 검증돼 있다면 폐기 일정을 확인하고 이행 시 UI 생성 프롬프트와 템플릿의 회귀 시험(스냅샷·시각 비교)을 돌린다. [추정]
- **35시간 자율 실행 주장을 UI 작업에 그대로 적용하지 않는다.** 벤더 설명이며 독립 확인이 없다. 장시간 에이전트를 쓴다면 파일 쓰기·셸 실행 범위, 작업 디렉터리, 파괴적 명령 차단(권한·훅)을 먼저 설정하고 완료 보고는 린터·타입체크·테스트 출력과 `git diff`로 확인한다. [부분: 벤더 주장]
- **Claude Code 같은 외부 하네스 호환은 편의일 뿐 성능 보증이 아니다.** 하네스 호환 사실이 그 하네스에서의 품질을 뜻하지는 않는다. 쓸 하네스에서 직접 시험한다. [부분]
- **경로별 가격·한도를 확인한다.** Alibaba 직접 입력 $2.50 / 출력 $7.50, OpenRouter·Vercel $1.25 / $3.75로 두 배 차이가 난다. 경로마다 데이터 조건도 다르다. 과제당 입력·출력 토큰과 도구 호출 수를 기록해 비용을 비교한다. [부분, 충돌]
- **보안·접근성 판단을 맡기지 않는다.** 인가, 입력 검증, 비밀 노출, 접근성 "충족" 여부는 도구 출력과 §3.1 기준으로 사람이 점검한다. API·CSS·브라우저 지원은 공식 문서와 린터·컴파일러 출력으로 확인한다.
- **미공개 소스를 보내기 전에 데이터 조건을 확인한다.** 학습 불사용 서술과 리전별 저장은 있으나 ZDR은 국제 사이트 기업 고객 한정이고 보관 기간(최대 30일은 제3자 서술)은 원문 확인이 필요하다(`qwen3.8-max` 문서 §2.3). [부분, 충돌] 확인 전에는 비밀·고객 데이터가 담긴 코드를 보내지 않는다(§1.6).
