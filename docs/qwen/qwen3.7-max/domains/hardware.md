## 2. 이 모델의 하드웨어 작업 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: API 전용, 한 세대 전, 환각 값 미확인, 하드웨어 설계 평가 없음, 경로별 데이터 조건 차이.

- **설계 판단에 쓰지 않는다.** 핀 배치, 정격, 타이밍, 수식은 틀리면 보드가 망가지거나 위험해진다. 이 모델의 회로·PCB·HDL 평가는 찾지 못했다. [미확인] 독립 지수(46.0 또는 56.6, 충돌)와 벤더 수치(HLE 41.4, MCP-Atlas 76.4)는 일반 능력 지표이고 회로 설계 정확도를 대표하지 않는다. 설계는 `gemini-4-argon`, `claude/opus-5.5`, `gpt-6.1-sol` 같은 상위 모델 문서와 같은 과제로 비교하고, 그 결과도 데이터시트 원문과 도구 계산으로 확인한다. [부분, 충돌]
- **값 회상을 믿지 않는다.** 환각·사실성 값을 찾지 못했다. [미확인] 부품 번호, 핀 번호, 레지스터 주소, 정격을 모델 기억에서 가져오게 하지 않는다. 값은 사람이 확보한 데이터시트 텍스트에서만 꺼내게 하고, 값마다 문서명·개정판·페이지를 같이 받아 원문 PDF와 한 건씩 대조한다. 원문에 없으면 null이다(§3.1).
- **이미지(회로도·PCB 사진) 판독은 근거로 쓰지 않는다.** 이 모델의 비전 지원과 판독 정확도는 확인하지 못했다. [미확인] 읽은 값은 원문 텍스트·넷리스트·ERC 보고서와 대조하고, 읽기 어려운 부분은 추측하지 말고 "판독 불가"로 표시하게 한다.
- **컨텍스트가 100만 토큰이어도 데이터시트를 통째로 넣지 않는다.** 필요한 장과 표만 넣고 PDF 표를 텍스트로 변환한 결과도 원문과 대조한다. [추정]
- **써도 되는 작업.** BOM 정규화, 부품 번호 목록 변환, 시험 로그 분류, 데이터시트 텍스트에서 정해진 필드 추출, 측정·변환 스크립트(파이썬)의 초안. 스크립트는 알려진 값을 넣어 실행해 확인한다. 새로 시작하는 작업이면 후속 `qwen3.8-max`나 더 싼 경로를 먼저 비교한다.
- **계산은 도구로 한다.** 전류 예산, 분압, 필터, 열 계산은 스크립트·시뮬레이터 출력으로 확인하고 식과 가정을 남긴다.
- **미공개 설계 자료를 API로 보내지 않는다(약관 확인 전).** 경로(직접, 중개)마다 데이터 조건이 다르고 ZDR은 기업 고객 한정이며 보관 기간은 원문 확인이 필요하다. 모기업이 중국 본사라는 위험 분석도 있다. [부분, 충돌] 회로도·레이아웃·펌웨어 이미지·부품 공급 정보는 영업비밀이고 수출 통제·고객 계약상 국외 이전이 제한될 수 있으므로 원문 약관과 법무 확인 뒤에만 보낸다.
- **인체·화재 위험 설계는 "안전하다"고 단정하지 않는다.** 고전압·대전류·배터리·모터는 사람의 검토를 요청한다.
