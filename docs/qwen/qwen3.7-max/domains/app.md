## 2. 이 모델의 앱 작업 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: API 전용이라 기기 내 실행 불가, 한 세대 전(후속 `qwen3.8-max`), 경로별 가격·데이터 조건 차이, 모바일 개발 독립 평가 없음.

**앱에 내장할 때**
- **기기 안에서 돌릴 모델이 아니다.** 호스팅 전용이다. 앱은 서버를 거쳐 호출하는 구조만 가능하다. 모바일 온디바이스는 `gemma-4-e2b`, `gemma-4-e4b` 문서를 본다.
- **API 키를 앱 바이너리나 리소스에 넣지 않는다.** 자체 백엔드에서 키 보관, 사용량 제한, 요청 검증, 로깅을 한다(§3.1 비밀 규칙). 모델 출력은 신뢰하지 않는 입력으로 취급해 서버에서 검증한 뒤 앱에 전달한다.
- **새로 만드는 기능이면 후속 `qwen3.8-max`를 기준으로 설계하고 이 모델은 폴백이나 기존 호환용으로 둔다.** 이 모델의 폐기 일정은 확인하지 못했으므로 공식 문서의 모델 수명주기를 확인하고 서버 쪽 모델 설정, 폴백 모델, 회귀 시험, 기능 플래그로 교체를 앱 업데이트 없이 할 수 있게 한다. [추정]
- **경로마다 데이터 조건이 다르다.** Alibaba Cloud Model Studio 직접 경로는 학습 불사용 서술과 리전별 저장 설정이 있고, OpenRouter·Vercel 같은 중개 경로는 그쪽 약관이 적용된다. 앱의 개인정보 선언(Apple 개인정보 영양 표시, Google Play 데이터 보안 양식)과 처리방침에 실제 경로의 전송 항목과 국외 이전을 반영한다. 모기업이 중국 본사라는 위험 분석이 있어 규제 데이터는 법무가 판단한다. [부분, 충돌]
- **비용을 경로별로 비교하고 서버에서 제한한다.** Alibaba 직접 입력 $2.50 / 출력 $7.50, 중개 경로 $1.25 / $3.75로 두 배 차이가 난다. 사용자당 한도, `max_tokens`, 요청 빈도 제한을 서버에 두고 실제 청구서로 확인한다. [부분, 충돌]
- **장시간 자율 에이전트 기능(35시간 주장)을 앱 기능으로 쓰기 전에 사용자 통제를 설계한다.** 장시간 실행은 비용과 데이터 노출이 커진다. 사용자별 실행 시간·비용 한도, 중단 버튼, 실행 로그와 삭제 경로를 둔다. [부분: 벤더 주장/추정]

**개발 보조로 쓸 때**
- **모바일(Kotlin·Swift) 코드에 대한 독립 평가는 찾지 못했다.** [미확인] 컴파일·린트·단위 테스트·UI 테스트로 검증하고, 수명주기·권한·비동기 처리가 걸린 구현은 상위 모델 문서(`claude/sonnet-5.5` 이상, `gpt-6.1-sol`, `gemini-4-argon`)와 같은 과제로 비교한다.
- 스토어 규정은 기억으로 답하지 않고 공식 문서로 확인한다(§3.2). 서명 키, 프로파일, 스토어 제출·배포는 승인 후에만 한다.
