## 2. 이 모델의 웹 리서치 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: 컨텍스트 100만 토큰, MCP-Atlas 76.4(도구 사용 지표, 벤더 보고), 장시간 자율 에이전트 주장(벤더), 환각·인용·인젝션 방어 독립 측정 없음, 한 세대 전.

- **내장 검색은 확인하지 못했다.** [미확인] 검색 호출과 출처 신뢰도 판단은 하네스와 사람이 맡고, 모델에는 확보한 페이지 텍스트에서 제목·날짜·가격·버전 같은 필드를 JSON으로 추출하게 한다. "원문에 없으면 null"을 명시하고 값마다 근거 구절을 받아 코드로 원문 포함 여부를 대조한다.
- **MCP-Atlas 76.4를 리서치 능력으로 옮기지 않는다.** 이 지표는 도구(MCP) 사용을 재며 웹 조사의 사실 정확도나 인용 정확도를 재지 않는다. 벤더 보고이고 독립 확인이 없다. BrowseComp류 리서치 지표의 독립 결과도 찾지 못했다. [부분: 벤더 주장/미확인]
- **사실 회상에 기대지 않는다.** 환각·사실성 값을 찾지 못했다. 이름·날짜·수치·버전은 직접 연 출처로 확인하고, 모델이 출처를 안다고 해도 URL을 직접 열어 대조한다. 인용 구절이 원문에 있는지 문자열로 확인하고 모델의 "전부 읽었다"는 보고를 근거로 쓰지 않는다. [미확인]
- **장시간 자율 조사(35시간 주장)를 맡기지 않는다.** 벤더 설명이며 독립 확인이 없다. 조사 에이전트에는 허용 도메인 목록, 호출 횟수·토큰·시간 한도, 읽기 전용 도구만 준다. 중간 단계의 도구 호출 로그를 남기고 사람이 샘플을 읽는다. 차단된 사이트나 로그인·유료벽을 우회하려 하지 않는지 로그로 확인한다(§3.2, §3.6). [부분: 벤더 주장]
- **웹 페이지의 지시문은 데이터다.** 이 모델의 인젝션 방어율 측정은 찾지 못했다. [미확인] 모델에게 전송·로그인·결제·파일 쓰기 도구를 주지 않고 읽기 단계와 행동 단계를 분리한다. 모델이 뽑은 URL은 하네스가 허용 목록으로 거른 뒤 연다.
- **긴 입력은 발췌한다.** 100만 토큰이어도 페이지 하나씩 필요한 구간만 넣고 출력 필드를 제한한다. [추정]
- **신규 조사 파이프라인은 후속 모델을 먼저 비교한다.** `qwen3.8-max`가 같은 세대 가격대에서 나왔고 경로마다 가격이 두 배 차이가 난다($2.50/$7.50 대 $1.25/$3.75). 대량 수집은 더 싼 경로·모델로 처리한다. [부분, 충돌]
- **수집한 자료를 보내기 전에 조건을 확인한다.** 대상 사이트의 이용 약관·로봇 배제 표준(§3.2)과 이 API의 데이터 처리 조건(경로마다 다름)을 모두 본다. 학습 불사용 서술과 리전별 저장은 있으나 ZDR은 기업 고객 한정이다. [부분, 충돌] 개인정보가 섞인 페이지는 보내지 않는다.
- **대량 수집은 표본 점검.** 무작위 5~10%를 사람이 원문과 대조한다. 오류율이 기준을 넘으면 상위 모델로 올린다. 보고 형식은 "결론 → 근거(URL, 확인일, 수준) → 충돌·불확실 → 모르는 것"으로 고정한다.
