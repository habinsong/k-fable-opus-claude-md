## 2. 이 모델의 기술 조사 운용, 그리고 이 모델을 평가할 때
모델 전체 특성은 같은 폴더의 `general.md` §2를 따른다. 요약: API 전용 플래그십(빌드 둘), 입력 $2 / 출력 $6, 독립 지수 45~58(스냅샷마다 다름), 출력 토큰 소비 많음, 벤더 수치는 외부 하네스 기반, 같은 세대 공개 가중치와 별개 모델, 데이터 정책 일부는 2차 출처.

**이 모델에게 기술 조사를 시킬 때**
- 분류·정리 단계에만 쓴다. 후보를 정해진 기준(라이선스 유형, 지원 언어, 릴리스 날짜)으로 분류해 표로 만들 때, 값은 사람이 확보한 1차 자료 텍스트에서 추출하게 하고 원문에 없으면 null로 둔다.
- 라이선스 호환성, 특허, 규정 적용 여부, 도입 권고는 단정시키지 않는다(§3.2, §3.5). 후보를 지나치게 높게 평가하는 경향(아첨)은 측정된 바 없으므로 사람이나 상위 모델이 근거를 보고 판단한다.
- 환각 값이 확인되지 않았으므로 모델이 말하는 버전·날짜·가격·라이선스는 모두 1차 출처로 다시 확인한다.

**Qwen3.8-Max를 도입 후보로 평가할 때**
- **같은 세대 모델을 혼동하지 않는다.** API 전용 `qwen3.8-max`, 공개 가중치 `qwen3.8-2.4t-a95b`(텍스트 전용, 자체 라이선스), `qwen3.8-27b`(밀집 VLM, Apache 2.0이라는 서술)는 사양·라이선스·접근 경로가 다른 별개 모델이다. 한 자료의 점수를 다른 모델에 옮기지 않는다. 후보 문서에 정확한 모델명과 빌드를 쓴다. [부분]
- **빌드가 둘이고 점수가 스냅샷마다 다르다.** 독립 지수가 45, 53, 56, 58로 보이고 빌드(`0803`/`0902`), 지수 버전(v4.1.1 등)이 섞여 있다. 비교할 때 같은 버전·같은 빌드의 값만 쓰고 최종 선택은 자체 실측으로 한다. Kimi K3가 25% 싸면서 점수가 더 높다는 비교 보도도 있다(2차). [부분, 충돌]
- **벤더 수치는 하네스 의존이다.** Terminal-Bench 2.1 86.6은 Alibaba 내부 실행, 독립 검증 대기이며 Anthropic 에이전트 하네스에서 돌렸다는 서술이 있다. 도입 시험은 실제로 쓸 하네스에서 한다. [부분: 벤더 주장]
- **총비용은 과제당 비용이다.** 단가(입력 $2 / 출력 $6, 장문 추가 요금 없음)는 낮지만 0902 빌드의 지수 실행에서 출력 토큰이 약 1.9억 개로 높았고 작업당 비용 서술이 $5.41(AA 페이지)과 $1.14(출시 보도)로 갈린다. 우리 과제의 토큰·도구 호출 수로 비교한다. [부분, 충돌]
- **데이터 거버넌스.** Alibaba는 데이터를 모델 학습에 쓰지 않는다고 밝히고, 리전이 저장 위치를 정하며(추론 위치는 별도 설정), ZDR은 국제 사이트 기업 고객 전용이고 일부 기능이 제외되며, 최대 30일 보관은 제3자 서술이다. 싱가포르 리전이어도 모기업은 중국 본사이고 중국 법령이 그룹사에 미칠 수 있다는 위험 분석이 있다. 약관·개인정보 처리방침·ZDR 조건을 원문으로 읽고 법무·보안 검토를 거친다. [부분, 충돌]
- **자체 호스팅이 필요하면 이 모델이 아니다.** API 전용이다. 공개 가중치는 `qwen3.8-27b`(24 GB급 GPU에서 4비트 양자화로 가능하다는 서술)와 `qwen3.8-2.4t-a95b`(대규모 노드)를 본다. 라이선스는 각각 원문으로 확인한다. [부분]
- **공급 연속성.** 7월 미리보기, 8월 3일 정식, 9월 2일 새 빌드, 8월 공개 가중치가 석 달 안에 나왔다. 빌드 폐기 일정, 모델 교체 절차, 폴백 모델, 회귀 시험을 도입 조건으로 둔다. 같은 계열의 이전 세대 `qwen3.7-max`(5월)와의 관계도 확인한다. [부분]
- **제공자 안전장치와 규정.** 규제 적합성은 모델이 아니라 시스템 전체에 대해 판단하고, 모델 카드를 규정 준수의 근거로 쓰지 않는다.
