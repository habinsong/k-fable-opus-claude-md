## 2. 이 모델의 웹 작업 운용
모델 전체 특성은 같은 폴더의 `general.md` §2를 따른다. 요약: API 전용(빌드 `0803`·`0902`), 컨텍스트 100만 토큰, 입력 $2 / 출력 $6, 독립 지수가 스냅샷마다 다름(45~58), 출력 토큰 소비 많음, 벤더 수치는 하네스 의존.

- **웹 UI 생성의 독립 평가는 찾지 못했다.** [미확인] 검색에서 나온 것은 출시 홍보, 벤치마크 인용, 가격 비교뿐이었다. 컴포넌트 단위 수정, 새 화면, 스크린샷 재현을 우리 코드베이스에서 상위 모델과 같은 조건으로 돌려 비교하고, 스크린샷 대조와 린터·타입체크·테스트 출력으로 판정한다. 기존 UI 체계가 우선한다(§3.1).
- **벤더 코딩 수치는 Anthropic 에이전트 하네스에서 잰 값이다.** Terminal-Bench 2.1 86.6은 Alibaba 내부 실행이고, 코딩 벤치마크를 Claude Code 같은 외부 하네스에서 돌렸다는 서술이 있다. 우리가 쓰는 하네스(Cursor, VS Code 확장, 자체 도구)에서 같은 성능을 기대하지 않는다. [부분: 벤더 주장]
- **빌드를 고정한다.** 같은 이름 아래 `0803`과 `0902`가 있다. UI 생성 프롬프트와 템플릿의 회귀 시험(스냅샷·시각 비교)을 빌드 변경 전후에 돌리고 빌드 ID를 지정한다. [부분/추정]
- **과제당 비용을 직접 잰다.** 단가($2/$6, 장문 추가 요금 없음)는 낮지만 0902 빌드의 지수 실행에서 출력 토큰이 약 1.9억 개로 높은 편이었다. 컴포넌트 수정 한 건당 입력·출력 토큰과 도구 호출 수를 기록한다. [부분]
- **스크린샷 입력은 직접 시험한다.** API의 Max는 비전을 포함하지만(공개 2.4T 체크포인트는 텍스트 전용), 레이아웃·간격·색 재현 정확도를 잰 자료는 찾지 못했다. [부분/미확인]
- **장시간 자율 에이전트 기능을 쓰려면 권한 경계를 먼저 둔다.** 파일 쓰기·셸 실행 범위, 작업 디렉터리, 파괴적 명령 차단(권한·훅)을 설정하고 완료 보고는 린터·타입체크·테스트 출력과 `git diff`로 확인한다.
- **보안·접근성 판단을 맡기지 않는다.** 인가, 입력 검증, 비밀 노출, 접근성 "충족" 여부는 도구 출력과 §3.1 기준으로 사람이 점검한다. API·CSS·브라우저 지원은 공식 문서와 린터·컴파일러 출력으로 확인한다.
- **미공개 소스를 보내기 전에 데이터 조건을 확인한다.** Model Studio는 학습에 쓰지 않는다고 밝히나 리전 설정, ZDR 대상(국제 사이트 기업 고객), 보관 기간(최대 30일은 제3자 서술)은 원문으로 확인해야 한다(general.md §2.3). [부분, 충돌] 확인 전에는 비밀·고객 데이터가 담긴 코드를 보내지 않는다(§1.6).
