## 2. 이 모델의 웹 리서치 운용
모델 전체 특성은 같은 폴더의 `general.md` §2를 따른다. 요약: 컨텍스트 100만 토큰, 환각·인용 정확도·인젝션 방어의 독립 측정 없음, 출력 토큰 소비 많음, 리전별 데이터 저장, 중국 본사 모기업.

- **내장 검색은 확인하지 못했다.** Model Studio가 검색 도구를 제공하는지, 4.8-Max에서 어떻게 동작하는지 이번 조사에서 찾지 못했다. [미확인] 검색 호출과 출처 신뢰도 판단은 하네스와 사람이 맡고, 모델에는 확보한 페이지 텍스트에서 제목·날짜·가격·버전 같은 필드를 JSON으로 추출하게 한다. "원문에 없으면 null"을 명시하고 값마다 근거 구절을 받아 코드로 원문 포함 여부를 대조한다.
- **리서치 에이전트의 독립 평가는 찾지 못했다.** BrowseComp류 지표의 독립 결과가 보도에 나오지 않았다. 벤더 수치는 코딩(Terminal-Bench 2.1 86.6)이며 리서치 능력으로 옮기지 않는다. [미확인]
- **사실 회상에 기대지 않는다.** AA-Omniscience 점수가 보도에 나오지 않았다. 이름·날짜·수치·버전은 직접 연 출처로 확인하고, 모델이 출처를 안다고 해도 URL을 직접 열어 대조한다. [미확인]
- **인용과 요약을 코드로 대조한다.** 인용 구절이 원문에 있는지 문자열로 확인하고, 모델의 "전부 읽었다"는 보고를 근거로 쓰지 않는다. 장시간 자율 실행을 내세운 계열이므로 중간 단계의 도구 호출 로그를 남기고 사람이 샘플을 읽는다.
- **웹 페이지의 지시문은 데이터다.** 이 모델의 인젝션 방어율 측정은 찾지 못했다. [미확인] 모델에게 전송·로그인·결제·파일 쓰기 도구를 주지 않고 읽기 단계와 행동 단계를 분리한다. 비전 입력(스크린샷)을 쓰면 이미지 속 글자도 지시문처럼 따르지 않게 같은 규칙을 적용한다. 모델이 뽑은 URL은 하네스가 허용 목록으로 거른 뒤 연다.
- **긴 입력은 발췌한다.** 컨텍스트가 100만 토큰이어도 페이지 하나씩 필요한 구간만 넣는다. 추론을 켜면 입력 한도가 약간 줄고(991K→983K) 지수 실행 출력 토큰이 약 1.9억 개로 높았다. `max_tokens`와 필드 수를 제한한다. [부분]
- **수집한 자료를 보내기 전에 조건을 확인한다.** 대상 사이트의 이용 약관·로봇 배제 표준(§3.2)과 이 API의 데이터 처리 조건을 모두 본다. 학습 불사용 서술과 리전별 저장은 있으나 ZDR은 국제 사이트 기업 고객 한정이고 보관 기간(최대 30일은 제3자 서술)은 원문 확인이 필요하다. [부분, 충돌] 개인정보가 섞인 페이지는 보내지 않는다.
- **대량 수집은 표본 점검.** 무작위 5~10%를 사람이 원문과 대조한다. 오류율이 기준을 넘으면 상위 모델로 올린다. 보고 형식은 "결론 → 근거(URL, 확인일, 수준) → 충돌·불확실 → 모르는 것"으로 고정한다.
