## 2. 이 모델의 펌웨어 작업 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: API 전용이라 기기 내 실행 불가, 벤더 코딩 수치는 외부 에이전트 하네스 기반, 임베디드 평가 없음, 환각 값 미확인, 데이터 정책 일부는 2차 출처.

- **기기 안에서 돌릴 모델이 아니다.** 호스팅 전용이다. 개발 워크스테이션에서 API로 쓰는 보조 도구로만 쓴다. 기기 내 추론이 필요하면 소형 모델 문서(`gemma-4-e2b`, `gemma-4-e4b`)를 본다.
- **펌웨어 코드를 직접 쓰거나 고치게 하지 않는다.** 레지스터 값, 인터럽트, 부트·업데이트 경로, 서명 검증은 환각이 장치 고장이나 보안 구멍이 된다. 임베디드·펌웨어 평가는 찾지 못했다. [미확인] 터미널 작업 점수(Terminal-Bench 2.1 86.6, 벤더 내부 실행, 외부 하네스 기반)는 장치 쓰기나 실시간 제약과 무관하다. 이 영역은 `gemini-4-argon`, `claude/sonnet-5.5` 이상, `gpt-6.1-sol` 문서를 따른다. [부분]
- **레지스터·타이밍을 모델의 기억에서 가져오지 않는다.** 환각 값이 보도에 나오지 않았다. 데이터시트·레퍼런스 매뉴얼의 개정판과 페이지를 사람이 확보한 텍스트로 주고, 확인하지 못했으면 값을 쓰지 않는다(§3.1). [미확인]
- **써도 되는 작업.** UART·RTT 로그 분류, 맵 파일 요약, 컴파일러 경고 그룹화, 변경 이력 요약, 호스트에서 돌리는 테스트 코드(하드웨어 추상화 뒤쪽 로직)의 초안. 입력은 관련 구간만 준다. 출력은 원본 로그·맵 파일과 한 건씩 대조한다.
- **장시간 자율 에이전트에 장치 접근을 열어 주지 않는다.** 플래시 소거, 퓨즈·OTP, 보호 비트, 부트로더 덮어쓰기, 디버그 포트 잠금은 사람이 대상 장치와 이미지를 확인한 뒤 실행한다. 프로그래머·시리얼 제어 도구는 읽기 전용부터 연결하고 권한·훅으로 쓰기 명령을 차단한다. 출력 토큰 소비가 많은 모델이므로(지수 실행 약 1.9억 개) 루프의 호출 횟수·토큰·시간 한도를 둔다. [부분]
- **변경 후 검증을 강제한다.** 호스트 단위 테스트와 정적 분석을 직접 돌려 출력을 읽고, 경고를 억제하라는 제안은 따르지 않는다. 실제 보드에서 확인하지 못했으면 "하드웨어 미검증"이라고 쓴다.
- **펌웨어 소스·로그·서명 키·양산 이미지를 API로 보내지 않는다(약관 확인 전).** 학습 불사용·보관·ZDR·추론 위치를 원문으로 확인해야 하고 모기업이 중국 본사라는 지적이 있다(README.md가 안내하는 개요·운용 문서.3). [부분, 충돌] 서명 키와 디버그 인증 정보는 약관과 무관하게 보내지 않는다(§3.4). 수출 통제·고객 계약상 국외 이전이 제한된 코드는 법무 확인 전에 보내지 않는다.
