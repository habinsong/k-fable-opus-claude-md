## 2. 이 모델의 앱 작업 운용
모델 전체 특성은 같은 폴더의 `general.md` §2를 따른다. 요약: API 전용이라 기기 내 실행 불가, 리전 설정으로 저장 위치 지정 가능(추론 위치는 별도 설정), 학습 불사용 서술, ZDR은 기업 고객 한정, 중국 본사 모기업, 모바일 개발 독립 평가 없음.

**앱에 내장할 때**
- **기기 안에서 돌릴 모델이 아니다.** 호스팅 전용이다. 앱은 서버를 거쳐 호출하는 구조만 가능하다. 모바일 온디바이스는 `gemma-4-e2b`, `gemma-4-e4b` 문서를 본다. 같은 세대의 소형 공개 모델(`qwen3.8-27b`)도 휴대 기기용이 아니다.
- **API 키를 앱 바이너리나 리소스에 넣지 않는다.** 앱에서 직접 호출하지 말고 자체 백엔드에서 키 보관, 사용량 제한, 요청 검증, 로깅을 한다(§3.1 비밀 규칙). 모델 출력은 신뢰하지 않는 입력으로 취급해 서버에서 검증한 뒤 앱에 전달한다.
- **리전을 앱의 개인정보 선언에 맞춘다.** Model Studio에서 리전이 접근 지점과 정적 데이터 저장 위치를 정하고 추론 위치는 별도 배포 범위 설정이라는 서술이 있다. 사용자 지역에 맞는 리전과 추론 범위를 지정하고, 앱 스토어의 개인정보 선언(Apple 개인정보 영양 표시, Google Play 데이터 보안 양식)과 처리방침에 전송 항목과 국외 이전을 반영한다. [부분]
- **학습 불사용·보관 조건을 원문으로 확인한다.** Alibaba는 데이터를 모델 학습에 쓰지 않는다고 밝히나(공식 FAQ 서술), ZDR은 국제 사이트 기업 고객 전용이고 일부 기능은 제외되며, 최대 30일 보관은 제3자 서술이다. 대화 저장·파일 기능은 사용자가 지울 때까지 남는다. 앱에서 대화 저장 기능을 켜면 삭제 요청(정보주체 권리) 처리 경로를 설계한다. 싱가포르 리전이어도 모기업이 중국 본사라는 지적이 있어 규제 데이터는 법무가 판단한다. [부분, 충돌]
- **이미지를 보내는 기능은 조심한다.** API의 Max는 비전을 포함한다는 서술이 있다. 사진에 담긴 얼굴·위치·문서 정보가 서버로 전송되므로 약관 확인과 사용자 동의 없이 보내지 않는다. [부분]
- **비용을 과제당으로 서버에서 제한한다.** 단가는 입력 $2 / 출력 $6이고 장문 추가 요금은 없다는 서술이 있으나 지수 실행에서 출력 토큰이 약 1.9억 개로 높은 편이었다. 사용자당 한도, `max_tokens`, 요청 빈도 제한을 서버에 두고 실제 청구서로 확인한다. [부분]
- **빌드를 고정하고 교체에 대비한다.** 같은 이름 아래 `0803`과 `0902` 빌드가 있었다. 서버 쪽 모델 설정, 폴백 모델, 회귀 시험, 기능 플래그를 두어 앱 업데이트 없이 교체할 수 있게 한다.

**개발 보조로 쓸 때**
- **모바일(Kotlin·Swift) 코드에 대한 독립 평가는 찾지 못했다.** [미확인] 컴파일·린트·단위 테스트·UI 테스트로 검증하고, 수명주기·권한·비동기 처리가 걸린 구현은 상위 모델 문서(`claude/sonnet-5.5` 이상, `gpt-6.1-sol`, `gemini-4-argon`)와 같은 과제로 비교한다. 벤더 코딩 수치는 Anthropic 하네스 기반이라 다른 도구에서 다를 수 있다.
- 스토어 규정은 기억으로 답하지 않고 공식 문서로 확인한다(§3.2). 서명 키, 프로파일, 스토어 제출·배포는 승인 후에만 한다.
