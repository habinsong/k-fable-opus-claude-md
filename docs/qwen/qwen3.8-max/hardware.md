## 2. 이 모델의 하드웨어 작업 운용
모델 전체 특성은 같은 폴더의 `general.md` §2를 따른다. 요약: API 전용, 컨텍스트 100만 토큰, 독립 지수 45~58(스냅샷마다 다름), 환각 값 미확인, 하드웨어 설계 평가 없음, 데이터 정책 일부는 2차 출처.

- **설계 판단에 쓰지 않는다.** 핀 배치, 정격, 타이밍, 수식은 틀리면 보드가 망가지거나 위험해진다. 이 모델의 회로·PCB·HDL 평가는 찾지 못했다. [미확인] 독립 지수와 코딩 점수는 일반 능력 지표이고 회로 설계 정확도를 대표하지 않는다. 설계는 `gemini-4-argon`, `claude/opus-5.5`, `gpt-6.1-sol` 같은 상위 모델 문서와 같은 과제로 비교하고, 그 결과도 데이터시트 원문과 도구 계산으로 확인한다.
- **값 회상을 믿지 않는다.** AA-Omniscience 점수가 보도에 나오지 않았다. [미확인] 부품 번호, 핀 번호, 레지스터 주소, 정격을 모델 기억에서 가져오게 하지 않는다. 값은 사람이 확보한 데이터시트 텍스트에서만 꺼내게 하고, 값마다 문서명·개정판·페이지를 같이 받아 원문 PDF와 한 건씩 대조한다. 원문에 없으면 null이다(§3.1).
- **이미지(회로도·PCB 사진) 판독은 근거로 쓰지 않는다.** API의 Max는 비전을 포함한다는 서술이 있으나(공개 2.4T 체크포인트는 텍스트 전용) 작은 글씨의 핀 표, 타이밍 다이어그램, 회로도의 정확도를 잰 자료는 찾지 못했다. 읽은 값은 원문 텍스트·넷리스트·ERC 보고서와 대조하고, 읽기 어려운 부분은 추측하지 말고 "판독 불가"로 표시하게 한다. [부분/미확인]
- **컨텍스트가 100만 토큰이어도 데이터시트를 통째로 넣지 않는다.** 필요한 장과 표만 넣고 PDF 표를 텍스트로 변환한 결과도 원문과 대조한다. 추론 모드를 켜면 입력 한도가 약간 줄고 출력 토큰 소비가 많다(지수 실행 약 1.9억 개). [부분/추정]
- **써도 되는 작업.** BOM 정규화, 부품 번호 목록 변환, 시험 로그 분류, 데이터시트 텍스트에서 정해진 필드 추출, 측정·변환 스크립트(파이썬)의 초안. 스크립트는 알려진 값을 넣어 실행해 확인한다.
- **계산은 도구로 한다.** 전류 예산, 분압, 필터, 열 계산은 스크립트·시뮬레이터 출력으로 확인하고 식과 가정을 남긴다. 추론 모드로 낸 풀이도 마찬가지다.
- **미공개 설계 자료를 API로 보내지 않는다(약관 확인 전).** 리전에 따라 저장 위치가 정해지지만 추론 위치는 별도 설정이고, ZDR은 국제 사이트 기업 고객 전용이며 보관 기간은 원문으로 확인해야 한다. 싱가포르 리전을 써도 모기업이 중국 본사라는 지적이 있다. [부분, 충돌] 회로도·레이아웃·펌웨어 이미지·부품 공급 정보는 영업비밀이고 수출 통제·고객 계약상 국외 이전이 제한될 수 있으므로 원문 약관과 법무 확인 뒤에만 보낸다.
- **인체·화재 위험 설계는 "안전하다"고 단정하지 않는다.** 고전압·대전류·배터리·모터는 사람의 검토를 요청한다.
