## 2. 이 모델의 웹 작업 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: 비용 중심 Flash, 코딩 지수 76.3(2차), 첫 토큰 지연이 큼, 말이 많음, 2027-01-01 이후 가격 2배 예상.

- **반복적인 화면 구현·수정에 쓸 만하다.** 코딩 지수가 76.3으로 보고됐고 DeepSWE v1.1 73.7%는 벤더 수치다. 비용이 낮아 컴포넌트 단위 반복에 맞는다. [부분] 웹 UI 품질에 대한 독립 평가는 찾지 못했다. [미확인] 시각 마감은 스크린샷을 직접 대조하고 "화면 미확인"이면 그렇게 보고한다.
- **첫 토큰이 느린 점을 UI 설계에 반영한다.** 한 측정에서 첫 토큰까지 13.30초였다. [부분] 추론하는 동안 응답이 시작되지 않으므로 대화형 UI는 `thinking_level: LOW`, 스트리밍, 로딩 표시를 쓴다. 비동기 코드 생성은 상관없다.
- **`thinking_level`.** 마크업 변환·린트 수정은 `LOW`, 일반 화면 구현은 `MEDIUM`, 상태 관리·동시성 버그는 `HIGH`. `MINIMAL`은 검증 오류이고 추론을 완전히 끌 수 없다. 생각 토큰은 출력 요금이다. [부분]
- **변경 후 실제 검사를 지시문으로 강제한다.** 브라우저에서 화면을 열고 콘솔 오류와 실패한 네트워크 요청을 확인하고 관련 테스트를 돌리라고 적는다. 3.8 Flash에 대한 자기 검증 평가는 찾지 못했다. [미확인]
- **요청하지 않은 변경을 막는다.** 장황한 출력 경향(장황함 74위)이 있다. [부분] 새 컴포넌트·보조 파일을 만들기 전에 기존 UI 체계를 먼저 찾게 하고 `git diff --stat`으로 범위를 확인한다. 기존 UI 체계가 우선한다(§3.1).
- **웹 사실은 검색 grounding으로 확인한다.** 브라우저 지원·표준·라이브러리 버전은 출처 URL을 직접 열어 대조한다. 지식 평가 정답 비율 55%는 소형 모델 중 나은 편이지만 절반 가까이 틀리거나 모른다. [부분]
- **Gemini CLI에서 쓴다면** 이 문서를 `GEMINI.md`로 복사한다. [확인]
