## 2. 이 모델의 연구 작업 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: 정답 비율 55%(소형 모델 중 높은 편), 지능 지수 40.9(2차), 추론을 완전히 끌 수 없음, 연구 평가 없음.

- **연구의 추론과 인용은 이 모델에 맡기지 않는다.** 독립 평가 점수에서 지능 40.9로 보고됐고 [부분], 연구 보조 능력에 대한 평가는 찾지 못했다. [미확인] 새 가설·통계 해석·증명은 `gemini-4-argon`, `claude/opus-5.5`, `gpt-6-astra` 문서를 따르고 전문가 검토를 거친다.
- **참고문헌을 만들거나 보충하게 하지 않는다.** 26개 LLM 연구에서 검증 가능한 참고문헌 중 모든 필드가 맞은 비율은 48.3%였고 저자 목록이 가장 약했다(51.7%). 3.8 Flash의 별도 측정은 찾지 못했다. [부분/미확인] 모든 인용은 Crossref·DataCite·원문에서 제목·저자·연도·권호와 주장의 실제 존재를 확인한다.
- **써도 되는 좁은 일.** 이미 검증한 서지 정보의 서식 변환, 실험 로그·메타데이터 정리, 표 형식 변환, 논문 초록에서 정해진 필드 추출, 대량 문서의 형식 점검. 비용이 낮아 대량 처리에 맞는다. "원문에 없으면 null"을 명시하고 추출값은 원문과 한 건씩 대조하며 5~10%를 사람이 표본 점검한다.
- **분석 결과를 모델 설명으로 대체하지 않는다.** 통계는 코드를 다시 실행해서 확인한다. 시드, 데이터 버전, 라이브러리 버전을 기록하고, 이상치 제거·검정 기준이 결과에 맞춰 바뀌지 않았는지 `git diff`로 확인한다.
- **`thinking_level`.** 서식 변환은 `LOW`. 통계 계산이 걸린 정리는 `MEDIUM` 이상. `MINIMAL`은 검증 오류이고 추론을 완전히 끌 수 없다. 생각 토큰은 출력 요금이다. [부분]
- **긴 논문 묶음을 한꺼번에 넣지 않는다.** 컨텍스트 1,048,576 토큰 안에 들어가더라도 세부 연결 정확도를 보증하지 않는다. 필요한 구간을 발췌한다.
- **전문 영역(의료, 법률, 안전) 결론에는 "전문가 검토 필요"를 붙인다.**
