## 2. 이 모델의 하드웨어 작업 운용
모델 전체 특성은 같은 폴더의 `general.md` §2를 따른다. 요약: AA-Omniscience 정답 비율 55%(소형 모델 중 높은 편), 추론을 완전히 끌 수 없음, 하드웨어 평가 없음.

- **설계 판단에 쓰지 않는다.** 핀 배치, 정격, 타이밍, 수식은 틀리면 보드가 망가지거나 위험해진다. 지식 평가 정답 비율이 55%로 GPT-6 Luna(44%)와 Haiku 5.5(36%)보다 높게 인용되지만 절반 가까이 틀리거나 모른다. [부분] 하드웨어 설계 능력에 대한 평가는 찾지 못했다. [미확인] 설계는 `gemini-4-argon`, `claude/opus-5.5`, `gpt-6.1-sol` 문서를 따르고 그 결과도 원문과 도구 계산으로 확인한다.
- **써도 되는 좁은 일.** BOM 행의 표기 정규화, 부품 번호 목록의 형식 변환, 시험 로그 분류, 데이터시트 텍스트에서 정해진 필드(패키지, 핀 수) 추출. "원문에 없으면 null"을 명시하고 추출값은 원본과 한 건씩 대조한다.
- **데이터시트 값은 원문에서 가져온다.** 핀 배치, 절대 최대 정격, 타이밍은 PDF의 개정판·페이지를 확인하고, 확인하지 못한 값은 숫자를 쓰지 않는다(§3.1). 모델의 기억으로 채우지 않는다.
- **계산은 도구로 다시 한다.** 전류 예산, 분압, 필터, 열 계산은 스크립트·시뮬레이터 출력으로 확인하고 식과 가정을 남긴다. `thinking_level`은 `MEDIUM` 이상으로 명시한다(추론을 완전히 끌 수 없고 `MINIMAL`은 검증 오류).
- **큰 데이터시트는 발췌해서 넣는다.** 컨텍스트 1,048,576 토큰과 최대 출력 65,536 토큰이 있고 생각 토큰이 출력 요금을 쓴다. 필요한 장과 표만 넣는다. [부분]
- **이미지(회로도 스크린샷) 판독은 근거로 쓰지 않는다.** 넷리스트·ERC 보고서와 대조한다. [권고]
- **인체·화재 위험 설계(고전압, 대전류, 배터리, 모터)는 "안전하다"고 단정하지 않는다.**
