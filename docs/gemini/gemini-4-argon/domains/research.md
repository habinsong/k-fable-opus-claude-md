## 2. 이 모델의 연구 작업 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: 입출력 통합 1M 컨텍스트, 환각을 모델 카드가 인정, 자기 검증이 약하다는 평가, 독립 지수는 Opus 5.5보다 낮음.

- **연구 보조에 대한 독립 평가는 찾지 못했다.** [미확인] Google은 과학자·연구자를 대상으로 소개하지만 벤더 서술이다. [부분]
- **참고문헌을 필드 단위로 검증한다.** 26개 LLM을 비교한 2026년 연구에서 검증 가능한 참고문헌 중 모든 필드가 맞은 비율은 48.3%였고 저자 목록이 가장 약했다(51.7%). Argon에 대한 별도 측정은 찾지 못했다. [부분/미확인] 모델이 grounding 출처를 붙였더라도 Crossref·DataCite·원문에서 제목·저자·연도·권호와 주장의 실제 존재를 확인한다. 확인하지 못한 항목은 목록에서 분리한다.
- **긴 자료 종합은 가능성이지 보증이 아니다.** 1,048,576 토큰의 통합 한도 안에서 많은 논문을 넣을 수 있지만 생각과 답변이 같은 예산을 쓴다. [부분] 모델이 연결한 주장은 해당 논문의 해당 위치에서 확인한다.
- **자기 검증을 연구 절차에 포함시킨다.** 이 모델은 되돌아가 검토하는 일이 약하다는 후기가 있다. [부분] "결론을 쓰기 전에 반대 근거를 일부러 찾고, 주장마다 출처 위치를 적고, 확인하지 못한 주장은 빼라"를 쓰고, 분석은 코드를 다시 실행해 결과를 대조한다.
- **분석 결과를 모델 설명으로 대체하지 않는다.** 시드, 데이터 버전, 라이브러리 버전을 기록하고, 이상치 제거·필터·검정 기준이 결과에 맞춰 바뀌지 않았는지 `git diff`로 확인한다.
- **열린 추론은 상위 후보와 비교한다.** 독립 지수에서 Argon 50, Opus 5.5 58로 정리한 2차 보도가 있다. [부분] 새 가설·증명·실험 설계는 모델 단독으로 끝내지 않고 전문가 검토를 거친다. 의료·법률·안전 결론에는 "전문가 검토 필요"를 붙인다.
- **`thinking_level`.** 통계 해석과 증명은 `HIGH`, 서식 변환은 `LOW`. `MINIMAL`은 400이다. [부분]
- **비용.** 2026-11-30 이후 입력 $4 / 출력 $20이다. 서지 서식 변환 같은 단순 작업은 더 싼 모델을 쓴다. [부분]
