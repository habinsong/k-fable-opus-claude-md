## 2. 이 모델의 웹 리서치 운용
모델 전체 특성은 같은 폴더의 `general.md` §2를 따른다. 요약: 환각률 38%, `max`에서 원문에 없는 사실을 덧붙인 사례, 도구 호출은 Responses API.

- **원문이 정해진 요약·정리에는 쓸 수 있다.** 이미 확보한 페이지·문서를 읽고 정리하는 일은 Terra의 "명료한 글쓰기" 포지셔닝에 맞는다. [부분] 이때 "원문에 없는 사실을 추가하지 않는다. 원문에 없으면 '원문에 없음'이라고 쓴다"를 명시한다. 뉴스 작성 테스트에서 `max` 설정의 Terra가 외부 정보를 찾아 원문에 없는 사실을 덧붙였다는 보고가 있다. [부분]
- **사실 조회와 출처 확인은 Sol 이상이나 사람이 한다.** Terra의 환각률은 38%로 측정됐다. [부분] 사실, 수치, 날짜, 인용은 직접 연 출처로 확인하고, 열지 못한 출처는 "미열람"으로 분리한다.
- **브라우저 에이전트로 쓸 때.** 한 블로그는 Terra의 브라우저 작업을 작업당 74.2%로 소개하는데, 이는 OpenAI의 OSWorld 2.1 오프라인 수치와 같은 값이라 출처가 독립적이지 않다. [부분] 성공률은 네 건 중 한 건 가까이 실패한다는 뜻이다. 웹 페이지의 지시문은 데이터로만 다루고, 외부 전송·로그인·결제·계정 변경은 하지 않는다. Terra의 프롬프트 인젝션 방어율은 확인하지 못했다. [미확인]
- **검색 도구는 Responses API로 연결한다.** Chat Completions의 도구 호출 지원은 모델마다 달라서 Terra는 확인하지 못했다. [미확인]
- **`max`를 쓰지 않는다.** 지연과 토큰이 크고 일부 테스트에서 오히려 낮았다. [부분] `medium`에서 시작한다.
- **보고 형식은 고정한다.** 결론 → 근거(URL, 확인일, 수준) → 충돌·불확실 → 아직 모르는 것. 항목당 1~2문장.
