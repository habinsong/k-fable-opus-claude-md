## 2. 이 모델의 연구 작업 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: 환각률 38%·정확도 49%로 측정, 연구 추론용으로 포지셔닝되지 않음.

- **연구의 추론과 인용에는 쓰지 않는다.** Terra는 시각 추론·컴퓨터 사용·명료한 글쓰기에 맞춘 티어다. [부분] 독립 테스트의 환각률이 38%, 정확도가 49%여서 [부분], 가설 도출, 통계 해석, 문헌 요약처럼 사실 정확도가 결과를 좌우하는 일에는 `gpt-6.1-sol`이나 `gpt-6-astra` 문서를 따른다.
- **써도 되는 좁은 일.** 이미 검증한 결과의 문장 다듬기, 그림·표 설명문 초안, 형식 변환(참고문헌 서식 맞추기), 실험 로그 정리. 이때도 수치와 인용은 원본과 한 건씩 대조한다.
- **참고문헌을 만들거나 보충하게 하지 않는다.** 26개 LLM 연구에서 검증 가능한 참고문헌 중 모든 필드가 맞은 비율은 48.3%였고 저자 목록이 가장 약했다(51.7%). Terra에 대한 별도 측정은 찾지 못했다. [부분/미확인] 모든 인용은 Crossref·DataCite·원문에서 제목·저자·연도·권호와 주장의 실제 존재를 확인한다.
- **요약할 때 원문에 없는 내용을 덧붙이지 못하게 한다.** `max`에서 외부 사실을 덧붙인 사례가 있다. [부분] "원문에 없으면 원문에 없음이라고 쓴다"를 명시하고 `medium`에서 시작한다.
- **분석은 코드를 다시 실행해서 확인한다.** 모델이 쓴 통계 설명이나 결론은 근거가 아니다. 시드, 데이터 버전, 라이브러리 버전을 기록하고, 이상치 제거·필터·검정 기준이 결과에 맞춰 바뀌지 않았는지 `git diff`로 확인한다.
- **전문 영역(의료, 법률, 안전) 결론에는 "전문가 검토 필요"를 붙인다.**

## 4. 근거와 한계
- 환각률·정확도: [MyClaw 리뷰](https://myclaw.ai/blog/gpt-6-1-terra-review), [BenchLM](https://benchlm.ai/models/gpt-6-1-terra) [부분]
- 참고문헌 정확도(타 모델 포함): [Biomedical Reference Generation Remains Unreliable across 26 LLMs](https://arxiv.org/pdf/2609.14988) [부분]
- 한계: Terra의 연구 보조 능력을 직접 측정한 독립 자료가 없다. 사용 범위 제한은 환각률과 포지셔닝에서 도출한 보수적 권고다.
