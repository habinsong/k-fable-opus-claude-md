## 2. 이 모델의 연구 작업 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: 환각률 77%(`max`), 정확도 44%, 연구 추론용으로 포지셔닝되지 않음.

- **연구의 추론, 인용, 통계 해석에 쓰지 않는다.** AA-Omniscience에서 정확도 44%, 환각률 77%로 측정됐다. [부분] 사실 정확도가 결과를 좌우하는 일은 `gpt-6.1-sol`이나 `gpt-6-astra` 문서를 따른다.
- **참고문헌을 만들거나 보충하게 하지 않는다.** 26개 LLM 연구에서 검증 가능한 참고문헌 중 모든 필드가 맞은 비율은 48.3%였고 저자 목록이 가장 약했다(51.7%). Luna에 대한 별도 측정은 찾지 못했다. [부분/미확인] 모든 인용은 Crossref·DataCite·원문으로 제목·저자·연도·권호와 주장의 실제 존재를 확인한다.
- **써도 되는 좁은 일.** 이미 검증한 서지 정보의 서식 변환(BibTeX, APA 등), 실험 로그·메타데이터 정리, 표 형식 변환, 논문 초록에서 정해진 필드(표본 크기, 데이터셋 이름) 추출. 추출값은 원문과 한 건씩 대조한다.
- **원문에 없는 값은 추측하지 않고 null.** 추출 작업에 명시하고, 값마다 근거 구절을 받아 코드로 원문 포함 여부를 확인한다.
- **분석 결과를 모델 설명으로 대체하지 않는다.** 통계는 코드를 다시 실행해서 확인한다. 시드, 데이터 버전, 라이브러리 버전을 기록하고, 이상치 제거·검정 기준이 결과에 맞춰 바뀌지 않았는지 `git diff`로 확인한다.
- **대량 추출은 표본 점검.** 5~10%를 무작위로 뽑아 사람이 원문과 대조한다.
- **전문 영역 결론에는 "전문가 검토 필요"를 붙인다.**
