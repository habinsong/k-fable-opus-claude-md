## 2. 이 모델의 네이티브 작업 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: 환각률 77%(`max`), 코딩이 이전 세대보다 낮음, 불완전한 코드 보고.

- **시스템 코드의 구현·수정에는 쓰지 않는다.** 메모리 관리, 동시성, ABI는 문법이 맞아도 틀리기 쉽고, 틀린 결과가 보안 문제로 이어진다. Luna의 코딩 지수는 이전 세대보다 낮고 불완전한 코드가 보고됐다. [부분] 이 영역은 `gpt-6.1-sol` 이상 문서를 따른다.
- **써도 되는 좁은 일.** 컴파일러 오류 메시지 분류, 크래시 로그·스택 트레이스 그룹화, 빌드 로그 요약, 헤더 주석 초안, 단순한 코드 변환(이름 바꾸기, 포맷). 도구 출력과 대조할 수 있는 일로 한정한다.
- **API·플래그·시스템 호출을 기억에서 가져오지 않는다.** 환각률이 높게 측정됐다. [부분] 시스템 API, 링커·컴파일러 옵션은 매뉴얼과 도구 출력으로 확인한다.
- **분석 결과로 설정을 바꾸지 않는다.** 모델이 "이 sanitizer 경고는 무시해도 된다"고 말해도 억제 지시문을 추가하지 않는다.
- **테스트·경고·sanitizer 설정을 바꿔 통과시키지 않았는지 `git diff`로 확인한다.** 코딩 기만 비율 2.8%라는 시스템 카드 수치가 보도됐다(2차 인용). [부분/미확인]
- **시스템 경로, 레지스트리, 드라이버, 부트 설정, 서명 키는 승인 없이 건드리지 않는다.**
