## 2. 이 모델의 기술 조사 운용, 그리고 이 모델을 평가할 때
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: 가장 싼 티어, 환각률 77%(`max`), 이전 세대보다 코딩이 낮아짐.

**이 모델에게 기술 조사를 시킬 때**
- **분류·정리 단계에만 쓴다.** 후보 수십~수백 개를 정해진 기준(라이선스 유형, 지원 언어, 최근 릴리스 날짜)으로 분류해 표로 만드는 일은 Luna의 용도에 맞다. 단, 값은 사람이 이미 확보한 1차 자료 텍스트에서 추출하게 하고, 원문에 없으면 null로 둔다. 모델의 기억으로 채우지 않는다.
- **판단은 맡기지 않는다.** 라이선스 호환성, 특허, 규정 적용 여부, 도입 권고는 Luna에게 단정시키지 않는다(§3.2). 사람이나 상위 모델이 근거를 보고 판단한다.
- **추출 결과는 표본 점검한다.** 무작위 5~10%를 원문과 대조하고, 오류율이 기준을 넘으면 Terra나 Sol로 올린다.

**Luna를 도입 후보로 평가할 때**
- **비용.** 입력 $0.10 / 출력 $0.50(100만 토큰당), 캐시 읽기 $0.01. 입력 272K 초과 시 입력 요금 2배 보고. [부분] 싼 모델은 재시도·검증 비용이 붙으므로 "정답으로 확인된 결과 한 건당 비용"으로 비교한다.
- **품질 후퇴를 확인한다.** 독립 평가에서 종합 지수는 GPT-5.6과 비슷하지만 코딩 지수는 2점 낮고 일부 평가는 후퇴했다. 환각률은 93%에서 77%로 줄었지만 여전히 높다. 수치 대부분이 `max` 기준이라 낮은 effort 결과는 자체 측정이 필요하다. [부분]
- **코딩 기만 2.8%** 수치는 2차 인용이므로 확정하지 않고, 도입 평가에서 테스트 조작 여부를 직접 확인한다. [부분/미확인]
- **데이터 요건.** Fast·Ultrafast 지원과 EU 데이터 레지던시 제약은 Luna 관련 문서(마이그레이션 가이드)에서 Astra·Sol·Luna에 공통으로 언급됐다. [확인] 규제 인증은 확인하지 못했다. [미확인]
- **계열 혼선.** "GPT-6 Luna"(2026-09)와 이전 "GPT-5.6 Luna"가 공존한다. 계정에서 선택 가능한 ID를 먼저 확인한다.
