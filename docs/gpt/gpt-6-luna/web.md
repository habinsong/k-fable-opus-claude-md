## 2. 이 모델의 웹 작업 운용
모델 전체 특성은 같은 폴더의 `general.md` §2를 따른다. 요약: 검증 가능한 대량 작업용, 환각률 77%(AA-Omniscience, `max`), 코딩은 이전 세대보다 낮고 불완전한 코드를 냄.

- **웹 작업의 주력 모델로 쓰지 않는다.** 코딩 지수가 GPT-5.6 Luna보다 낮아졌고, 독립 평가자들은 문법은 맞지만 동작이 불완전한 코드를 보고했다. [부분] 화면 구현과 상태 관리는 `gpt-6.1-sol` 이상 문서를 따른다.
- **써도 되는 좁은 일.** i18n 문자열 추출·번역 초안, 테스트 데이터 생성, 린트 오류의 기계적 수정, 마크업의 단순 변환, 컴포넌트 문서 초안, 로그 분류. 결과는 린터·타입체크·테스트로 검증되는 일로 한정한다.
- **존재하지 않는 API·CSS 속성을 만들어낼 수 있다.** 환각률이 높게 측정됐다. [부분] 브라우저 지원 여부와 라이브러리 API는 공식 문서와 컴파일러·린터 출력으로 확인한다.
- **보안·접근성 판단을 맡기지 않는다.** 인가, 입력 검증, 비밀 노출, 접근성 "충족" 여부는 도구 출력과 §3.1 기준으로 사람이 점검한다.
- **형식을 강제한다.** JSON 스키마, 정해진 파일 형식 등 출력 구조를 지정하고 코드로 검증한다. 형식 오류는 자동 재시도하거나 폐기한다.
- **테스트를 고치지 않는다.** 코딩 기만 비율 2.8%라는 시스템 카드 수치가 보도됐다(2차 인용). [부분/미확인] 변경 후 `git diff`에서 테스트·스냅샷·기대값이 바뀌었는지 확인한다.
- **대량 변경은 표본 점검.** 여러 파일에 같은 변환을 적용했다면 무작위 몇 개를 열어 직접 대조한다.
