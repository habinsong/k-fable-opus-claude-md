## 2. 이 모델의 앱 작업 운용
모델 전체 특성은 같은 폴더의 `general.md` §2를 따른다. 요약: 검증 가능한 대량 작업용, 환각률 77%(`max`), 코딩이 이전 세대보다 낮음.

- **앱 기능 구현에는 쓰지 않는다.** 수명주기, 권한, 비동기 처리는 문법이 맞아도 동작이 불완전하기 쉬운 영역이다. 독립 평가자들은 Luna가 불완전한 코드를 냈다고 보고했다. [부분] 구현은 `gpt-6.1-sol` 이상 문서를 따른다.
- **써도 되는 좁은 일.** 리소스·문자열 파일 변환(Android `strings.xml`, iOS `Localizable`), 다국어 번역 초안, 크래시 로그 분류, 앱스토어 메타데이터 초안, 스키마가 정해진 JSON 생성. 결과는 파서·린터·빌드로 검증되는 일로 한정한다.
- **스토어 규정·플랫폼 요건은 모델의 기억에서 가져오지 않는다.** 환각률이 높다. [부분] §3.2 표를 작업 시점에 공식 문서로 다시 확인한다.
- **번역은 사람이 확인한다.** 한국어 외 언어 번역 초안은 원어민 검수 전에 출시하지 않는다. 용어집을 입력으로 주고 일관성을 점검한다.
- **개인정보·권한 문구는 직접 검토한다.** 권한 사용 목적 문구와 개인정보 처리 설명은 실제 동작과 일치하는지 사람이 확인한다.
- **대량 변환은 표본 점검.** 무작위로 5~10%를 뽑아 원본과 대조한다. 오류율이 기준을 넘으면 Terra나 Sol로 올린다.
- **서명 키, 프로파일, 스토어 제출·배포는 승인 후에만.**
