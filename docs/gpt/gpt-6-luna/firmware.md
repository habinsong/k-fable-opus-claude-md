## 2. 이 모델의 펌웨어 작업 운용
모델 전체 특성은 같은 폴더의 `general.md` §2를 따른다. 요약: 환각률 77%(`max`), 불완전한 코드 보고, 임베디드 평가 없음.

- **펌웨어 코드를 직접 쓰거나 고치게 하지 않는다.** 레지스터 값, 인터럽트, 부트·업데이트 경로, 서명 검증은 환각이 장치 고장이나 보안 구멍이 된다. Luna는 문법은 맞지만 불완전한 코드를 냈다는 보고가 있다. [부분] 이 영역은 `gpt-6.1-sol` 이상 문서를 따른다.
- **써도 되는 좁은 일.** UART·RTT 로그의 형식별 분류, 맵 파일에서 심볼 크기 표 만들기, 컴파일러 경고 그룹화, 변경 이력 요약. 출력은 원본 로그·맵 파일과 한 건씩 대조할 수 있어야 한다.
- **레지스터·타이밍을 모델의 기억에서 가져오지 않는다.** 데이터시트·레퍼런스 매뉴얼의 개정판과 페이지를 확인하고, 못 했으면 값을 쓰지 않는다(§3.1).
- **장치 쓰기는 모델이 실행하지 않는다.** 플래시 소거, 퓨즈·OTP, 보호 비트, 부트로더 덮어쓰기, 디버그 포트 잠금은 사람이 대상 장치와 이미지를 확인한 뒤 실행한다.
- **정적 분석 경고를 억제하는 제안을 따르지 않는다.** 경고는 억제하지 않고 원인을 고친다(§3.1).
- **"통과했다"는 모델의 판단을 쓰지 않는다.** 실제 보드에서 확인하지 못했으면 "하드웨어 미검증"이라고 쓴다.
