# 분야 규칙 "시점에 민감한 사실"의 근거 수준 — 기술 리서치

> 사람이 읽는 조사 기록이다. LLM 컨텍스트에 넣지 않는다.
> `universal/tech-research.md`의 "시점에 민감한 사실" 표 각 행이 어디까지 확인됐는지다. 항목과 내용이 `universal`과 같아야 하며 `scripts/docs_tool.py check`가 대조한다.
> 수준 정의는 [`docs/README.md`](../../README.md)에 있다. 원래 수준 표기가 붙은 전체 원문은 git 이력의 `docs/_common/domain-rules/`에 있다.

| 항목 | 근거 수준 | 내용 |
|---|---|---|
| EU AI Act | 부분 | Digital Omnibus(Regulation (EU) 2026/1744)가 2026-07-27 발효. Annex III 고위험 2027-12-02, 제품 내장 고위험 2028-08-02로 연기. Art.50(2) 워터마크 적용 시점은 출처 간 상충(2026-08-02 / 2026-12-02) → 관보 확인 |
| 한국 AI 기본법 | 부분 | 2026-01-22 시행. 고영향 AI와 생성형 AI 고지·표시 의무, 과태료 최대 3천만 원, 계도 기간 최소 1년으로 보도됨 → 과기정통부 고시·시행령 원문 확인 |
| EU CRA | 부분 | 보고 의무 2026-09-11, 대부분 의무 2027-12-11 |
| 모델 라이선스 | 부분 | Kimi K3는 "Modified MIT"가 아닌 자체 라이선스(규모 기준 초과 시 표기·상업 계약 요구로 요약됨, 임계값은 출처마다 다름). 원문 확인 전에는 상업 이용 가능 여부를 단정하지 않음 |
| 모델 라인업 | 확인 | 이 저장소의 모델 정보는 기준일 시점이며, 미출시 모델(Fable 5.5, Gemini 4 Carbon, GLM-5.5, Grok 4.8·5)은 공식 발표 전까지 확인되지 않은 것으로 다룬다 |
