# 분야 규칙 "시점에 민감한 사실"의 근거 수준 — 펌웨어

> 사람이 읽는 조사 기록이다. LLM 컨텍스트에 넣지 않는다.
> `universal/firmware.md`의 "시점에 민감한 사실" 표 각 행이 어디까지 확인됐는지다. 항목과 내용이 `universal`과 같아야 하며 `scripts/docs_tool.py check`가 대조한다.
> 수준 정의는 [`docs/README.md`](../../README.md)에 있다. 원래 수준 표기가 붙은 전체 원문은 git 이력의 `docs/_common/domain-rules/`에 있다.

| 항목 | 근거 수준 | 내용 |
|---|---|---|
| EU 사이버복원력법(CRA) | 부분 | 취약점·활발히 악용되는 취약점 보고 의무가 2026-09-11 시작(24시간 조기 경고, 72시간 통지, 최종 보고 14일 이내 안내). 대부분의 의무는 2027-12-11부터. 과태료 상한 1,500만 유로 또는 전 세계 매출 2.5% |
| MISRA C:2025 | 부분 | 활성 지침 225개, 롤링 릴리스 방식. Rust 대응은 Addendum 6 |
| UEFI Secure Boot 인증서 | 부분 | Microsoft 2011 인증서가 2026-06부터 순차 만료(날짜는 출처마다 다름), 2023 인증서로 교체 필요. 펌웨어(OEM) 업데이트가 필요한 장비가 있음 |
| 양자내성 서명 | 부분 | NIST IR 8547 기준 RSA·ECC는 2030 이후 deprecated, 2035 전 폐지 취지. 펌웨어 서명용 상태 유지형 해시 서명(LMS·XMSS)은 CNSA 2.0 권고에 포함 |
| 메모리 안전 | 부분 | CISA는 신규 제품군에 메모리 안전 언어를 권장하고 기존 제품에는 로드맵 공개를 요구(지원 종료가 2030 이전인 제품은 제외) |
