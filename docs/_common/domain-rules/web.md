# 분야 규칙 "시점에 민감한 사실"의 근거 수준 — 웹

> 사람이 읽는 조사 기록이다. LLM 컨텍스트에 넣지 않는다.
> `universal/web.md`의 "시점에 민감한 사실" 표 각 행이 어디까지 확인됐는지다. 항목과 내용이 `universal`과 같아야 하며 `scripts/docs_tool.py check`가 대조한다.
> 수준 정의는 [`docs/README.md`](../../README.md)에 있다. 원래 수준 표기가 붙은 전체 원문은 git 이력의 `docs/_common/domain-rules/`에 있다.

| 항목 | 근거 수준 | 내용 |
|---|---|---|
| WCAG | 부분 | 2.2가 현행 권고이며 ISO/IEC 40500:2025로 채택(2025-10). 3.0은 2026-03 워킹 드래프트라 법적 기준이 아님 |
| 유럽 접근성법(EAA) | 부분 | 2025-06-28 적용. 기술 기준은 EN 301 549(WCAG 2.1 AA 수준) |
| 미국 ADA Title II | 부분 | WCAG 2.1 AA 요구. 시한이 출처마다 다름(2026-04-24 / 2027-04-26 연장설) → 법무 확인 |
| OWASP Top 10:2025 | 부분 | A01 접근 제어 실패, A02 보안 설정 오류, A03 소프트웨어 공급망 실패(신규), A10 예외 상황 처리 실패(신규) |
| Core Web Vitals | 부분 | LCP ≤2.5s, INP ≤200ms, CLS ≤0.1 (p75). 변경 시 사전 고지 정책 |
