# 분야 규칙 "시점에 민감한 사실"의 근거 수준 — 웹 리서치

> 사람이 읽는 조사 기록이다. LLM 컨텍스트에 넣지 않는다.
> `universal/web-research.md`의 "시점에 민감한 사실" 표 각 행이 어디까지 확인됐는지다. 항목과 내용이 `universal`과 같아야 하며 `scripts/docs_tool.py check`가 대조한다.
> 수준 정의는 [`docs/README.md`](../../README.md)에 있다. 원래 수준 표기가 붙은 전체 원문은 git 이력의 `docs/_common/domain-rules/`에 있다.

| 항목 | 근거 수준 | 내용 |
|---|---|---|
| AI 크롤러 선호 표기 | 부분 | IETF AI Preferences(어휘·robots.txt 부착) 초안은 아직 표준이 아니며 배포 사례가 없다고 보고됨. IAB 워크숍 보고서(RFC 9969)는 AI 크롤러의 robots.txt 처리가 제각각이라고 지적 |
| 논문 인용의 책임 | 부분 | arXiv는 2026-05 검증 없는 LLM 출력(환각 참고문헌 등)의 명백한 증거가 있으면 1년 제출 금지를 적용한다고 발표. 저자가 내용 전체에 책임짐 |
| 검색 도구의 한계 | 확인 | 이 환경의 검색은 일부 지역·도메인 결과가 빠질 수 있고, 일부 사이트는 네트워크 정책으로 열리지 않을 수 있음 |
