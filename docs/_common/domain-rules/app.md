# 분야 규칙 "시점에 민감한 사실"의 근거 수준 — 앱

> 사람이 읽는 조사 기록이다. LLM 컨텍스트에 넣지 않는다.
> `universal/app.md`의 "시점에 민감한 사실" 표 각 행이 어디까지 확인됐는지다. 항목과 내용이 `universal`과 같아야 하며 `scripts/docs_tool.py check`가 대조한다.
> 수준 정의는 [`docs/README.md`](../../README.md)에 있다. 원래 수준 표기가 붙은 전체 원문은 git 이력의 `docs/_common/domain-rules/`에 있다.

| 항목 | 근거 수준 | 내용 |
|---|---|---|
| Apple 빌드 요건 | 부분 | 2026-04-28부터 Xcode 26 이상, iOS 26 SDK로 빌드해 업로드. 2027-04부터 Xcode 27·iOS 27 SDK, 타깃 iOS 15 이상으로 올라간다고 안내됨 |
| Apple 연령 등급 | 부분 | 4+, 9+에 13+·16+·18+ 추가. 2026-11-16부터 신규 설명자(공유 위치, 데이팅·관계), 선언 기한 2027-01-12 |
| Google Play 타깃 API | 부분 | 신규 앱·업데이트는 API 36(Android 16) 이상. 기한 2026-08-31이 지났고 연장 신청 안내가 있었음. 기존 앱 유지 기준은 API 35 |
| Android 개발자 인증 | 부분 | 2026-09-30 브라질·인도네시아·싱가포르·태국에서 집행 시작, 2027년 전 세계 확대 계획. 인증 앱 등록 필요 |
| 16KB 페이지 | 부분 | Android 15 이상을 타깃하는 앱은 16KB 페이지 지원 필요(2025-11-01 적용, 연장 있었음). 이후 추가 연장설은 단일 글이라 Play Console 확인 |
