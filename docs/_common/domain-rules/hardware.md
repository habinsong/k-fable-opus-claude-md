# 분야 규칙 "시점에 민감한 사실"의 근거 수준 — 하드웨어

> 사람이 읽는 조사 기록이다. LLM 컨텍스트에 넣지 않는다.
> `universal/hardware.md`의 "시점에 민감한 사실" 표 각 행이 어디까지 확인됐는지다. 항목과 내용이 `universal`과 같아야 하며 `scripts/docs_tool.py check`가 대조한다.
> 수준 정의는 [`docs/README.md`](../../README.md)에 있다. 원래 수준 표기가 붙은 전체 원문은 git 이력의 `docs/_common/domain-rules/`에 있다.

| 항목 | 근거 수준 | 내용 |
|---|---|---|
| EU 무선기기(RED) 사이버보안 | 부분 | 위임법이 2025-08-01부터 적용. 조화표준 EN 18031-1·-2·-3(일부 제한 조건)이 관보에 인용됨. CRA의 조화표준으로 단정하지 않음 |
| EU 사이버복원력법(CRA) | 부분 | 취약점·사고 보고 의무 2026-09-11 시작, 대부분의 의무는 2027-12-11부터. 디지털 요소가 있는 제품이 대상 |
| KiCad | 부분 | 10.0.0이 2026-03에 안정판으로 나옴(그래픽 DRC 규칙 편집기, 디자인 변형, 시간 단위 길이 튜닝, IPC-4761 비아 보호). 팀 도구 버전은 프로젝트 파일에서 확인 |
| 국내 인증 | 미확인 | 전파·전기안전 등 국내 인증 요건(KC)은 제품군별로 다르므로 공식 고시로 확인 |
