# 분야 규칙 "시점에 민감한 사실"의 근거 수준 — 리서치

> 사람이 읽는 조사 기록이다. LLM 컨텍스트에 넣지 않는다.
> `universal/research.md`의 "시점에 민감한 사실" 표 각 행이 어디까지 확인됐는지다. 항목과 내용이 `universal`과 같아야 하며 `scripts/docs_tool.py check`가 대조한다.
> 수준 정의는 [`docs/README.md`](../../README.md)에 있다. 원래 수준 표기가 붙은 전체 원문은 git 이력의 `docs/_common/domain-rules/`에 있다.

| 항목 | 근거 수준 | 내용 |
|---|---|---|
| arXiv 정책 | 부분 | 2026-05 발표: 검증 없는 LLM 출력의 명백한 증거(환각 참고문헌, 남은 챗봇 문구)가 있으면 1년 제출 금지 후 피어리뷰 게재 필요. 저자가 내용 전체에 책임 |
| 학술지 AI 사용 고지 | 미확인 | 학술지·학회마다 다르다. 투고 대상의 최신 정책을 직접 확인하고, AI는 저자가 될 수 없고 책임은 저자에게 있다는 원칙을 따른다 |
| 환각 인용의 규모 | 미확인 | 2026년 감사 연구 수치가 출처마다 달라 규모를 단정하지 않는다 |
