# 규칙 적용 시험 기록

> 사람이 읽는 조사 기록이다. LLM 컨텍스트에 넣지 않는다.
> 이 기록은 `universal/ko-*.md`의 규칙을 실제 글에 적용해 보고 `scripts/ko_style_probe.py`로 전후를 비교한 것이다.

## 이 시험이 보여 주는 것과 보여 주지 못하는 것

- 보여 주는 것: 규칙이 지시한 문체 특징(부정 대구, 분열문, 3항 나열, 감정 단어, 번역투)가 실제로 줄었는지, 숫자와 영문 같은 사실이 그대로인지, 규칙이나 도구에 모순과 누락이 있는지.
- 보여 주지 못하는 것: **글이 사람에게 자연스럽게 읽히는지.** 시험한 주체가 이 저장소를 쓴 AI 에이전트 하나이고, "전" 글과 "후" 글을 모두 그 에이전트가 썼으며, 표본은 세 개다. 사람 독자가 읽고 평가한 것이 아니다. 자연스러움은 아래 "사람 평가 절차"로 직접 확인해야 한다.

## 방법

1. 분야마다 AI 습관(부정 대구, 분열문, 3항 나열, 의미 부풀리기, 감정 설명, 과한 사과·감사)을 모은 "전" 글을 썼다.
2. `universal/ko-core.md`와 분야 문서의 규칙을 적용해 "후" 글을 썼다. 필자의 주장과 사실은 바꾸지 않았고, 없던 인물이나 사물을 만들지 않았다.
3. 같은 도구로 전후를 쟀다. 숫자와 영문 낱말 집합이 같은지는 정규식으로 대조했다.

## 시험 글

### 학술·기술
- 전: 인공지능 기술의 급속한 발전은 단순한 기술적 진보가 아니라 연구 방법론 전반의 패러다임 전환을 의미한다. 본 연구에서는 제안된 방법을 통해 추론 속도의 향상을 달성하는 것을 목표로 하였다. 또한 실험 결과, 제안 방법은 기존 방법에 비해 추론 시간이 38% 감소하였으며, 정확도는 91.2%로 유지되었다. 따라서 이는 시사하는 바가 크다고 할 수 있다. 중요한 것은 속도가 아니라 신뢰성이다. 효율성, 정확성, 그리고 확장성이 모두 확보되어야 한다.
- 후: 본 연구는 제안한 방법으로 추론 속도를 높이는 것을 목표로 하였다. 실험에서 추론 시간은 기존 방법보다 38% 줄었고 정확도는 91.2%로 유지되었다. 속도보다 신뢰성이 중요하며, 효율과 정확성과 확장성을 함께 확보해야 한다.

### 일상
- 전: 정말 죄송합니다. 오늘 약속에 늦을 것 같습니다. 이는 단순한 지각이 아니라 교통 상황으로 인한 불가피한 상황입니다. 이해해 주셔서 정말 감사합니다. 소중한 시간을 허비하게 해서 진심으로 미안하고, 최대한 빨리 도착하도록 노력하겠습니다. 언제든 연락 주세요!
- 후: 죄송합니다. 길이 막혀서 약속에 늦을 것 같습니다. 최대한 빨리 가겠습니다.

### 문학
- 전: 그날 저녁 서연은 가슴이 먹먹해졌다. 그것은 단순한 슬픔이 아니라 오래된 그리움이었다. 눈물이 흘렀고, 그녀는 정말 외로웠다. 창밖에는 비가 내리고 있었다. 마치 그녀의 마음처럼, 비는 하염없이 내렸다. 그녀는 비로소 깨달았다. 중요한 것은 떠나간 사람이 아니라 남겨진 자신이라는 것을.
- 후: 그날 저녁 서연은 창밖의 비를 보고 있었다. 오래 묵은 그리움이 올라왔다. 한참 뒤에야 그녀는 떠난 사람보다 남겨진 자기 자신을 생각하고 있다는 걸 알았다.

## 측정 결과 (전 → 후)

| 지표 | 학술 | 일상 | 문학 |
|---|---|---|---|
| 글자 수(공백 제외) | 191 → 98 | 112 → 33 | 124 → 65 |
| 변경률(원문 글자 중 바뀌거나 사라진 비율) | 64.4% | 75.9% | 74.2% |
| 부정 대구 후보 | 2 → 0 | 1 → 0 | 2 → 0 |
| 분열문·강조 도입 | 1 → 0 | 0 → 0 | 2 → 0 |
| 3항 나열 후보 | 1 → 0 | 0 → 0 | 0 → 0 |
| 감정 단어 | 0 → 0 | 0 → 0 | 3 → 0 |
| 번역투 후보 | 1 → 0 | 0 → 0 | 0 → 0 |
| `~적` 표현 | 1 → 0 | 0 → 0 | 0 → 0 |
| 당위 서술 | 1 → 1 | 0 → 0 | 0 → 0 |
| 숫자·영문 낱말 보존 | 같음(38%, 91.2%) | 해당 없음 | 해당 없음 |

## 발견과 조치

1. **측정 도구에 탐지 누락이 있었다.** 처음 돌렸을 때 "전" 글의 "확보되어야 한다"(당위)와 "효율성, 정확성, 그리고 확장성이"(3항 나열)를 세지 못했다. 정규식이 `해야 한다`만 보았고, 3항 나열은 마지막 덩어리가 길면 놓쳤다. → 정규식을 고치고 회귀 시험 2개를 추가했다.
2. **규칙에 모순이 있었다.** 규칙은 변경률이 50%를 넘으면 되돌리라고 했는데, 군더더기가 대부분인 글에서는 이 규칙을 지키면 윤문이 불가능하다. 세 시험 모두 변경률이 64~76%였다. → "50%를 넘으면 멈추고 필자에게 알린다. 지워진 것이 군더더기뿐이고 사실이 그대로면 필자 확인을 받아 진행한다"로 바꿨다(`universal/ko-core.md` §3.1).
3. **당위 서술은 줄지 않았다(1 → 1).** 필자가 유보하지 않은 규범적 주장("확보해야 한다")이라 남겼다. 표현이 줄지 않았다는 사실만 기록하고, 고칠지는 필자가 정할 일이다.
4. **"전" 글이 지나치게 군더더기투성이였다.** 실제 AI 글은 이보다 덜 극단적일 수 있다. 시험 글을 에이전트가 만들었으므로 실제 분포를 대표하지 않는다.

## 사람 평가 절차 (10분)

규칙의 진짜 효과를 보려면 사람이 읽어야 한다. 아래처럼 하면 된다.

1. 위 "전"과 "후" 묶음(또는 직접 가진 원고 3개)을 준비한다. 순서를 섞고 어느 쪽이 "후"인지 가린다.
2. 읽는 사람에게 묻는다. "어느 쪽이 사람이 쓴 글처럼 읽히나", "어색한 문장에 밑줄", "원문의 뜻이 빠졌나".
3. 결과를 이 파일에 덧붙인다. 규칙이 틀렸다면 해당 규칙을 `universal/`에서 고치고 `docs/_common/korean-writing/`의 근거 문서에 이유를 적는다.
