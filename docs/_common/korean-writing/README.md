## 읽는 법

- 지침에 수록된 규칙들은 본 폴더의 조사 근거를 바탕으로 정했습니다. 근거가 상대적으로 약한 규칙은 지침에서 표현 강도를 낮추거나 "되풀이될 때만"처럼 조건을 붙여 완화했습니다.
- 통계 수치는 대부분 특정 프로젝트 저자의 **자체 보고**에 기반하고 있습니다. 공식 동료 심사를 거친 학술 논문이 아니며 비교 대상 모델의 버전도 본 저장소의 대상 모델과 다를 수 있으므로, 모델 간 우열을 가르는 절대적 근거로 삼지 않습니다.
- 공식 규범(국립국어원)과 일부 학술 원문은 네트워크 환경상 직접 열람하지 못해 검색 요약문 위주로 확인했습니다. 세부 규범 인용 시에는 원문을 다시 한 번 확인해 주시기 바랍니다.
