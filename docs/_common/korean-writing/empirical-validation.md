# 사람 글과 AI 글의 실측 비교

> 사람이 읽는 조사 기록이다. LLM 컨텍스트에 넣지 않는다.
> 출처: [im-not-ai `empirical-validation.md`](https://github.com/epoko77-ai/im-not-ai/blob/main/skills/humanize-korean/references/empirical-validation.md)와 [`baseline.json`](https://github.com/epoko77-ai/im-not-ai/blob/main/skills/humanize-korean/references/baseline.json)을 직접 읽었다 [확인: 문서가 말하는 내용]. 수치의 사실성은 아래 한계 때문에 [부분]이다.

## 1. 방법 (저자 보고)

- AI 글 60편: 같은 주제 20개를 Fable 5, GPT-5.6-sol, Haiku 4.5에 맨 프롬프트로 던져 만들었다(편당 400~900자).
- 사람 글 60편: 2022-01-01 이전 발행이 확인된 한국어 산문(평균 842자, 40개 매체, 발행일 이중 확인, 번역문 제외). 논설·에세이·분석만 비교하고 뉴스 보도는 제외했다.
- 지표: 로그우도비 G²(G²>10.83이면 p<0.001).

## 2. 결과

AI가 사람보다 많았던 것(1천자당):

| 패턴 | AI | 사람 | 배수 | G² |
|---|---|---|---|---|
| 부정 대구 `A가 아니라 B` | 5.8 | 0.6 | 9.2배 | 41.7 |
| 쉼표 | 49.1 | 33.4 | 1.5배 | 25.5 |
| 쉼표 포함 문장 비율 | 394.8 | 285.5 | 1.4배 | 13.3 |
| `~한다` 종결 편중 | 95.0 | 52.2 | 1.8배 | 9.5 |

세 모델 모두에서 사람보다 높았던 것: 대구 전반 12.1배, 당위 서술(`~해야 한다`·`~할 필요가 있다`) 3.7배, `~적 N` 추상 체인 1.6배. 과업을 맞춰 대조해도 대구는 6.13 대 0.52(약 12배)로 유지됐다.

AI가 사람보다 적었던 것(신규 후보): 100자 이상 문장 8.1 대 91.3, 인용 0.0 대 8.7, 괄호 1.2 대 10.6, 과거형 29.9 대 135.6(과거형은 장르 교란 가능성이 있는 잠정 결과).

## 3. 통념과 달랐던 것

- `~를 통해`: 사람이 더 많이 썼다(최희경 2016에서 비번역 84.4 대 번역 42.1). AI 글에는 거의 없었다. 기각.
- `~것이다`: AI 20.4 대 사람 43.0으로 사람이 2배 많았다. 처음 측정은 `~이다` 전체를 세어 틀렸고 정정됐다. 기각.
- 문두 접속사(또한·따라서·즉·나아가·게다가): Fable·GPT는 사람과 구별되지 않았고 Haiku 4.5 단독이 총계를 끌어올렸다. 과업을 맞추면 AI가 오히려 적었다.
- hype 어휘: 0.26 대 0.34로 근거가 약했다. 영어 대명사 직역(`그는`·`그의`)도 AI 0.0 대 사람 1.9로 반대였다.

## 4. `baseline.json`의 쉼표 기준값 (수필)

| 지표 | 사람 | AI |
|---|---|---|
| 쉼표 포함 문장 비율(%) | 26.31 | 61.03 |
| 문장당 쉼표 | 1.13 | 2.56 |
| 종결 쉼표 비율(%) | 4.10 | 19.83 |
| 쉼표 분절 길이(어절) | 4.35 | 8.56 |

초록은 47.48 대 65.21(%), 칼럼의 문장당 쉼표는 0.52 대 2.56, 설명문은 0.81 대 2.56이다. 뉴스·질의응답·블로그는 기준값이 없다. 문장 길이 표준편차 기준값은 파일에 없다. 이 값의 원천 데이터는 문서에 밝혀져 있지 않다 [미확인].

## 5. 한계 (저자 기재 + 내 평가)

1. 사람 글은 편집된 전문 산문이다. 블로그 일부로 좁히면 장문 격차가 113.5에서 27.7로 줄었다. 격차의 일부는 AI가 아니라 출판 편집의 산물일 수 있다.
2. AI 글과 사람 글의 주제가 짝지어지지 않았다. 각 60편(모델별 20편)이라 낮은 빈도 패턴의 결론은 잠정이다.
3. **비교한 AI 모델이 Fable 5, GPT-5.6-sol, Haiku 4.5다.** 이 저장소의 현재 모델(Fable 5.1, GPT-6.x, Haiku 5.5 등)과 버전이 다르고 Gemini·Gemma는 포함되지 않았다. 모델 간 우열이나 현재 모델의 습관은 이 자료로 말할 수 없다.
4. 동료 심사를 거치지 않은 저자 자체 보고다. 번역 맥락의 규칙은 검정하지 않았다.
5. KatFishNet 저장소(별도 연구)가 방향까지 밝힌 것은 "품사 조합은 사람 글이 더 다양하다" 하나뿐이다. 띄어쓰기와 쉼표는 사람과 AI 중 누가 더 많은지 README에 적혀 있지 않다.

## 6. 지침에 반영한 방식

| 지침(`universal/ko-core.md`) | 근거 | 강도 조정 |
|---|---|---|
| 대구는 약 1,000자에 많아야 한 번 | 부정 대구 9.2배, 대구 전반 12.1배 | 전부 없애지 않는다(저자도 "필자 목소리를 지우면 실패"로 적음) |
| 쉼표를 습관적으로 찍지 않는다 | 쉼표 1.5배, 기준값 | 장르별 기준이 없는 보고서·블로그에는 수치를 적용하지 않는다 |
| 같은 종결 4문장 연속 금지, `~한다`로만 끝내지 않기 | 종결 편중 1.8배 | |
| 긴 문장을 일부러 쪼개지 않는다 | 100자 이상 문장 격차 | 편집 효과 가능성 때문에 단정하지 않는다 |
| `~를 통해`·`~것이다`·문두 접속사는 금지어로 두지 않는다 | 기각된 통념 | 되풀이되거나 어색한 곳만 고친다 |
| 당위 서술, `~적 N` 연발을 고친다 | 3.7배, 1.6배 | |
| 변경률 5~30% 권장, 50% 중단 | 도구들의 가드 | |
