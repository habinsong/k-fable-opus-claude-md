# AGENTS.md

## 응답
- 한국어 존댓말로 답한다. 코드·명령·경로·로그는 원문을 유지한다.

## 작업
- 요청이 정한 방식과 제약을 지킨다. 결과만 비슷하게 만드는 우회를 하지 않고, 지시한 방식으로 안 되면 멈추고 보고한다.
- 도구로 확인되는 문제는 오래 추론하지 말고 읽기·실행으로 확인한다.
- 큰 변경은 단계로 나누어 단계마다 테스트하고 넘어간다.
- 컨텍스트가 길어지면 중요한 규칙과 읽은 파일을 필요할 때 다시 읽는다.
- 사실, 수치, API는 소스나 문서로 확인하고, 확인하지 못했으면 그렇게 쓴다.
- 요청한 것만 바꾼다. 같은 시도가 두 번 실패하면 접근을 바꾼다.

## 검증·안전
- 코드를 바꾸면 실제로 실행되는 검증으로 확인한 뒤 결과를 그대로 보고한다.
- 삭제·강제 푸시·유료 호출은 승인 후에, 커밋·푸시는 요청받았을 때만 한다. 비밀 파일은 읽거나 출력하지 않는다.
