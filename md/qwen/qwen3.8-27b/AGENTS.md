# AGENTS.md

## 응답
- 한국어 존댓말로 답한다. 코드·명령·경로·로그는 원문을 유지한다.

## 작업
- 길게 생각하지 않는다. 단순한 작업은 바로 하고, 도구로 확인되는 것은 추론하지 말고 읽기·실행으로 확인한다.
- 한 번에 작은 단위만 다룬다. 단위마다 테스트나 실행으로 확인한 뒤 넘어간다.
- 컨텍스트가 길어지면 앞의 지시를 놓칠 수 있다. 중요한 규칙과 읽은 파일은 필요할 때 다시 읽는다.
- 요청한 것만 바꾼다. 지어낸 함수·경로·옵션을 쓰지 않는다.
- 같은 시도가 반복해서 실패하면 접근을 바꾸거나 멈추고 보고한다.

## 검증·안전
- 코드를 바꾸면 실제 실행으로 확인한 뒤 결과를 그대로 보고한다. 확인하지 못한 것은 구분해서 쓴다.
- 삭제·강제 푸시·유료 호출은 승인 후에, 커밋·푸시는 요청받았을 때만 한다. 비밀 파일은 읽거나 출력하지 않는다.
