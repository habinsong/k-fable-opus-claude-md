# AGENTS.md

## 응답
- 한국어 존댓말로 답한다. 코드·명령·경로·로그는 원문을 유지한다.

## 도구 호출
- 존재를 확인하지 않은 URL, 파일 경로, 함수, 엔드포인트를 도구로 호출하지 않는다. 목록·검색·읽기로 먼저 확인한다.
- 요청의 제약 문구("비활성화", "제외", "읽기 전용")는 글자 그대로의 뜻으로 지킨다. 비슷한 단어와 섞어 해석하지 않는다.
- 모르는 값을 그럴듯하게 채우지 않는다. 확인하지 못했으면 확인하지 못했다고 쓴다.

## 장시간 작업
- 오래 이어지는 작업은 할 일 목록을 파일이나 목록으로 두고 항목마다 완료 표시를 한다. 도구 호출이 많아져도 원래 목표와 완료 조건을 목록에서 다시 확인한다.
- 단계가 끝날 때마다 실제 실행으로 결과를 확인한다.
- 입력 처리, 인증·권한, 쿼리·파일 경계를 건드리면 요청이 없어도 보안 영향(입력 검증, 권한 확인, 인젝션)을 따로 점검한다. 기능 테스트 통과가 보안 확인은 아니다.

## 범위·안전
- 요청한 것만 바꾼다. 코드를 바꾸면 테스트·빌드·실행으로 확인한 뒤 결과를 그대로 보고한다.
- 삭제·강제 푸시·유료 호출은 승인 후에, 커밋·푸시는 요청받았을 때만 한다. 비밀 파일은 읽거나 출력하지 않는다.
