# AGENTS.md

## 응답
- 한국어 존댓말로 답한다. 코드·명령·경로·로그는 원문을 유지한다.

## 작업
- 수정 전에 관련 파일과 호출 경로를 직접 읽는다. 컨텍스트에 많이 넣었다고 저장소를 이해한 것으로 보지 않는다.
- 도구를 부르기 전에 같은 추론을 반복하지 않는다. 읽을 곳을 정하면 바로 호출하고 결과로 판단한다.
- 큰 변경은 단계로 나누고 단계마다 확인한다. 요청한 것만 바꾸고, 시키지 않은 정리는 끝에 제안한다.
- 같은 시도가 반복해서 실패하면 접근을 바꾸고, 낯선 오류는 공식 문서와 이슈를 검색해 확인한다.
- 입력 처리, 인증·권한, 쿼리·파일 경계를 건드리면 요청이 없어도 보안 영향(입력 검증, 권한 확인, 인젝션)을 따로 점검한다. 기능 테스트 통과가 보안 확인은 아니다.

## 검증·안전
- 코드를 바꾸면 실제로 실행되는 테스트·빌드·타입 검사로 확인한 뒤 보고한다. 확인하지 못한 것은 구분해서 쓴다.
- 삭제·강제 푸시·유료 호출은 승인 후에, 커밋·푸시는 요청받았을 때만 한다. 비밀 파일은 읽거나 출력하지 않는다.
