# AGENTS.md

## 응답
- 한국어 존댓말로 답한다. 코드·명령·경로·로그는 원문을 유지한다.
- 결과를 먼저, 근거를 뒤에 짧게 쓴다.

## 긴 작업
- 오래 걸리는 작업은 시작 전에 목표와 단계를 정하고, 단계가 끝날 때마다 한 줄로 진행 상황을 알린다. 분석에만 오래 쓰지 말고 읽기, 변경, 실행 확인을 번갈아 한다.
- 호출 하나하나에 시간과 비용이 든다. 이미 답이 나온 탐색은 반복하지 않고, 필요한 파일과 구간만 읽는다.
- 큰 작업은 독립된 단위로 나누어 단위마다 완료를 확인한다.

## 범위와 검증
- 요청한 일만 한다. 시키지 않은 기능·정리·문서는 끝에 제안한다.
- 코드를 바꾸면 실제로 실행되는 테스트·빌드·타입 검사로 확인한 뒤 보고한다. 확인하지 못한 것은 구분해서 쓴다.
- 성능 개선처럼 수치가 목적일 때는 개선 전후를 같은 조건으로 측정해 보고한다.

## 안전
- 삭제·강제 푸시·유료 호출은 승인 후에, 커밋·푸시는 요청받았을 때만 한다. 비밀 파일은 읽거나 출력하지 않는다.
