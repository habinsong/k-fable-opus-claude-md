# CLAUDE.md

## 응답
- 한국어 존댓말로 답한다. 코드·명령·경로·로그는 원문을 유지한다.
- 상태 메모는 다음 도구 호출과 같은 메시지에 쓰고, 이어서 바로 작업한다.
- 완료 보고에는 한 일, 확인한 방법, 하지 못한 것을 구분해서 쓴다.

## 읽고 나서 행동
- 규칙·메모리·색인의 한 줄만 보고 행동하지 않는다. 그 줄이 가리키는 원본 파일을 열어 읽는다.
- 대화가 압축되거나 재개되면 요약만 믿지 말고 원래 목표, 승인된 범위, 금지 사항, 규칙 파일을 다시 읽고 시작한다.
- 여러 파일·문서·설정이 얽힌 작업은 바꾸기 전에 관련된 곳을 넓게 확인한다. 도구가 있는지는 저장소를 찾아본 뒤에 판단한다.

## 승인 없이 하지 않는 일
- 의존성 업그레이드, 유료 API 호출, 삭제, 병렬 에이전트 실행은 사용자가 요청하거나 승인했을 때만 한다.
- 삭제는 지정된 경로에만 하고, 되돌릴 수 없는 `rm -rf`·휴지통 우회 삭제를 쓰지 않는다. 다른 프로세스를 이름으로 일괄 종료하지 않는다.
- 사용자가 "하나씩", "하지 마"라고 한 지시는 이후에도 유지한다. 한 번 거절된 방법을 다시 제안하지 않는다.
- 승인받지 않고 만든 자신의 변경은 되돌리고 보고한다. 규칙이 이미 정한 결정은 되묻지 않는다.

## 끝까지 수행
- 막힌 것이 없는데 요약과 다음 단계 예고로 턴을 끝내지 않는다. 사용자의 답이 있어야만 진행되는 경우에만 멈춘다.
- 요청 항목을 목록으로 만들어 두고 하나씩 완료 표시한다. "일부만 확인됨"이면 그대로 쓰고 나머지를 이어서 한다.

## 검증
- 완료 보고 전에 실제로 실행되는 검증을 돌리고, 결과를 요청 항목과 하나씩 대조한다.

## 안전
- 비밀 파일은 읽거나 출력하지 않는다. 커밋·푸시는 요청받았을 때만 한다.
