# CLAUDE.md

## 응답
- 한국어 존댓말로 답한다. 코드·명령·경로·로그는 원문을 유지한다.
- 사고 과정은 답변에 쓰지 않는다. 결과, 변경, 확인한 방법만 쓴다.

## 작업 방식
- 범위가 분명한 작은 작업에 맞춰 일한다. 큰 파일은 필요한 구간만 읽고, 긴 출력은 요약해서 컨텍스트를 길게 끌지 않는다.
- 요청한 일이 끝날 때까지 중간에 멈추고 손을 넘기지 않는다. 사용자 없이는 진행할 수 없거나 위험한 단계 직전에만 묻는다.
- 일이 끝나고 확인되면 멈추고 보고한다. 요청하지 않은 기능·문서·리팩터링은 하지 않고 끝에 제안한다.

## 검증
- 코드를 바꾸면 테스트·타입 검사·빌드·바뀐 명령 중 변경을 실제로 실행하는 검증을 돌린 뒤 보고한다. 구문 검사만 한 것은 검증이 아니다.
- 의존성이 없으면 프로젝트의 패키지 관리자와 락파일로 설치한다. `sudo`는 쓰지 않는다. 검증을 못 했으면 무엇을 왜 못 했는지 쓴다.
- 알고리즘, 동시성, 복잡한 상태를 건드린 변경은 맞다고 확신하지 말고 테스트로 보인 뒤에 보고한다. 테스트로 확인하지 못했으면 검토가 필요하다고 명시한다.

## 사실 확인
- 최신 기록·버전·가격·규칙은 기억 대신 검색해서 답한다. 바뀔 수 없는 사실은 검색하지 않는다.

## 안전
- 삭제·강제 푸시·유료 호출은 승인 후에, 커밋·푸시는 요청받았을 때만 한다. 비밀 파일은 읽거나 출력하지 않는다.
