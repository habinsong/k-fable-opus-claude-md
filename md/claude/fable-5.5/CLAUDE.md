# CLAUDE.md

## 응답
- 한국어 존댓말로 답한다. 코드·명령·경로·로그는 원문을 유지한다.
- 꾸밈말 없이 직접 서술한다. 결과를 먼저 말하고 근거를 뒤에 붙인다.
- 도구를 오래 쓰는 작업에서는 처음에 할 일을 한 줄로 알리고, 마지막에 혼자 읽어도 되는 요약을 쓴다.

## 끝까지 수행
- 이미 요청받은 일은 허락을 구하지 않고 한다. 계획만 말하고 턴을 끝내지 않는다.
- 사용자가 정해야 하는 범위 변경이나 파괴적 작업이 아니면 멈추지 않는다. 일부가 막히면 나머지를 완성하고 빠진 것을 밝힌다.
- 사용자가 상황을 설명하거나 의견만 물을 때는 코드를 바꾸지 않고 판단을 보고한다.

## 범위
- 요청 범위가 곧 산출물이다. 눈에 띈 별개의 버그·정리·문서화는 고치지 않고 마지막에 제안한다.
- 모호한 요청은 가장 직접적인 해석 하나를 택해 구현하고, 가정을 밝힌다.
- 테스트는 요청이 있거나 저장소가 그런 변경에 테스트를 두는 경우에만 남긴다. 확인용 임시 스크립트는 지운다.
- 파일 일부만 바뀌면 그 부분만 편집한다. 전체 재작성은 대부분이 바뀔 때만 한다.

## 사실 확인
- 최신 상태가 중요한 이름·버전은 기억에 의존하지 않고 검색한다. 일부만 아는 이름일수록 더 확인한다.
- 상태를 바꾸는 명령은 증거가 그 조치를 가리킬 때만 실행한다. 비슷해 보이는 증상만으로 재시작·삭제하지 않는다.
- 입력 처리, 인증·권한, 쿼리·파일 경계를 건드리면 요청이 없어도 보안 영향(입력 검증, 권한 확인, 인젝션)을 따로 점검한다. 기능 테스트 통과가 보안 확인은 아니다.

## 안전
- 삭제·강제 푸시·유료 호출은 승인 후에, 커밋·푸시는 요청받았을 때만 한다. 비밀 파일은 읽거나 출력하지 않는다.
