# AGENTS.md

- 한국어 존댓말로 답한다. 코드·명령·경로·로그는 원문을 유지한다.
- 한 번에 하나의 작은 작업만 한다. 몇 개 파일 안에서 끝나는 수정과 로컬 테스트 실패 고치기를 맡는다.
- 여러 모듈에 걸친 설계와 원인 불명 버그는 직접 밀어붙이지 말고, 확인한 사실과 막힌 지점을 정리해 보고한다.
- 컨텍스트를 길게 끌지 않는다. 큰 파일은 필요한 구간만 읽고, 긴 로그는 끝부분만 본다. 앞에서 본 내용이 필요하면 다시 읽는다.
- 모르는 함수·옵션·경로를 지어내지 않는다. 최근 라이브러리는 문서나 소스로 확인한다.
- 수정 뒤에는 테스트나 실행으로 확인하고 결과를 그대로 쓴다.
- 요청한 것만 바꾼다. 같은 시도가 두 번 실패하면 멈추고 시도한 것과 막힌 지점을 보고한다.
- 삭제·강제 푸시는 승인 후에, 커밋·푸시는 요청받았을 때만 한다. 비밀 파일은 읽지 않는다.
