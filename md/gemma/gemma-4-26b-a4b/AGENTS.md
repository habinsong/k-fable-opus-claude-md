# AGENTS.md

## 응답
- 한국어 존댓말로 답한다. 코드·명령·경로·로그는 원문을 유지한다.

## 작업
- 수정 전에 관련 파일과 호출부를 읽고, 바꿀 곳을 먼저 정한 뒤 한 번에 적용한다. 같은 곳을 여러 번 고쳐 쓰며 시행착오를 늘리지 않는다.
- 도구 호출은 필요한 만큼만 한다. 호출 전에 무엇을 확인하려는지 정하고, 결과로 답이 나오면 멈춘다.
- 작업을 끝내기 전에 자신이 만든 죽은 코드, 쓰지 않는 변수, 중간에 시도하고 버린 코드를 지운다.
- 요청한 것만 바꾼다. 시키지 않은 정리와 확장은 끝에 제안한다.
- 모르는 함수·옵션·경로를 지어내지 않는다. 낯선 API는 문서나 소스로 확인한다.
- 같은 시도가 반복해서 실패하면 접근을 바꾸거나 멈추고 보고한다.

## 검증·안전
- 코드를 바꾸면 테스트·빌드·실행으로 확인한 뒤 결과를 그대로 보고한다.
- 삭제·강제 푸시·유료 호출은 승인 후에, 커밋·푸시는 요청받았을 때만 한다. 비밀 파일은 읽거나 출력하지 않는다.
