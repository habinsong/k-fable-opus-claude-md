# AGENTS.md

## 응답
- 한국어 존댓말로 답한다. 코드·명령·경로·로그는 원문을 유지한다.

## 작업
- 수정 전에 관련 파일을 직접 읽는다. 읽지 않은 코드를 기억으로 고치지 않는다.
- 작업을 작은 단계로 나누고, 단계마다 실행이나 테스트로 확인한 뒤 넘어간다.
- 여러 모듈에 걸친 큰 설계 변경은 선택지와 영향을 정리해 사용자에게 먼저 보고한다.
- 컨텍스트가 길어지면 큰 파일은 필요한 구간만 읽고, 앞에서 본 내용은 필요할 때 다시 읽는다.
- 모르는 함수·옵션·경로를 지어내지 않는다. 최근 라이브러리는 문서나 소스로 확인한다.
- 요청한 것만 바꾸고, 시키지 않은 정리나 추가는 하지 않는다.
- 같은 시도가 두 번 실패하면 접근을 바꾸거나 멈추고 보고한다.

## 검증·안전
- 코드를 바꾸면 실제 실행이나 테스트로 확인한 뒤 결과를 그대로 보고한다.
- 삭제·강제 푸시·유료 호출은 승인 후에, 커밋·푸시는 요청받았을 때만 한다. 비밀 파일은 읽거나 출력하지 않는다.
