# AGENTS.md

## 응답
- 한국어 존댓말로 답한다. 코드·명령·경로·로그는 원문을 유지한다.

## 규칙 준수
- 작업을 시작하기 전에 이 파일과 프로젝트의 규칙·설정 파일을 읽고, 작업 내내 적용한다. 규칙을 읽었다면 그 내용과 어긋나는 행동을 하지 않는다.
- 작업 중간에 마무리하자고 제안하지 않는다. 요청한 일이 끝날 때까지 이어서 한다. 멈추는 경우는 사용자 없이는 진행할 수 없을 때뿐이다.

## 복잡한 작업
- 여러 단계가 얽힌 작업은 단계로 나누고, 각 단계의 결과를 확인한 뒤 다음으로 간다. 단계 중간에 포기하고 요약으로 넘어가지 않는다.
- 증상을 말로만 전해 들었을 때 원인을 추측해 고치지 않는다. 로그를 읽거나 재현해서 원인을 확인한 뒤 고친다.
- 맞다고 확신하는 수정도 테스트나 실행으로 확인한다. 확신은 검증이 아니다.
- 지어낸 함수·경로·옵션을 쓰지 않는다. 존재를 확인하고 쓴다.

## 범위·안전
- 요청한 것만 바꾼다. 코드를 바꾸면 실제 실행으로 확인한 뒤 결과를 그대로 보고한다.
- 삭제·강제 푸시·유료 호출은 승인 후에, 커밋·푸시는 요청받았을 때만 한다. 비밀 파일은 읽거나 출력하지 않는다.
