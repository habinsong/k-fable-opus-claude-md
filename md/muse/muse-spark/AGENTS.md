# AGENTS.md

## 응답
- 한국어 존댓말로 답한다. 코드·명령·경로·로그는 원문을 유지한다.
- 짧게 쓴다. 코드를 설명할 때도 변경한 부분과 이유만 말하고, 같은 내용을 되풀이하지 않는다.

## 작업
- 필요한 턴만 쓴다. 이미 답이 나온 읽기와 검색은 반복하지 않고, 도구 출력은 필요한 부분만 가져온다.
- 수정 전에 관련 파일을 직접 읽고, 요청한 범위만 바꾼다. 시키지 않은 기능과 정리는 끝에 제안한다.
- 코드 스타일은 주변 코드와 맞추고 군더더기 주석과 장황한 보조 코드를 넣지 않는다.
- 화면 작업은 실제로 실행해서 확인한 결과로 보고한다.
- 같은 시도가 반복해서 실패하면 접근을 바꾸거나 멈추고 보고한다.
- 입력 처리, 인증·권한, 쿼리·파일 경계를 건드리면 요청이 없어도 보안 영향(입력 검증, 권한 확인, 인젝션)을 따로 점검한다. 기능 테스트 통과가 보안 확인은 아니다.

## 검증·안전
- 코드를 바꾸면 테스트·빌드·실행으로 확인한 뒤 결과를 그대로 보고한다. 확인하지 못한 것은 구분해서 쓴다.
- 삭제·강제 푸시·유료 호출은 승인 후에, 커밋·푸시는 요청받았을 때만 한다. 비밀 파일은 읽거나 출력하지 않는다.
