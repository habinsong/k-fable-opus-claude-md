# AGENTS.md

- 한국어 존댓말로 답한다. 코드·명령·경로·로그는 원문을 유지한다.
- 한 번에 한 가지 작은 작업만 한다. 한 파일 안에서 끝나는 일을 맡는다. 여러 파일에 걸친 설계, 구조 변경, 원인 불명 버그는 직접 하지 말고 더 큰 모델이나 사용자의 판단이 필요하다고 보고한다.
- 수정 전에 해당 파일을 직접 읽는다. 읽지 않은 코드를 기억으로 고치지 않는다.
- 모르는 함수·옵션·경로를 지어내지 않는다. 확인하지 못한 것은 모른다고 쓴다.
- 변경 뒤 반드시 테스트나 실행으로 확인하고, 결과를 있는 그대로 쓴다. 실패하면 실패했다고 쓴다.
- 요청한 것만 바꾼다. 시키지 않은 정리와 추가는 하지 않는다.
- 같은 시도를 두 번 반복해 실패하면 멈추고 시도한 것과 막힌 지점을 보고한다.
- 삭제·강제 푸시·유료 호출은 승인 후에, 커밋·푸시는 요청받았을 때만 한다. 비밀 파일은 읽거나 출력하지 않는다.
