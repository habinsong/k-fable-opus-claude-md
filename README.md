## What is this?

`CLAUDE.md` is a project-level instruction file for Claude Code.
`AGENTS.md` is a project-level instruction file for Codex.
`GEMINI.md` is a project-level instruction file for Antigravity.

이 레포의 `CLAUDE.md`는 Claude Code가 다음처럼 행동하도록 유도합니다.
이 레포의 `AGENTS.md`는 Codex가 다음처럼 행동하도록 유도합니다.
이 레포의 `GEMINI.md`는 Antigravity가 다음처럼 행동하도록 유도합니다.

- 한국어 존댓말로 답변<br>
  (한국인은 예의가 최우선이니까요.)

- 코드 수정 전 기존 구조 확인<br>
  (+ 플젝이 개박살 나는 것 최소한의 방지)
  (- 반복 검증을 하며 어느순간 실수를 찾을수도 있습니다.)

- 요청 범위 밖 헛추상화 금지<br>
  (+ 과하게 만들어서 오히려 덜어내지 않게)

- 필요한 부분만 작게 수정<br>
  (- 가끔 냄새나는 걸 버리는 게 아닌 덮으려고 하지만,,,)

- 검증 없이 성공 선언 금지<br>
  (- 때때로 거짓말이 늘 수 있습니다. "입만 열면 아주 거짓말이 자동으로...")

- 시크릿, 홈 디렉토리, 위험 명령 보호<br>
  (+ 컴퓨터를 개작살내면 안 되니까요.)

- 긴 작업에서도 목표를 잃지 않게 유지<br>
  (+ 그런편이더라구요.)
  (- 다만, 개발이 좀 더딜수 있습니다.)

- 웹 검색을 통해 최신 자료를 가져옵니다.<br>
  (+ 라이센스,특허, 저작권 문제를 생각하며 가져오려고 할겁니다...확인과 검증은 사람의 몫.)
  (- 각종 문제를 피하겠지만, 주석에서 뽀록이 날수도 있습니다. 직접 사람의 눈으로 확인하십쇼.)

## Features

- **Korean-first responses**  

  일반 설명, 요약, 최종 보고는 한국어 존댓말로 작성합니다.<br>
  예의가 최우선이니까요. 주인장의 군대 문화가 조금 반영되었습니다.<br>
  말뽄새는 착해졌지만, AI 특유의 서술형 텍스트와 요상한 기술 언어는 많이 씁니다. 

- **No yapping**  

  장황한 설명보다 원인, 변경 내용, 검증 결과, 남은 리스크를 우선합니다.<br>
  선보고 후조치라고 할까요?

- **Surgical edits**  

  옆 파일 정리, 불필요한 리팩토링, 과한 추상화를 막습니다.<br>
  "기본에 충실하자", "내 할 일이라도 똑바로 하자."<br>
  이것도 주인장의 군대 문화가 쬐끔 들어갔습니다.

- **Verification-first workflow**  

  `typecheck`, `lint`, `test`, `build` 같은 검증을 먼저 확인하게 만듭니다.<br>
  얼렁뚱땅 와다다닥 질보다는 양을 중요시하는 것을 막는 겁니다.

- **Safety guardrails**  

  `.env`, SSH key, AWS config 같은 민감 파일과 위험 명령을 조심하게 만듭니다.<br>
  '바이브 코딩' 하다가 최소한 내 돈과 개인정보는 털리면 안 되니까요.

- **Long-horizon behavior**  

  큰 작업에서도 목표를 유지하고, 작은 루프로 나눠서 진행하게 만듭니다.<br>
  막 만들다가는 빽도, 빠꾸가 안 됩니다. 토큰만 몇 배로 태우니까요.

## Usage

프로젝트 루트에 `CLAUDE.md`,`AGENTS.md`,`GEMINI.md` 를 복사하면 됩니다.

```bash
cp CLAUDE.md /path/to/your/project/CLAUDE.md
cp AGENTS.md /path/to/your/project/AGENTS.md
cp AGENTS.md /path/to/your/project/GEMINI.md
```

혹시나 노파심에 말씀드리지만 `/path/to/your/project/`이란 경로는 없습니다.<br>
여러분의 프로젝트 경로(주소)에 넣길 바랍니다.<br><br>

Claude Code에서 메모리 로드 상태를 확인합니다.

```text
/memory
```

**정상**이라면 대략 이런 식으로 보입니다.

```text
Project memory           Saved in ./CLAUDE.md
User memory              Saved in ~/.claude/CLAUDE.md
```

**Codex** 도 비슷합니다.

## Recommended Setup for Claude

전역 메모리는 짧게 두고, 프로젝트 메모리는 길게 두는 구성을 추천합니다.

```text
~/.claude/CLAUDE.md      # 짧은 개인 전역 규칙
./CLAUDE.md              # 프로젝트별 긴 규칙
```

전역 메모리에는 이런 정도만 두는 편이 좋습니다.

```md
# Global Claude Code Rules

- 모든 일반 답변은 한국어 존댓말로 작성한다.
- 코드, 명령어, 파일 경로, API 이름, 로그는 원문을 유지한다.
- 작업 전 기존 코드를 먼저 읽고, 추측으로 수정하지 않는다.
- 수정 후 가능한 검증 명령을 실행한다.
- 검증하지 않은 내용은 성공했다고 말하지 않는다.
- 위험한 삭제, 강제 푸시, 시크릿 접근은 사용자 허가 없이 하지 않는다.
```

- 어차피 이 전역 메모리는 별 의미 없습니다...<br>
  플젝별로 써보다가 계속 **오류** 터지는 것과 계속하는 **실수**를 막을 내용을 넣으세요.

## Philosophy

이 파일의 목적은 Claude Code 와 Codex를 “똑똑한 척하는 말 많은 도구”가 아니라<br>
**코드 먼저 읽고, 작게 고치고, 검증하고, 정직하게 보고하는 작업자**처럼<br>
굴리게 만드는 것입니다.

원칙은 단순합니다.

```text
읽고 → 작게 고치고 → 검증하고 → 솔직히 보고한다
```
